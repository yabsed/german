# 대화 표현 — 바로 쓰는 틀

## 호칭과 자기소개

| 내용 | 친근한 한 사람 | 존칭 | 답 |
|---|---|---|---|
| 이름 | Wie heißt du? | Wie heißen Sie? | Ich heiße Minho Kim. 민호 김이다. |
| 이름, 다른 표현 | Wie ist dein Name? | Wie ist Ihr Name? | Mein Name ist Klaus Schmidt. 이름은 클라우스 슈미트다. |
| 출신 | Woher kommst du? | Woher kommen Sie? | Ich komme aus Korea. 한국 출신이다. |
| 거주지 | Wo wohnst du? | Wo wohnen Sie? | Ich wohne in München. 뮌헨에 산다. |
| 직업 | Was machst du beruflich? | Was machen Sie beruflich? | Ich bin Lehrer. 교사다. |
| 직업, 다른 표현 | Was bist du von Beruf? | Was sind Sie von Beruf? | Ich bin Student. 대학생이다. |

`du`는 친근한 한 사람, `ihr`는 친근한 여러 사람, `Sie`는 존칭 단수·복수다. 호칭은 `Herr/Frau + 성`. `Frau`는 결혼 여부와 무관하다. `sein + 직업·신분`에서는 보통 관사를 생략한다.

## 장소·출신·방향

| 묻는 말 | 답의 틀 | 예 |
|---|---|---|
| woher, 어디에서 | aus + 출신지 | aus Korea 한국 출신 |
| wo, 어디에 | in + 거주지 | in Seoul 서울에 |
| wohin, 어디로 | 도시 등에는 nach | nach Berlin 베를린으로 |
| 정지한 위치 | 해당 전치사와 격을 함께 익힘 | im Café = in dem Café, 카페에서 / auf einer Bank, 벤치에 |

나라 이름에 관사가 있으면 함께 변화한다: `aus der Schweiz`, `in der Schweiz`. `im Englischen Garten`은 영국정원에서, `in der Nähe`는 근처에, `auf dem Land`는 시골에다. `dort`는 거기에서, `dorthin`은 그쪽으로다.

## 안부

| 질문 | 답 |
|---|---|
| Wie geht es dir? 어떻게 지내니? | Mir geht es gut. 잘 지내. |
| Wie geht es Ihnen? 어떻게 지내세요? | Danke, es geht mir gut. Und Ihnen? 잘 지냅니다. 선생님은요? |
| Wie geht es ihm/ihr? 그/그녀는 어떻게 지내? | Es geht ihm/ihr gut. 그/그녀는 잘 지내. |

틀은 **es geht + 3격 사람 + 상태**다. `Wie geht's? = Wie geht es?`. 짧은 답은 `super/prima` 아주 좋아, `gut` 좋아, `Es geht so` 그럭저럭, `nicht so gut` 썩 좋지는 않아, `schlecht` 나빠.

## 만남·작별·확인

| 표현 | 쓰임 |
|---|---|
| Guten Morgen / Guten Tag / Guten Abend | 아침 / 낮 / 저녁에 만나는 인사 |
| Gute Nacht | 잠자리에 들거나 밤에 헤어질 때 |
| Hallo / Tschüss / Tschau | 친근한 만남 / 작별 |
| Auf Wiedersehen | 정중한 작별 |
| Danke / Vielen Dank / Danke schön | 감사 |
| Bitte / Bitte schön | 부탁, 감사에 대한 응답, 건네기 등 문맥별 사용 |
| Wie bitte? / Wie schreibt man das? | 다시 말씀해 주세요 / 그것을 어떻게 쓰나요? |
| Moment, ich buchstabiere. | 잠깐만요, 철자를 말할게요. |
| Alles klar? — Ja, alles klar. | 다 이해됐어? — 응, 다 이해됐어. |

## 활동과 작은 말

| 표현 | 뜻·역할 |
|---|---|
| einen Kaffee trinken / Platz nehmen | 커피 한 잔 마시다 / 자리를 잡고 앉다 |
| einen Spaziergang / eine Reise / eine Prüfung machen | 산책하다 / 여행하다 / 시험을 보다 |
| Sport treiben / Klavier spielen | 운동하다 / 피아노를 치다 |
| gerne / Gute Idee! | 제안에 기꺼이 동의 / 좋은 생각이야! |
| Die Prüfung ist vorbei. | 시험이 끝났다. |
| Hast du denn Zeit? | 그런데 시간은 있어? denn은 이 질문을 자연스럽게 잇는 말. |
| Kommen Sie mal nach Berlin! | 베를린에 한번 오세요! mal은 권유를 부드럽게 함. |
| Sie ist zwar alt, aber sehr gesund. | 나이는 많지만 아주 건강하다. 양쪽 사실을 함께 인정. |
| mindestens einmal pro Woche | 적어도 일주일에 한 번 |

## 같은 뜻, 다른 문장 구조

| 표현 | 구조·뜻 |
|---|---|
| Ich vermisse sie. | 내가 주어, 그들은 4격 대상. 나는 그들이 그립다. |
| Sie fehlen mir. | 그들이 주어, 나는 3격 경험자. 그들이 내게 그립다. |
| Er trägt einen Rucksack. | 배낭은 tragen의 4격 대상. 그는 배낭을 멘다. |
| Der Rucksack ist schwarz. | 배낭은 1격 주어. 색 형용사는 sein 뒤에서 어미 없이 쓴다. |
