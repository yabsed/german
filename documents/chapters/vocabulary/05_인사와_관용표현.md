# 단어장 5. 인사와 관용표현

[전체 목차](../../독일어_통합_학습노트.md)

단어를 하나씩 번역하기보다 통째로 알아두는 표현을 모았다. 완전한 대화는 [첫 만남](../readings/01_첫_만남.md), [커피와 산책](../readings/02_커피와_산책.md), [가족 이야기](../readings/03_가족_이야기.md)에 있고, 표현의 구조는 [대화의 문법](../rules/12_대화의_문법.md)에서 설명한다.

## 만날 때와 헤어질 때

| 상황 | 표현 | 뜻 |
|---|---|---|
| 아침 | Guten Morgen! | 좋은 아침입니다! |
| 낮의 인사 | Guten Tag! | 안녕하세요! |
| 저녁 | Guten Abend! | 안녕하세요! |
| 친근한 인사 | Hallo! | 안녕! |
| 헤어질 때 | Auf Wiedersehen! | 안녕히 가세요·계세요! / 또 뵙겠습니다! |
| 친근하게 헤어질 때 | Tschüss! / Tschau! | 잘 가! |
| 잠자리에 들 때 | Gute Nacht! | 잘 자요! |
| 감사 | Danke! / Vielen Dank! / Danke schön! | 고마워요! / 대단히 감사합니다! |
| 감사에 답하거나 건넬 때 | Bitte! / Bitte schön! | 천만에요! / 여기 있습니다! |
| 환영 | Herzlich willkommen! | 진심으로 환영합니다! |

`Guten Abend`는 저녁에 만날 때, `Gute Nacht`는 잠자리에 들거나 밤에 헤어질 때 쓴다. `Wiedersehen`은 다시 만남이라는 뜻이다. `Bitte/Bitte schön`은 부탁·감사에 대한 응답·물건을 건네는 상황에서 쓰여 문맥에 따라 번역이 달라진다.

## 이름과 철자를 확인할 때

| 표현 | 뜻 |
|---|---|
| Wie heißen Sie? / Wie heißt du? | 성함이 어떻게 되세요? / 이름이 뭐니? |
| Wie ist Ihr Name? / Wie ist dein Name? | 성함이 어떻게 되세요? / 이름이 뭐니? |
| Mein Name ist … / Ich heiße … | 제 이름은 ~입니다. |
| Wie bitte? | 뭐라고요? / 다시 말씀해 주세요. |
| Wie schreibt man das? | 그것을 어떻게 쓰나요? |
| Moment, ich buchstabiere. | 잠깐만요, 철자를 말할게요. |
| Alles klar? — Ja, alles klar. | 다 이해됐어? — 응, 다 이해됐어. |

## 안부와 응답

| 상대 | 질문 | 대답 |
|---|---|---|
| 친한 한 사람 | Wie geht es dir? | Mir geht es gut. |
| 정중한 상대 | Wie geht es Ihnen? | Danke, es geht mir gut. Und Ihnen? |
| 그 남자 | Wie geht es ihm? | Es geht ihm gut. |
| 그 여자 | Wie geht es ihr? | Es geht ihr gut. |

질문은 ‘어떻게 지내니/지내세요?’이고 답은 ‘잘 지내/지냅니다’다. `ihm`은 그 남자에게, `ihr`는 그 여자에게라는 뜻으로 안부의 대상을 바꾼다. `Und dir? / Und Ihnen?`는 ‘너는? / 선생님은요?’다.

| 기분·상태 | 뜻 |
|---|---|
| super / prima | 아주 좋아 |
| sehr gut | 매우 좋아 |
| gut | 좋아 |
| es geht / es geht so | 그럭저럭이야 |
| nicht so gut | 썩 좋지는 않아 |
| nicht gut / schlecht | 좋지 않아 / 나빠 |
| auch gut | 나도 좋아 |

## 가족 대화의 결합 표현

| 표현 | 뜻 | 대화에서의 쓰임 |
|---|---|---|
| in der Nähe | 근처에 | wohnen과 함께 거주 위치를 말함 |
| wie oft | 얼마나 자주 | 방문 빈도를 물음 |
| mindestens | 적어도 | 빈도의 최솟값을 말함 |
| einmal pro Woche | 일주일에 한 번 | einmal 한 번 + pro Woche 주당 |
| zwar …, aber … | …이기는 하지만 … | Sie ist zwar alt, aber sehr gesund. |
| nur | 오직, …만 | nur meine Großmutter |
| noch | 아직 | lebt noch |
| regelmäßig | 규칙적으로 | regelmäßig Sport treiben |
| auch | 또한, …도 | spielt auch Klavier |
| auf dem Land | 시골에 | Sie leben auf dem Land. |

`Sie ist zwar alt, aber sehr gesund`는 ‘그녀는 나이가 많지만 아주 건강하다’, `Sie leben auf dem Land`는 ‘그들은 시골에 산다’다. `Ich vermisse sie`와 `Sie fehlen mir`는 모두 그들이 그립다는 뜻이지만 주어와 목적어의 관계가 다르다. 그 차이는 [가족 이야기](../readings/03_가족_이야기.md)에서 문장 단위로 설명한다.
