# 단어장 6. 숫자와 지명

[전체 목차](../../독일어_통합_학습노트.md)

## 십·백 단위

| 숫자 | 독일어 | 주의할 점 |
|---|---|---|
| 20 | zwanzig | zwei + zig로 단순히 만들 수 없음 |
| 30 | dreißig | -zig가 아니라 -ßig |
| 40 | vierzig | vier + zig |
| 50 | fünfzig | fünf + zig |
| 60 | sechzig | sechs의 s가 빠짐 |
| 70 | siebzig | sieben의 en이 빠짐 |
| 80 | achtzig | acht + zig |
| 90 | neunzig | neun + zig |
| 100 | hundert / einhundert | ein을 붙일 수 있음 |
| 101 | hunderteins / einhunderteins | 끝의 1은 eins |
| 200 | zweihundert | zwei + hundert |

## 큰 수

| 숫자 | 독일어 | 한국어 |
|---|---|---|
| 1,000 | tausend / eintausend | 천 |
| 1,000,000 | eine Million | 백만 |
| 1,000,000,000 | eine Milliarde | 십억 |
| 1,000,000,000,000 | eine Billion | 일조 |

`Million/Milliarde/Billion`은 여성 명사이며 복수는 `Millionen/Milliarden/Billionen`이다. 독일어 `Billion`은 일조다.
