# 단어장 4. 형용사·부사·기능어

[전체 목차](../../독일어_통합_학습노트.md)

대상과 상태를 설명하는 형용사, 시간·장소·방식을 보태는 부사, 말을 연결하는 기능어를 모았다. 같은 단어가 쓰임에 따라 여러 품사 역할을 할 수 있으므로 분류보다 예문의 뜻을 먼저 읽는다. 대명사와 관사의 **변화 규칙**은 규칙 문서에 있다.

## 색

| 색 | 뜻 | 색 | 뜻 |
|---|---|---|---|
| weiß | 흰색 | schwarz | 검은색 |
| grau | 회색 | blau | 파란색 |
| grün | 초록색 | gelb | 노란색 |
| braun | 갈색 | | |

`rot`은 빨간색으로 발음 자료에 등장한다. `Der Rucksack ist schwarz`는 배낭이 검은색, `Die Jacke ist blau`는 재킷이 파란색이라는 뜻이다.

| groß | 큰·키가 큰 | Peter ist groß. 페터는 키가 크다. |

| gesund | 건강한 | sehr gesund 아주 건강한 |

| süß | 달콤한·귀여운 | Ein Kind ist süß. 아이가 귀엽다. |

## 장소·방향과 질문

| 단어 | 뜻 | 구별 |
|---|---|---|
| hier | 여기·여기에서 | 말하는 쪽의 장소 |
| dort | 거기·거기에서 | 이미 언급하거나 가리키는 장소 |
| da | 여기·거기·저기 | 문맥의 지시; die Dame da 저 여자분 |
| draußen | 밖에·밖에서 | hier draußen 여기 바깥에 |
| hierhin | 이쪽으로 | 방향 |
| dorthin | 그쪽으로 | 방향; 부정문 보충 예 |
| wer | 누구 | 사람을 묻기 |
| was | 무엇 | 내용·행동을 묻기 |
| wie | 어떻게 | 이름·상태 등 정해진 질문과 결합 |
| wo | 어디에 | 위치 |
| woher | 어디에서 | 출처·출신 |
| wohin | 어디로 | 향하는 곳 |
| wie alt | 몇 살 | 나이 |
| wie oft | 얼마나 자주 | 빈도 |

## 연결어·전치사·작은 말

| 말 | 기본 뜻 | 자료 속 쓰임 |
|---|---|---|
| und | 그리고 | 두 대상·문장을 연결; Und dir? 너는? |
| aber | 하지만 | 앞 내용과 대조 |
| zwar …, aber … | ~이기는 하지만 ~ | 양쪽 사실을 함께 인정하는 대조 |
| sondern | ~가 아니라 | 앞의 부정을 받아 다른 내용을 제시 |
| ja | 네; 강조·공감 | 답변 또는 Das Wetter ist ja wunderschön의 뉘앙스 |
| nein | 아니요 | 질문에 대한 부정의 답 |
| denn | 여기서는 질문을 자연스럽게 잇는 말 | Hast du denn Zeit? 그런데 시간은 있어? |
| mal | 한번, 권유를 부드럽게 함 | Kommen Sie mal nach Berlin! |
| eigentlich | 원래·사실은 | 출신과 현재 거주지를 나눌 때 |
| gerne | 기꺼이·즐겨 | 제안에 Gerne! 좋아! |
| aus | ~에서·~출신으로 | aus Korea 한국 출신으로 |
| in | ~안에·~에 | in Seoul 서울에 |
| nach | 도시·나라 등으로 향하여 | nach Berlin 베를린으로 |
| von | ~의·~에서 | von Beruf 직업으로 |
| auf | ~위에 | auf einer Bank 벤치에; auf dem Land 시골에 |
| über | ~에 관해·~위로 | reden über + 4격 ~에 관해 이야기하다 |
| pro | ~당 | pro Woche 일주일당 |
| statt | ~대신 | statt deiner 네 대신, 문어 표현 |
| im | in dem의 축약 | im Café 카페에서 |

발음 자료에만 등장하는 형용사·부사는 [발음 단어장](01_발음_단어.md)에 있다. 출처: 교재의 대화·어휘표, 부정문·대명사 프린트와 필기.
