# 숫자와 단어 만들기

## 숫자 조합

| 범위·역할 | 만드는 법 | 예 |
|---|---|---|
| 0–12 | 기본형을 익힘 | null, eins, zwei, drei, vier, fünf, sechs, sieben, acht, neun, zehn, elf, zwölf |
| 13–19 | 일의 자리 + zehn | drei + zehn → dreizehn, 13 |
| 16·17 | 일부 철자 축약 | sechzehn, siebzehn |
| 21–99의 일의 자리 있는 수 | 일의 자리 + und + 십 단위 | dreiundzwanzig, 23 / neunundvierzig, 49 |
| 독립적인 1 | eins | eins; hunderteins, 101 |
| 수를 조합하는 1 | ein | einundzwanzig, 21 / einhundert, 100 |
| 명사 앞의 하나 | 성·격에 따라 변화 | ein Kind, eine Schwester, einen Bruder |
| 백·천 | 큰 단위를 앞에 둠 | zweihundert, 200 / eintausend, 1,000 |
| 더 큰 명사 단위 | 대문자, 여성 명사 | eine Million, 백만 / eine Milliarde, 십억 / eine Billion, 일조 |

| 20 | 30 | 40 | 50 | 60 | 70 | 80 | 90 |
|---|---|---|---|---|---|---|---|
| zwanzig | dreißig | vierzig | fünfzig | sechzig | siebzig | achtzig | neunzig |

26·27에서는 줄이지 않는다: `sechsundzwanzig`, `siebenundzwanzig`. 큰 수의 복수는 `Millionen/Milliarden/Billionen`. 독일어 `Billion`은 현대 영어 billion과 크기가 다르다.

## 나이

| 물음·답 | 뜻 |
|---|---|
| Wie alt bist du? | 너는 몇 살이니? |
| Wie alt sind Sie? | 몇 살이신가요? |
| Ich bin neunzehn Jahre alt. | 나는 열아홉 살이다. |
| Er ist neunundvierzig Jahre alt. | 그는 마흔아홉 살이다. |
| Sie ist siebzehn. | 그녀는 열일곱 살이다. 문맥이 분명하면 Jahre alt 생략 가능. |

**주어 + sein + 숫자 + Jahre alt**. 나이를 `haben`의 대상으로 말하지 않는다.

## 여성형과 복합명사

| 만들기 | 규칙 | 예 |
|---|---|---|
| 여러 직업·신분의 여성형 | 남성형 + -in, 관사는 die | der Lehrer → die Lehrerin |
| 해당 여성형의 복수 | -innen | die Lehrerinnen, die Studentinnen |
| 복합명사의 성 | 마지막 명사가 결정 | Deutsch + der Lehrer → der Deutschlehrer |
| 복합명사의 복수 | 마지막 명사의 복수형을 따름 | der Schreibtisch → die Schreibtische |
| 형용사·동사 어간도 결합 | 앞부분이 의미를 좁힘 | groß + Eltern → Großeltern; schreib- + Tisch → Schreibtisch |
| 자료 속 복합명사의 강세 | 앞부분에 주강세 | **Deutsch**lehrer, **Haus**frau, **Schreib**tisch |

`Lehrer → Lehrern`은 격에 맞춘 **굴절**, `Lehrer → Lehrerin`은 새 단어를 만드는 **파생**, `Deutsch + Lehrer`는 **합성**이다. 모든 여성 명사가 -in으로 만들어지지는 않는다. `Schülerin`은 학교 학생, `Studentin`은 대학생이다.

## 명사를 외우는 단위

**단수 관사 + 명사 + 복수형**을 함께 익힌다: `der Mann — die Männer`, `das Buch — die Bücher`. 뜻만으로 사물의 성을 정하지 않는다. `Eltern/Großeltern/Geschwister`는 자료에서 복수이고, `Familie`는 여러 사람을 가리켜도 문법적으로 단수일 수 있다.
