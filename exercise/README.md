# 독일어 필사와 핵심 요약

## 1. 그대로 타이핑하는 필사 자료

`typing/`의 22개 파일은 `chapters/`의 규칙 12장, 단어장 6개, 읽기 4개에 하나씩 대응한다. 한국어 설명, 독일어 예문, 어휘와 뜻, 변화형, 대화와 문화 내용을 모두 옮겼다. **각 파일의 제목부터 끝까지 보이는 내용을 그대로 타이핑하면 된다.**

표는 줄 단위로 풀었다. 동사 변화형은 `ich komme; du kommst`처럼 주어와 함께 입력하도록 만들었다. 명사는 관사·단수·복수·뜻을 함께 쓴다. 강세를 표시한 단어는 `Vater (강세: Va)`처럼 강세 정보도 글자로 남겼다. 목차 메뉴와 URL, 별도의 출처 행은 옮기지 않았으며 원문은 아래 링크에서 열 수 있다.

Markdown 미리보기의 내용을 기준으로 옮기면 된다. 제목 표시용 `#`까지 입력할 필요는 없다. 독일어의 대소문자, 움라우트, ß, 예문의 문장부호와 발음기호는 보이는 대로 유지한다. 파일 안에서는 소제목을 기준으로 나눠 타이핑할 수 있다.

## 2. 형태를 바로 찾는 핵심 요약

`summary/`는 긴 설명을 다시 읽지 않고 규칙과 형태를 비교하는 문서다. 특히 **[관사 통합표](summary/01_관사_통합표.md)**에서 `der/ein/kein/mein/ihr`를 같은 성·수·격에 나란히 놓았다.

| 요약 노트 | 바로 확인할 내용 |
|---|---|
| [01. 관사 통합표](summary/01_관사_통합표.md) | 정관사와 ein 계열, 모든 소유자, euer의 철자, ihr의 여러 쓰임 |
| [02. 격과 대명사](summary/02_격과_대명사.md) | 1·2·3·4격, 동사가 요구하는 격, 대명사 전체표, 목적어 순서 |
| [03. 동사와 어순](summary/03_동사와_어순.md) | 현재형 공통 어미와 예외, sein/haben, 질문·평서문·제안 |
| [04. 부정문](summary/04_부정문.md) | kein/nicht 선택, 격, 위치와 대조 |
| [05. 발음](summary/05_발음.md) | 장단음, 이중모음, 자음 조합, 강세 |
| [06. 숫자와 단어 만들기](summary/06_숫자와_단어_만들기.md) | 수 조합, 나이, 여성형, 복합명사, 명사 암기 단위 |
| [07. 대화 표현](summary/07_대화_표현.md) | 소개·안부·호칭·장소·활동·가족 대화의 기본 틀 |

필사본은 현재 챕터 내용을 옮긴 독립 파일이다. 나중에 챕터를 수정하면 해당 필사본도 함께 갱신해야 한다.
