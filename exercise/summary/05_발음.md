# 발음 — 철자에서 소리로

**글자 이름과 단어 속 발음을 구별한다.** `[ː]`는 앞 소리를 길게, `[ˈ]`는 뒤 음절에 강세를 준다는 표시다. 한글 발음은 근사치다.

## 모음의 장단음

| 글자 | 짧은 소리 | 긴 소리 | 비교 |
|---|---|---|---|
| a | [a] | [aː] | Stadt 도시 / Staat 국가 |
| e | [ɛ] | [eː] | Bett 침대 / Tee 차 |
| i | [ɪ] | [iː] | bitten 부탁하다 / bieten 제공하다 |
| o | [ɔ] | [oː] | offen 열린 / Ofen 난로 |
| u | [ʊ] | [uː] | Mutter 어머니 / gut 좋은 |
| ä | [ɛ] | [ɛː] | Hände 손들 / Käse 치즈 |
| ö | [œ] | [øː] | öffnen 열다 / schön 아름다운 |
| ü | [ʏ] | [yː] | füllen 채우다 / fühlen 느끼다 |

`ö`는 에 계열의 혀 위치에서, `ü`는 이 계열의 혀 위치에서 입술을 둥글게 한다. 강세 없는 `e`는 흔히 `[ə]`, `-er`는 `[ɐ]`로 약해진다: `Name`, `Vater`.

| 철자의 단서 | 기본 경향 | 한계·예외 |
|---|---|---|
| 겹자음·자음 여러 개 | 앞 모음이 짧은 경우가 많음 | Mann; 하지만 Buch, schläft는 긴 모음 |
| 열린 음절·뒤 자음 하나 | 긴 경우가 많음 | Na-me; 하지만 mit는 짧음 |
| 모음 뒤의 h | h가 묵음이고 앞 모음이 긴 경우가 많음 | Bahn, wohnen; Haus의 첫 h는 발음 |
| aa, ee, oo | 하나의 긴 모음 | Haar, Tee, Boot |
| ie | 대개 [iː] | Liebe; Familie, Ferien, Aktie 등은 별도 확인 |

자음 **글자 수**만 세어 길이를 단정하지 않는다. 강세가 있다고 언제나 긴 모음인 것도 아니다.

## 이중모음

| 철자 | 소리 | 예 |
|---|---|---|
| au | [aʊ] | Haus, Frau |
| ai/ay/ei/ey | [aɪ] | Mai, Bayern, Wein, Meyer |
| eu/äu | [ɔʏ] | heute, Freund, Häuser |

`ie`와 `ei`는 다르다. `Museum/Amadeus`의 e·u는 위 eu처럼 합치지 않는다. `Friseur/Ingenieur`의 eu는 긴 ö 계열이다.

## 자음에서 자주 틀리는 부분

| 철자·위치 | 소리·규칙 | 예 |
|---|---|---|
| 음절 끝 b/d/g | 흔히 [p]/[t]/[k] | Dieb, Kind, Tag; Tages에서는 [ɡ] |
| 단어 끝 -ig | 독일 표준 발음에서 흔히 [ɪç] | König, billig; 지역차 있음 |
| w / j | [v] / [j] | Wetter / ja |
| z / x / qu | [ts] / [ks] / [kv] | Zeit / Taxi / Quelle |
| v | [f] 또는 [v] | Vater / Vase, 단어별 확인 |
| s / ß | s는 흔히 [z] 또는 [s], ß는 [s] | Sonne / Haus / Fuß |
| a/o/u/au 뒤 ch | [x] | Bach, Buch, Tochter, auch |
| 그 밖의 모음·여러 자음 뒤 ch | 흔히 [ç] | ich, Milch, Bücher, Töchter |
| 외래어·어두 ch | 단어·지역별 확인 | China/Chemie [ç] 계열, Chaos [k], Chef [ʃ] |
| chs / ck | [ks] / [k] | sechs / Zucker |
| ng / nk | [ŋ] / [ŋk] | Finger / danken |
| pf / ph | [pf] / [f] | Apfel / Physik |
| sch / tsch | [ʃ] / [tʃ] | Schule / Deutsch |
| 어근 첫머리 sp/st | [ʃp]/[ʃt] | Sport, Stein, Aussprache, verstehen |
| 그 밖의 sp/st | 흔히 [sp]/[st] | Wespe, Fenster |
| ds/ts/tz | [ts] | abends, nachts, jetzt |
| dt/th | [t] | Stadt, Theater |
| rh | r 소리 | Rhein |
| 외래어 ti + 모음 | 흔히 [tsi̯] 계열 | Nation, Patient |

`z`를 발음기호 `[z]`로 읽지 않는다. 철자 z는 `[ts]`다. r는 모음 뒤나 약한 `-er`에서 모음처럼 약해질 수 있다. y는 `Typ/System`에서 ü 계열, `Yoga`에서 `[j]` 계열이다.

## 강세

| 묶음 | 기본 경향 | 예 |
|---|---|---|
| 기본 단어 | 첫 음절인 경우가 많음 | **Va**ter; 예외 Ber**lin**, Ca**fé** |
| 분리접두사 | 보통 접두사에 강세 | **ab**fahren, **an**kommen |
| 비분리접두사 | 보통 접두사에 강세 없음 | be**kom**men, ver**ste**hen; miss-는 단어별 확인 |
| -heit/-keit/-lein/-ung/-er/-schaft/-bar/-haft/-ig/-isch/-lich | 대체로 강세를 끌어오지 않음 | Ge**sund**heit, **Prü**fung |
| -ent/-ion/-tät/-ist/-ieren | 흔히 강세를 받음 | Stu**dent**, Na**tion**, stu**die**ren |

`ä/ö/ü/ß` 입력이 어려울 때 대체 철자는 `ae/oe/ue/ss`다. 원래 철자를 쓸 수 있으면 유지한다.
