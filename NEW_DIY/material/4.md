## 1. 가족 대화

교재 29–30쪽 · [29쪽](../materials/textbook/KakaoTalk_20261012_104454803_10.jpg) · [30쪽](../materials/textbook/KakaoTalk_20261012_104454803_11.jpg)

### 1.1. 도입 문장

* Hana und Julia sitzen jetzt auf einer Bank im Englischen Garten.
    * 하나와 율리아는 지금 영국정원의 벤치에 앉아 있다.
    * Hana und Julia = 복수 주어 → sitzen.
    * sitzen                  : 앉아 있다
    * jetzt                   : 지금.
    * die Bank → die Bänke    : 벤치. 위치 auf + 3격 → auf einer Bank.
    * der Garten → die Gärten : 정원. im = in dem → 장소 3격.
* Sie reden über ihre Familien.
    * 두 사람은 자신들의 가족에 관해 이야기한다.
    * sie 복수 → reden
    * reden über + 4격           : ~에 관해 말하다.
    * die Familie → die Familien : 가족.
    * ihre Familien = ‘그들의 가족들’, 복수 4격.

---

### 1.2. 부모님

* Hana  : Wo wohnen deine Eltern?
    * 네 부모님은 어디에 사시니?
    * wo         : 어디에
    * die Eltern : 부모, 복수 → wohnen.
    * dein + 복수 1격 → deine Eltern.
* Julia : Meine Eltern wohnen hier in der Nähe.
    * 우리 부모님은 여기 근처에 사셔.
    * mein + 복수 1격 → meine Eltern.
    * die Nähe    : 가까움, 근처
    * in der Nähe : 근처에, 여성 3격.
* Hana  : Wie oft besuchst du sie?
    * 얼마나 자주 부모님을 찾아뵈니?
    * wie oft        : 얼마나 자주
    * besuchen + 4격 : 방문하다.
    * du → besuchst / sie = 부모님을 받는 복수 4격.
* Julia : Ich besuche sie mindestens einmal pro Woche.
    * 적어도 일주일에 한 번은 찾아뵈어.
    * ich → besuche / sie = 4격 목적어.
    * mindestens             : 적어도
    * einmal                 : 한 번.
    * die Woche → die Wochen : 주.
    * pro Woche              : 매주, 일주일에.

---

### 1.3. 형제자매

* Hana  : Hast du Geschwister?
    * 형제자매가 있니?
    * haben → du hast
    * die Geschwister : 형제자매, 복수.
    * 불특정 복수 4격 → 무관사 Geschwister.
* Julia : Ja, ich habe einen Bruder und eine Schwester.
    * 응, 남자 형제 하나와 여자 형제 하나가 있어.
    * der Bruder → die Brüder        : 형·오빠·남동생.
    * die Schwester → die Schwestern : 언니·누나·여동생.
    * haben + 4격 → einen Bruder / eine Schwester.
* Mein Bruder ist 30 Jahre alt.
    * 내 남자 형제는 서른 살이야.
    * mein Bruder = 남성 1격 주어.
    * das Jahr → die Jahre : 해, 년
    * dreißig              : 30
    * alt                  : 나이가 ~인.
    * sein + 숫자 + Jahre alt → 나이.
* Er ist Deutschlehrer.
    * 그는 독일어 교사야.
    * er = Bruder / der Deutschlehrer → die Deutschlehrer.
    * 직업 보어 → 무관사 Deutschlehrer.
* Hana  : Und wie alt ist deine Schwester?
    * 그러면 여자 형제는 몇 살이니?
    * wie alt : 몇 살
    * deine Schwester = 여성 1격 주어 → ist.
* Julia : Sie ist siebzehn. Sie ist Schülerin.
    * 열일곱 살이야. 학생이야.
    * sie = Schwester
    * siebzehn                         : 17
    * Jahre alt가 생략된 나이 표현.
    * die Schülerin → die Schülerinnen : 여학생. 무관사 1격 보어.

---

### 1.4. 조부모님

* Hana  : Hast du auch Großeltern?
    * 조부모님도 계시니?
    * auch           : ~도
    * die Großeltern : 조부모, 복수.
    * haben + 4격, 불특정 복수라 무관사.
* Julia : Ja, aber nur meine Großmutter lebt noch.
    * 응, 그런데 할머니만 살아 계셔.
    * die Großmutter → die Großmütter : 할머니.
    * aber                            : 하지만
    * nur                             : 오직
    * noch                            : 아직.
    * nur meine Großmutter = 한 주어 성분 / lebt ← leben, 단수.
* Sie ist zwar alt, aber sehr gesund.
    * 연세는 많으시지만 아주 건강하셔.
    * zwar … aber … : 비록 ~하지만 ….
    * alt·gesund    : 형용사 보어
    * sehr          : 매우.
    * aber 뒤에 Sie ist가 생략되어 있다.
* Sie treibt regelmäßig Sport und spielt auch Klavier.
    * 규칙적으로 운동하시고 피아노도 치셔.
    * treiben → sie treibt / spielen → sie spielt.
    * regelmäßig                 : 규칙적으로
    * auch                       : ~도
    * und                        : 그리고.
    * der Sport                  : 스포츠
    * Sport treiben              : 운동하다.
    * das Klavier → die Klaviere : 피아노
    * Klavier spielen            : 피아노를 치다.
    * 두 동사가 같은 주어 Sie를 공유한다. 두 명사는 관용적으로 무관사.
* Hana  : Ich habe auch Großeltern in Korea.
    * 나도 한국에 조부모님이 계셔.
    * ich → habe
    * Großeltern = 복수 4격
    * in Korea : 한국에.
* Sie leben auf dem Land.
    * 조부모님은 시골에 사셔.
    * sie = 조부모님, 복수 → leben.
    * das Land → die Länder : 나라; 이 표현에서는 시골.
    * auf dem Land          : 시골에서, 중성 3격.
* Julia : Vermisst du sie?
    * 조부모님이 보고 싶니?
    * vermissen + 4격 : 그리워하다
    * du → vermisst
    * sie = 복수 4격.
* Hana  : Ja, sie fehlen mir sehr.
    * 응, 아주 보고 싶어.
    * fehlen + 3격 사람 : ~에게 없어서 아쉽다, ~가 그립다.
    * sie = 그리운 대상인 조부모님, 주어 복수 → fehlen.
    * mir = 그리움을 느끼는 나, 3격.

* die Eltern                : 부모
* die Nähe                  : 가까움, 근처
* besuchen                  : 방문하다
* mindestens                : 적어도
* einmal                    : 한 번
* pro                       : ~마다
* die Woche                 : 주
* die Geschwister           : 형제자매
* der Bruder                : 남자 형제
* die Schwester             : 여자 형제
* das Jahr                  : 년
* der Deutschlehrer         : 독일어 교사
* alt                       : 늙은, 나이가 ~인
* der Schüler → die Schüler : 남학생

### 1.6. 30쪽 영국정원 문화

* der Englische Garten : 뮌헨의 영국정원
    * englisch   : 영국의
    * der Garten : 정원.
    * 장소 3격 → im Englischen Garten.
* der Chinesische Turm : 중국탑
    * chinesisch           : 중국의
    * der Turm → die Türme : 탑.
* 교재 소개            : 1789년에 조성된 뮌헨의 휴식 공간. 중국탑과 그 앞의 야외 주점을 소개한다.

## 2. 소유관사

교재 31쪽 · [원본](../materials/textbook/KakaoTalk_20261012_104454803_11.jpg)

### 2.1. 누구의 것인가

* ich → mein  : 나의
* du → dein   : 너의
* er → sein   : 그의
* sie → ihr   : 그녀의
* es → sein   : 그것의
* wir → unser : 우리의
* ihr → euer  : 너희의
* sie → ihr   : 그들의
* Sie → Ihr   : 당신의, 여러분의 — 존칭 대문자.
* 교재 제목은 ‘소유대명사’. 여기서는 명사 앞에서 쓰므로 소유관사라고 부른다.

---

### 2.2. 소유자와 뒤 명사를 따로 본다

* 소유자 → mein/dein/sein/ihr 등의 어간을 고른다.
* 뒤 명사의 성·수·격 → 어미를 고른다.
* 단수는 ein의 변화와 같다. 복수도 쓸 수 있다.
* mein의 전체 변화 → 1 / 2 / 3 / 4격
    * 남성 : mein / meines / meinem / meinen
    * 여성 : meine / meiner / meiner / meine
    * 중성 : mein / meines / meinem / mein
    * 복수 : meine / meiner / meinen / meine
* 명사까지 함께 변화한다.
    * mein Bruder → meines Bruders.
    * meine Kinder → meinen Kindern, 복수 3격.
* euer + 어미 → 보통 eure/eures/eurem/euren/eurer.
    * eure Schwester / euren Bruder.
* sein은 두 역할이 있다.
    * 동사 sein     : ~이다
    * 소유관사 sein : 그의, 그것의.

---

### 2.3. 이름 묻기 전체

* Wie ist dein Name? — Mein Name ist Klaus Schmidt.
    * 이름이 뭐니? — 내 이름은 클라우스 슈미트야.
    * der Name → die Namen : 이름. 남성 1격 → dein / mein.
* Wie ist Ihr Name?  — Mein Name ist Klaus Schmidt.
    * 성함이 어떻게 되세요? — 제 이름은 클라우스 슈미트입니다.
    * 존칭 Ihr. 교재의 dein/Ihr 선택지를 두 문장으로 풀었다.
* Wie ist sein Name? — Sein Name ist Minho Kim.
    * 그의 이름은 뭐니? — 그의 이름은 김민호야.
    * er → sein / Name 남성 1격 → sein Name.
* Wie ist ihr Name?  — Ihr Name ist Hana Park.
    * 그녀의 이름은 뭐니? — 그녀의 이름은 박하나야.
    * 질문의 ihr = 그녀의. 답의 Ihr는 문장 첫 글자라 대문자.
    * 문장 첫 Ihr가 항상 존칭인 것은 아니다.

---

### 2.4. 남성 1격 → 4격

* Mein Bruder studiert in Deutschland.
    * 내 남자 형제는 독일에서 대학 공부를 한다.
    * der Bruder → die Brüder / mein Bruder = 남성 1격 주어.
    * studieren → studiert : 3인칭 단수.
* Ich vermisse meinen Bruder.
    * 나는 내 남자 형제가 그립다.
    * vermissen + 4격 → meinen Bruder.

---

### 2.5. 여성 1격 → 4격

* Meine Großmutter lebt noch.
    * 내 할머니는 아직 살아 계신다.
    * die Großmutter → die Großmütter / meine Großmutter = 여성 1격.
    * leben → lebt
    * noch : 아직.
* Ich liebe meine Großmutter.
    * 나는 내 할머니를 사랑한다.
    * lieben + 4격. 여성 4격도 meine.

---

### 2.6. 중성 1격 → 4격

* Mein Kind ist 5 Jahre alt.
    * 내 아이는 다섯 살이다.
    * das Kind → die Kinder / mein Kind = 중성 1격.
    * fünf Jahre alt : 다섯 살.
* Ich liebe mein Kind sehr.
    * 나는 내 아이를 아주 사랑한다.
    * lieben + 4격. 중성 4격도 mein
    * sehr : 매우.

---

### 2.7. 복수 1격 → 4격

* Meine Eltern wohnen hier in der Nähe.
    * 우리 부모님은 여기 근처에 사신다.
    * die Eltern = 복수 → meine Eltern, wohnen.
    * die Nähe → in der Nähe, 여성 3격 장소구.
* Ich besuche meine Eltern einmal pro Woche.
    * 나는 일주일에 한 번 부모님을 찾아뵌다.
    * besuchen + 4격 → meine Eltern.
    * einmal                : 한 번
    * die Woche → pro Woche : 일주일에.

---

### 2.8. 사진의 나이 질문 필기

* Wie alt sind Sie?
    * 연세가 어떻게 되세요? wie alt + sind + Sie.
    * Sie는 주어 1격이고 존칭이라 대문자.

## 3. 숫자와 단어 만들기

교재 32–33쪽 · [원본](../materials/textbook/KakaoTalk_20261012_104454803_12.jpg)

### 3.1. 숫자 표 전체

* 0 null / 1 ein(s) / 2 zwei / 3 drei / 4 vier / 5 fünf
* 6 sechs / 7 sieben / 8 acht / 9 neun / 10 zehn
* 11 elf / 12 zwölf / 13 dreizehn / 14 vierzehn / 15 fünfzehn
* 16 sechzehn / 17 siebzehn / 18 achtzehn / 19 neunzehn / 20 zwanzig
* 21 einundzwanzig / 22 zweiundzwanzig
* 30 dreißig / 40 vierzig / 50 fünfzig / 60 sechzig
* 70 siebzig / 80 achtzig / 90 neunzig / 100 hundert

* 13–19 → 일의 자리 + zehn.
    * 16 sechzehn : sechs의 s 탈락.
    * 17 siebzehn : sieben의 en 탈락.
* 21–99의 합성 수 → 일의 자리 + und + 십의 자리.
    * 21 = ein + und + zwanzig. einsundzwanzig가 아니다.
* 20·30·60·70 → zwanzig, dreißig, sechzig, siebzig의 철자 주의.
* 교재의 큰 수
    * tausend                        : 천
    * die Million → die Millionen    : 백만
    * die Milliarde → die Milliarden : 십억
    * die Billion → die Billionen    : 조
* 하나를 단독으로 셀 때 eins. 명사 앞의 ein은 성·격에 따라 변한다.

---

### 3.2. 여성 명사

* der Schüler → die Schülerin : 남학생 → 여학생
    * die Schüler / die Schülerinnen : 각각 복수.
* der Student → die Studentin : 남자 대학생 → 여자 대학생
    * die Studenten / die Studentinnen : 각각 복수.
* 직업·신분 명사의 여성형 → 교재 예에서는 -in.
* 여성형 -in의 복수 → -innen.

---

### 3.3. 복합명사 전체

* der Deutschlehrer = das Deutsch + der Lehrer
    * 독일어 + 교사 → 독일어 교사.
    * 뒤의 der Lehrer가 성을 결정 → der Deutschlehrer.
* die Hausfrau = das Haus + die Frau
    * 집 + 여자 → 전업주부.
    * 뒤의 die Frau가 성을 결정 → die Hausfrau.
* die Großeltern = groß + die Eltern
    * 큰 + 부모 → 조부모.
    * die Eltern이 복수 → die Großeltern도 복수.
* der Schreibtisch = schreiben + der Tisch
    * 쓰다 + 탁자 → 책상.
    * schreiben의 어간 schreib- + Tisch.
    * der Tisch → die Tische / der Schreibtisch → die Schreibtische.
* 기본 강세는 앞부분에, 성은 마지막 명사에 맞춘다.
* 교재 어휘 상자
    * das Haus → die Häuser                : 집
    * die Hausfrau → die Hausfrauen        : 전업주부
    * schreiben                            : 쓰다
    * der Schreibtisch → die Schreibtische : 책상
