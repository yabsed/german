# 핵심 개념 + 문장 타이핑

- 각 소단원은 **개념 타이핑 → 예문 타이핑** 순서다.
- 개념의 불릿 내용을 타이핑하고, 바로 아래 독일어 예문을 타이핑한다.
- 예문 아래 한국어는 뜻 확인용이다. `#`, `-`, `**` 같은 마크다운 기호는 입력하지 않아도 된다.
- 독일어 대소문자·움라우트·ß·문장부호는 그대로 쓴다. 발음 편은 소리 내어 읽으며 입력한다.
- 한 소단원씩 공부한다. 익숙해지면 독일어를 가리고 한국어 뜻만 보고 다시 쓴다.
- `chapters`의 22개 주제와 `exercise/typing`, `exercise/summary`의 핵심을 재구성했다.
- 규칙·예외·전체 변화 체계는 남기고, 반복 설명·같은 유형의 나열은 줄였다. 어휘는 대표 문장으로 연습한다.
- 예문은 원자료에서 고르거나 같은 규칙으로 새로 구성했다. 인물·이름 순위 등은 교재 당시 설정으로 표시했다.
