# Lektion 1 · 단어와 발음

단어와 뜻을 외운다. 명사는 관사와 복수형을 함께 외운다.

## 기본 단어

* das Alphabet → die Alphabete : 알파벳
* die Aussprache → die Aussprachen : 발음
* die Lektion → die Lektionen : 과
* der Vokal → die Vokale : 모음
* der Konsonant → die Konsonanten : 자음

## 모음

> 같은 자음이 두 번 나오면 앞 모음은 대체로 짧다. 모음 뒤의 묵음 h는 앞 모음이 길다는 표시다.
> 모음 길이는 단어와 함께 익힌다. 발음기호의 ː는 긴 소리를 뜻한다.

### a

> da·fahren은 긴 [aː], hallo·fallen은 짧은 [a].

* da : 거기에
* fahren : 타고 가다
* hallo : 안녕
* fallen : 떨어지다

### e

> Lehrer·See는 긴 [eː], hell·lernen은 짧은 [ɛ].

* der Lehrer → die Lehrer : 남자 교사
* der See → die Seen : 호수
* hell : 밝은
* lernen : 배우다

### 강세 없는 e, 어말 -er

> Name·komme의 끝 e는 약한 [ə]. Lehrer·Mutter의 끝 -er는 흔히 [ɐ].

* der Name → die Namen : 이름
* kommen → ich komme : 오다 → 나는 온다
* die Mutter → die Muetter : 어머니

### i, ie

> Berlin·Miete는 긴 [iː], ich·Mitte는 짧은 [ɪ]. Familie·Asien의 강세 없는 ie는 [i̯ə].

* Berlin : 베를린
* die Miete → die Mieten : 집세
* ich : 나
* die Mitte → die Mitten : 가운데
* die Familie → die Familien : 가족
* Asien : 아시아

### o

> Sohn·Boot는 긴 [oː], von·kommen은 짧은 [ɔ].

* der Sohn → die Soehne : 아들
* das Boot → die Boote : 배
* von : ~로부터, ~의
* kommen : 오다

### u

> gut·Beruf는 긴 [uː], und·Mund는 짧은 [ʊ].

* gut : 좋은, 잘
* der Beruf → die Berufe : 직업
* und : 그리고
* der Mund → die Muender : 입

### ae

> Baeren·schlaeft의 ae는 긴 [ɛː]. Getraenke의 ae는 짧은 [ɛ]. Aerztin은 자음 개수만으로 모음 길이를 판단하지 않는다.

* der Baer → die Baeren : 곰
* schlafen → er schlaeft : 자다 → 그는 잔다
* die Aerztin → die Aerztinnen : 여자 의사
* das Getraenk → die Getraenke : 음료

### oe

> schoen·hoeren은 긴 [øː], Woerter·Koeln은 짧은 [œ].

* schoen : 아름다운, 좋은
* hoeren : 듣다
* das Wort → die Woerter : 낱말
* Koeln : 쾰른

### ue

> suess·fuehlen은 긴 [yː], duenn·fuellen은 짧은 [ʏ].

* suess : 달콤한, 귀여운
* fuehlen : 느끼다
* duenn : 얇은, 마른
* fuellen : 채우다

### au

> au는 [aʊ]. 두 소리를 이어 읽는다.

* das Haus → die Haeuser : 집
* die Frau → die Frauen : 여자, 부인

### eu, aeu

> eu와 aeu는 같은 [ɔʏ].

* heute : 오늘
* der Freund → die Freunde : 남자 친구
* der Kaeufer → die Kaeufer : 구매자
* der Raeuber → die Raeuber : 강도

### ai, ay, ei

> 아래 단어의 ai·ay·ei는 모두 [aɪ].

* der Mai : 5월
* der Laib → die Laibe : 빵 한 덩이
* Bayern : 바이에른
* Mayer : 성씨
* nein : 아니요
* allein : 혼자, 홀로

## 자음

### b, p

> b는 [b]. 단어 끝에서는 [p]로 읽는다. p는 [p].

* sein → ich bin : ~이다 → 나는 ~이다
* der Beruf → die Berufe : 직업
* der Dieb → die Diebe : 도둑
* lieb : 사랑스러운
* die Post : 우편
* das Papier → die Papiere : 종이, 서류

### d, t

> d는 [d]. 단어 끝에서는 [t]로 읽는다. 아래 단어의 t·dt·th는 [t].

* der : 남성 1격 등의 정관사
* die Dame → die Damen : 숙녀, 여자분
* die Hand → die Haende : 손
* der Mund → die Muender : 입
* der Tag → die Tage : 날
* haben → er hat : 가지고 있다 → 그는 가지고 있다
* Schmidt : 성씨 슈미트
* das Theater → die Theater : 극장, 연극

### g, k, ck, c

> g는 [ɡ]. 단어 끝에서는 [k]로 읽는다. k·ck와 Cola·Computer의 c도 [k].

* gut : 좋은, 잘
* der Magen → die Maegen : 위
* der Tag → die Tage : 날
* die Burg → die Burgen : 성
* kalt : 추운
* welken : 시들다
* dick : 두꺼운, 뚱뚱한
* zurueck : 뒤로, 돌아서
* die Cola → die Colas : 콜라
* der Computer → die Computer : 컴퓨터

### s, ss

> sehen·Sohn의 s는 [z]. Haus·Maus의 끝 s와 ss는 [s].

* sehen : 보다
* der Sohn → die Soehne : 아들
* das Haus → die Haeuser : 집
* die Maus → die Maeuse : 쥐
* der Fuss → die Fuesse : 발
* das Mass → die Masse : 치수, 척도

### v, f, w

> Vase·Verb의 v는 [v], von·Vater의 v는 [f]. f는 [f], w는 [v].

* die Vase → die Vasen : 꽃병
* das Verb → die Verben : 동사
* von : ~로부터, ~의
* der Vater → die Vaeter : 아버지
* die Familie → die Familien : 가족
* helfen : 돕다
* wir : 우리
* was : 무엇
* das Wetter : 날씨

### l, r, j

> l은 [l], r은 [ʁ] 등으로 읽는다. j는 ja의 첫소리 [j].

* lesen : 읽다
* das Glueck : 행운, 행복
* das Herz → die Herzen : 심장, 마음
* trinken : 마시다
* ja : 네
* das Jahr → die Jahre : 해, 년

### ng, nk

> ng는 [ŋ], nk는 [ŋk]. ng에서는 g를 따로 읽지 않는다.

* eng : 좁은
* singen : 노래하다
* denken : 생각하다
* der Onkel → die Onkel : 삼촌

### ch

> echt·ich·Buecher·durch의 ch는 [ç]. Bach·Buch·doch의 ch는 [x].

* echt : 진짜의
* ich : 나
* das Buch → die Buecher : 책
* durch : ~을 통하여
* der Bach → die Baeche : 시내
* doch : 그렇지만; 부정 질문에 대한 ‘아니, 그래’

### chs

> chs는 [ks].

* sechs : 6
* der Fuchs → die Fuechse : 여우

### z, ts, tz

> z·ts·tz는 [ts].

* die Zeit → die Zeiten : 시간
* rechts : 오른쪽에
* jetzt : 지금
* die Katze → die Katzen : 고양이

### tsch, sch

> tsch는 [tʃ], sch는 [ʃ].

* Deutsch : 독일어 — 언어명으로는 보통 관사 없이 쓴다.
* tschues : 잘 가
* schoen : 아름다운, 좋은
* die Schule → die Schulen : 학교

### sp, st

> 단어·어간 첫머리의 sp는 [ʃp], st는 [ʃt].

* spielen : 놀다, 연주하다
* der Sport : 스포츠
* der Student → die Studenten : 남자 대학생
* stehen : 서 있다

## 강세

> 굵은 부분에 강세를 둔다.

### 첫 음절

> 아래 단어는 첫 음절에 강세가 온다.

* der **A**bend → die Abende : 저녁
* die **Ar**beit → die Arbeiten : 일
* der **Bru**der → die Brueder : 남자 형제
* die **El**tern : 부모 — 복수
* **Ham**burg : 함부르크
* der **Leh**rer → die Lehrer : 남자 교사
* die **Schu**le → die Schulen : 학교
* die **Son**ne → die Sonnen : 태양
* das **Wet**ter : 날씨
* **bit**ten : 부탁하다
* **hei**ssen : 이름이 ~이다
* **kom**men : 오다
* **le**ben : 살다
* **ma**chen : 하다
* **schwim**men : 수영하다
* **woh**nen : 거주하다
* **al**les : 모든 것
* **ger**ne : 기꺼이, 즐겨
* **heu**te : 오늘
* **im**mer : 항상
* **lei**der : 유감스럽게도
* **spae**ter : 나중에

### 뒤 음절

> 아래 단어는 첫 음절보다 뒤에 강세가 온다.

* Ber**lin** : 베를린
* das Ca**fé** → die Cafés : 카페
* die Mu**sik** : 음악
* moe**bliert** : 가구가 갖추어진

### 분리 접두사

> 아래 동사는 접두사에 강세가 온다.

* **ab**fahren : 출발하다
* **an**kommen : 도착하다
* **aus**steigen : 내리다
* **auf**fallen : 눈에 띄다
* **ein**schlafen : 잠들다
* **mit**fahren : 함께 타고 가다
* **vor**haben : 계획하다
* **zu**sagen : 승낙하다

### 비분리 접두사

> 아래 동사는 접두사 뒤의 어간에 강세가 온다.

* be**kom**men : 받다
* emp**feh**len : 추천하다
* ent**de**cken : 발견하다
* er**zaeh**len : 이야기하다
* ge**fal**len : 마음에 들다
* miss**brau**chen : 남용하다
* ver**ste**hen : 이해하다
* zer**stoe**ren : 파괴하다

### 강세 없는 접미사

> -heit·-keit·-lein·-ung·-er·-schaft·-bar·-haft·-ig·-isch·-lich는 보통 강세를 받지 않는다.

* die Ge**sund**heit : 건강
* die **Sau**berkeit : 청결
* das **Fraeu**lein → die Fraeulein : 아가씨라는 옛 호칭
* die **Prue**fung → die Pruefungen : 시험
* der **Leh**rer → die Lehrer : 교사
* die **Freund**schaft → die Freundschaften : 우정
* **wun**derbar : 멋진
* **zwei**felhaft : 의심스러운
* **flei**ssig : 부지런한
* **herz**lich : 진심 어린

### 강세 있는 접미사

> -ent·-ion·-taet·-ist·-ieren에는 강세가 온다.

* der Stu**dent** → die Studenten : 대학생
* die Na**tion** → die Nationen : 국가, 민족
* die Universi**taet** → die Universitaeten : 대학교
* der Pia**nist** → die Pianisten : 피아니스트
* stu**die**ren : 대학에서 공부하다
