## 1. 대화와 이름

교재 21–22쪽 · [21쪽](../../materials/textbook/KakaoTalk_20261012_104454803_06.jpg) · [22쪽](../../materials/textbook/KakaoTalk_20261012_104454803_07.jpg)

### 1.1. 안부

* Hana  : Hallo, Julia!
    * 안녕, 율리아! hallo = 가벼운 인사, Julia = 부르는 이름.
* Julia : Hallo, Hana! Wie geht es dir?
    * 안녕, 하나! 어떻게 지내?
    * gehen : 가다. 안부 표현에서는 ‘지내다’에 해당.
    * es = 형식적 주어 / geht = 3인칭 단수 / dir = du의 3격.
* Hana  : Danke. Mir geht es gut. Und dir?
    * 고마워. 잘 지내. 너는?
    * mir = ich의 3격. 문장 맨 앞이어도 주어는 es.
    * gut : 잘
    * Und dir? = 같은 질문의 생략형.
* Julia : Prima. Heute ist das Wetter sehr schön.
    * 좋아. 오늘 날씨가 아주 좋아.
    * prima      : 아주 좋은
    * heute      : 오늘
    * sehr       : 매우
    * schön      : 좋은, 아름다운.
    * das Wetter : 날씨. Heute / ist / das Wetter / sehr schön.
* Trinken wir einen Kaffee?
    * 우리 커피 한 잔 마실까?
    * trinken + 4격 / wir → trinken.
    * der Kaffee → einen Kaffee : 남성 단수 4격. 질문형 제안.
* Hana  : Gerne.
    * 좋아, 기꺼이. gerne = 제안을 받아들이는 부사.

---

### 1.2. 카페

* Bald finden sie ein Café.
    * 곧 두 사람은 카페 하나를 찾는다.
    * bald                 : 곧
    * finden               : 찾다
    * sie                  : 앞의 두 사람, 복수.
    * das Café → die Cafés : 카페. ein Café = 중성 4격.
* Julia : Die Sonne scheint.
    * 해가 비친다.
    * die Sonne → die Sonnen : 태양. 주어 1격.
    * scheinen → scheint     : 3인칭 단수.
* Nehmen wir hier draußen Platz?
    * 우리 여기 바깥에 앉을까?
    * nehmen → wir nehmen
    * hier                   : 여기
    * draußen                : 바깥에.
    * der Platz → die Plätze : 자리. Platz nehmen = 자리에 앉다, 무관사 관용구.
* Hana  : Ja, das Wetter ist heute wirklich schön.
    * 응, 오늘 날씨가 정말 좋아.
    * das Wetter = 주어
    * ist = 동사
    * wirklich : 정말
    * schön = 형용사 보어.
* Später machen wir einen Spaziergang im Englischen Garten.
    * 나중에 영국정원에서 산책하자.
    * später                             : 나중에
    * machen                             : 하다
    * wir = 주어.
    * der Spaziergang → die Spaziergänge : 산책. einen Spaziergang = 남성 4격.
    * der Garten → die Gärten            : 정원.
    * im = in dem → 장소 3격
    * im Englischen Garten               : 영국정원에서.
* Julia : Gute Idee. Hast du denn Zeit?
    * 좋은 생각이야. 그런데 시간 있어?
    * die Idee → die Ideen  : 생각. Gute Idee = 짧은 감탄 표현.
    * die Zeit → die Zeiten : 시간. haben + 4격, 여기서는 무관사 Zeit.
    * hast ← haben, du형
    * denn                  : 질문의 어감을 부드럽게 하는 말.
* Hana  : Ja, die Prüfung ist vorbei.
    * 응, 시험이 끝났어.
    * die Prüfung → die Prüfungen : 시험. 주어 1격.
    * vorbei sein                 : 끝나다, 지나가다. ist는 현재형.
* Ich habe jetzt viel Zeit.
    * 이제 시간이 많아.
    * ich → habe
    * jetzt : 지금
    * viel  : 많은.
    * viel Zeit = 4격 목적어. 시간의 양을 말하므로 무관사.
* Julia : Das ist gut.
    * 잘됐다.
    * Das = 앞 상황을 가리키는 대명사 / ist + gut.

---

### 1.3. 어휘 상자 전체 확인

* hallo           : 안녕
* gehen           : 가다
* danken          : 감사하다
* prima           : 아주 좋은
* das Wetter      : 날씨
* sehr            : 매우
* schön           : 아름다운, 좋은
* trinken         : 마시다
* bald            : 곧
* finden          : 찾다
* das Café        : 카페
* die Sonne       : 태양
* scheinen        : 비치다
* nehmen          : 잡다, 취하다
* hier            : 여기
* draußen         : 밖에
* der Platz       : 자리
* heute           : 오늘
* wirklich        : 정말
* später          : 나중에
* machen          : 하다
* der Spaziergang : 산책
* gut             : 좋은
* die Idee        : 생각
* haben           : 가지다
* denn            : 그런데, 질문의 어감
* die Zeit        : 시간
* die Prüfung     : 시험
* vorbei          : 끝난

* 사진 필기
    * eine Reise machen        : 여행하다.
    * die Reise → die Reisen   : 여행
    * eine Reise = 여성 4격.
    * einen Spaziergang machen : 산책하다    — 남성 4격.
    * eine Prüfung machen      : 시험을 보다 — 여성 4격.
    * Platz nehmen             : 자리에 앉다 — 이 표현에는 보통 관사를 넣지 않는다.

---

### 1.4. 22쪽 이름 문화

* der Vorname → die Vornamen : 이름, 성을 제외한 이름
* 독일어 이름에는 게르만·기독교 전통에서 온 이름과 외래 이름이 있다.
* 교재가 든 외래 이름 : Jennifer, Kevin, Nathalie, Marco.
* 아래 순위는 교재에 실린 출생연도별 자료다.
* 이름은 고유명사 → 일반 문장에서 정관사를 붙이지 않는다.

* 남자 1940년, 1–5위
    * Peter → Klaus/Claus → Hans → Jürgen → Dieter
* 남자 1970년, 1–5위
    * Stefan/Stephan → Michael → Andreas → Thomas → Frank
* 남자 1990년, 1–5위
    * Jan → Tobias → Christian → Alexander → Daniel
* 남자 2000년, 1–5위
    * Lucas/Lukas → Jan → Tim/Timm → Finn/Fynn → Leon

* 여자 1940년, 1–5위
    * Karin → Ingrid → Helga → Renate → Elke
* 여자 1970년, 1–5위
    * Nicole → Anja → Claudia → Stephanie/Stefanie → Andrea
    * 사진의 Stehphanie 표기는 Stephanie로 바로잡았다.
* 여자 1990년, 1–5위
    * Julia → Sarah/Sara → Jennifer → Katharina → Lisa
* 여자 2000년, 1–5위
    * Anna → Lea/Leah → Sarah/Sara → Hannah/Hanna → Michelle

* 교재는 중성적인 이름에 두 번째 이름을 붙이는 관행도 소개한다. 이는 교재의 문화 설명이며 현재의 이름 등록 요건을 정리한 법률 안내가 아니다.

## 2. 관사와 인칭대명사와 haben

교재 23–25쪽 · [23쪽](../../materials/textbook/KakaoTalk_20261012_104454803_07.jpg) · [24–25쪽](../../materials/textbook/KakaoTalk_20261012_104454803_08.jpg)

### 2.1. 네 격과 성

* N. = Nominativ : 1격 → 주어, sein 뒤 명사 보어.
* G. = Genitiv   : 2격 → 소유·관계 ‘~의’.
* D. = Dativ     : 3격 → 해당 동사·전치사가 요구하는 상대.
* A. = Akkusativ : 4격 → 해당 동사·전치사가 요구하는 대상.
* M. = 남성 / F. = 여성 / N. = 중성 / Pl. = 복수.
    * N.은 표의 위치에 따라 1격 또는 중성을 뜻한다.
* 명사는 첫 글자를 대문자로 쓴다.
* 한국어 조사만으로 격을 정하지 않고, 문장 속 역할과 동사를 확인한다.

---

### 2.2. 정관사 전체 → 1 / 2 / 3 / 4격 순서

* der Mann → die Männer : 남자
    * der Mann / des Mannes / dem Mann / den Mann
* die Frau → die Frauen : 여자
    * die Frau / der Frau / der Frau / die Frau
* das Kind → die Kinder : 아이
    * das Kind / des Kindes / dem Kind / das Kind
* 복수 die Kinder
    * die Kinder / der Kinder / den Kindern / die Kinder

* 남성·중성 단수 2격 → 대개 명사에도 -(e)s.
* 복수 3격 → 대개 명사에 -n. Kinder → Kindern.
* 성은 바뀌지 않는다. 여성 명사도 격에 따라 der Frau가 된다.

---

### 2.3. 정관사 예문 전체

* die Frau des Mannes
    * 그 남자의 아내. die Frau = 중심 명사 / des Mannes = 2격 수식.
* der Vater des Kindes
    * 그 아이의 아버지. der Vater / des Kindes = 중성 단수 2격.

* Der Mann ist groß.
    * 그 남자는 키가 크다. Der Mann = 1격 / ist + 형용사 groß.
* Die Frau ist schön.
    * 그 여자는 아름답다. Die Frau = 1격 / schön = 형용사 보어.
* Das Kind ist laut.
    * 그 아이는 시끄럽다. Das Kind = 1격 / laut = 시끄러운.
* Die Kinder spielen draußen.
    * 아이들이 밖에서 논다. Die Kinder = 복수 주어 / spielen = 복수 동사.
* Die Sonne scheint.
    * 해가 비친다. die Sonne = 여성 1격 / scheint = 3인칭 단수.
* Das Wetter ist heute wirklich schön.
    * 오늘 날씨가 정말 좋다. das Wetter = 중성 1격 / heute·wirklich = 부사.

* Ich kenne den Mann.
    * 나는 그 남자를 안다. kennen + 4격 → den Mann.
* Ich kenne die Frau.
    * 나는 그 여자를 안다. 여성 4격 → die Frau.
* Ich kenne das Kind.
    * 나는 그 아이를 안다. 중성 4격 → das Kind.
* Ich kenne die Kinder.
    * 나는 그 아이들을 안다. 복수 4격 → die Kinder.
* kennen : 알다
* ich kenne.

---

### 2.4. 부정관사 전체 → 1 / 2 / 3 / 4격

* 남성
    * ein Mann / eines Mannes / einem Mann / einen Mann
* 여성
    * eine Frau / einer Frau / einer Frau / eine Frau
* 중성
    * ein Kind / eines Kindes / einem Kind / ein Kind
* 복수 → ein의 복수형은 없다.

* Ein Mann kommt.
    * 한 남자가 온다. Ein Mann = 남성 1격 / kommt = 단수.
* Das ist eine Flasche.
    * 이것은 병이다. Das = 주어 / eine Flasche = 여성 1격 보어.
    * die Flasche → die Flaschen : 병.
* Das ist ein Café.
    * 이것은 카페다. ein Café = 중성 1격 보어.
* Trinken wir einen Kaffee?
    * 커피 한 잔 마실까? einen Kaffee = 남성 4격 목적어.
* Ich mache morgen eine Prüfung.
    * 나는 내일 시험을 본다. eine Prüfung = 여성 4격
    * morgen : 내일.
* Bald finden sie ein Café.
    * 곧 그들은 카페를 찾는다. ein Café = 중성 4격 / sie = 복수.
* Das sind Bücher.
    * 이것들은 책들이다. die Bücher = 복수 기본형, 불특정 복수는 무관사 Bücher.
    * sind는 복수 서술에 맞춘다.

---

### 2.5. kein

* ein → kein : 하나의 명사구를 부정한다.
* Ich mache morgen keine Prüfung.
    * 나는 내일 시험을 보지 않는다.
    * die Prüfung : 여성 4격 → keine Prüfung.
* Sie finden hier kein Café.
    * 그들은/당신은 여기서 카페를 찾지 못한다.
    * das Café : 중성 4격 → kein Café.
    * 문장 첫 Sie만으로 존칭인지 복수인지 확정하지 않는다.
* kein은 단수에서 ein처럼 변화하고 복수형도 있다.
    * 복수 1·4격 keine / 2격 keiner / 3격 keinen.

---

### 2.6. 인칭대명사 전체 → 1 / 2 / 3 / 4격

* 나   : ich / meiner / mir / mich
* 너   : du / deiner / dir / dich
* 그   : er / seiner / ihm / ihn
* 그녀 : sie / ihrer / ihr / sie
* 그것 : es / seiner / ihm / es
* 우리 : wir / unser / uns / uns
* 너희 : ihr / euer / euch / euch
* 그들 : sie / ihrer / ihnen / sie
* 존칭 : Sie / Ihrer / Ihnen / Sie
    * 명사 앞의 소유관사 Ihr와 인칭대명사 2격 Ihrer를 구별한다.
    * 2격 대명사는 이 단계의 일상 예문에서는 자주 쓰이지 않는다.

---

### 2.7. 안부 예문 전체

* Wie geht es dir?   — Mir geht es gut.
    * 어떻게 지내? — 잘 지내. dir·mir = 3격.
* Wie geht es Ihnen? — Es geht mir gut.
    * 어떻게 지내세요? — 잘 지냅니다. Ihnen = 존칭 3격.
* Wie geht es ihm?   — Es geht ihm gut.
    * 그는 어떻게 지내? — 잘 지내. ihm = er의 3격.
* Wie geht es ihr?   — Es geht ihr gut.
    * 그녀는 어떻게 지내? — 잘 지내. ihr = sie의 3격.
* Mir geht es gut. = Es geht mir gut.
    * 앞에 오는 성분은 달라도 주어는 es, 동사는 geht.

---

### 2.8. haben 전체 현재형

* haben : 가지다, ~이 있다
    * ich habe / du hast / er hat / sie hat / es hat
    * wir haben / ihr habt / sie haben / Sie haben
* Hast du denn Zeit?  — Ja, ich habe jetzt viel Zeit.
    * 시간 있니? — 응, 지금 시간이 많아.
    * du → hast / ich → habe / viel Zeit = 4격 목적어.
* Habt ihr denn Zeit? — Ja, wir haben jetzt viel Zeit.
    * 너희 시간 있니? — 응, 우리 지금 시간이 많아.
    * ihr → habt / wir → haben.
* Er/sie hat jetzt keine Zeit.
    * 그/그녀는 지금 시간이 없다. er·sie 단수 → hat.
    * die Zeit = 여성 4격 목적어 → keine Zeit로 부정.
* Sie haben jetzt viel Zeit.
    * 그들/당신은 지금 시간이 많다. 복수·존칭 → haben.

## 3. 옷과 색깔

교재 28쪽 · [원본](../../materials/textbook/KakaoTalk_20261012_104454803_10.jpg)

### 3.1. 옷과 소지품 전체

* das Hemd → die Hemden          : 셔츠
* die Bluse → die Blusen         : 블라우스
* die Jacke → die Jacken         : 재킷
* der Rock → die Röcke           : 치마
* die Tasche → die Taschen       : 가방
* die Lederhose → die Lederhosen : 가죽 바지
* die Brille → die Brillen       : 안경
* die Mütze → die Mützen         : 모자
* der Rucksack → die Rucksäcke   : 배낭
* die Socke → die Socken         : 양말
* die Kleidung                   : 의복 — 일반적인 옷 전체를 가리킬 때 단수 집합명사.
    * 교재 표 제목은 Kleidungen. 보통 ‘옷’은 die Kleidung으로 외운다.
* das Foto → die Fotos           : 사진 — 교재 표의 Fotos.

---

### 3.2. 색깔 전체

* weiß    : 흰색의
* schwarz : 검은색의
* grau    : 회색의
* blau    : 파란색의
* grün    : 초록색의
* gelb    : 노란색의
* braun   : 갈색의
* 색을 서술하는 형용사 → sein 뒤에서는 어미를 붙이지 않는다.

---

### 3.3. 교재 예문 전체

* Er trägt einen Rucksack.
    * 그는 배낭을 메고 있다.
    * tragen                        : 입다, 착용하다, 들고 있다.
    * er → trägt                    : a → ä.
    * der Rucksack → einen Rucksack : 남성 4격 목적어.
* Der Rucksack ist schwarz.
    * 그 배낭은 검은색이다.
    * Der Rucksack = 남성 1격 주어 / ist + 색 형용사.
    * 처음 ein으로 소개한 배낭을 다음 문장에서는 der로 특정한다.
* Sie trägt eine Jacke.
    * 그녀는 재킷을 입고 있다.
    * sie 단수 → trägt / die Jacke → eine Jacke, 여성 4격.
* Die Jacke ist blau.
    * 그 재킷은 파란색이다.
    * Die Jacke = 여성 1격 / blau = 형용사 보어.

---

### 3.4. 격에 따라 쓰는 관사

* 남성
    * der Rock → einen Rock
    * der Rucksack → einen Rucksack
* 여성
    * die Bluse → eine Bluse / die Jacke → eine Jacke
    * die Tasche → eine Tasche / die Lederhose → eine Lederhose
    * die Brille → eine Brille / die Mütze → eine Mütze
    * die Socke → eine Socke
* 중성
    * das Hemd → ein Hemd
* 복수
    * die Socken → Socken : 불특정 양말들이면 ein의 복수 관사 없음.
