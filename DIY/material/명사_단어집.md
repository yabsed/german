# 명사 단어집

교재 사진 9–13, 15–33, 37–41쪽의 본문·발음 예시·문제·제목과 읽을 수 있는 필기에 나온 명사. 37–41쪽은 [5과 자료](5.md), 49–52쪽과 맞은편 어휘 상자의 보이는 부분은 [7과 자료](7.md)를 반영했다. 7과에서 추가한 어휘는 연습문제 영역을 제외한다.

* 외우는 순서 → 정관사 + 단수 → 정관사 + 복수 → 뜻.
* 정관사는 사전형인 1격 기준. 문장에서는 성·수·격에 맞춰 바꾼다.
* ‘보통 단수’는 이 뜻에서 일상적으로 복수를 잘 쓰지 않는다는 뜻.
* ‘복수’ 표시는 해당 뜻으로 복수형을 사용하는 단어.
* 복수형·뜻·변화 주의점은 교재 어휘의 학습을 위한 보충 분석이다.

## 12. 문장에 넣을 때 확인

* 남성·중성 2격 → 대개 -(e)s
    * der Mann → des Mannes / das Kind → des Kindes.
* 복수 3격 → 대개 -n
    * die Kinder → den Kindern / die Brüder → den Brüdern.
    * 이미 -n으로 끝나거나 -s 복수인 경우는 보통 추가하지 않는다.
* 약변화 남성 명사 → 단수 2·3·4격에 -(e)n
    * der Student → des/dem/den Studenten.
    * der Junge → des/dem/den Jungen.
    * der Bär → des/dem/den Bären.
    * der Architekt → des/dem/den Architekten.
    * der Pianist → des/dem/den Pianisten.
    * der Herr → des/dem/den Herrn; 복수는 die Herren.
* der Name → des Namens / dem Namen / den Namen.
* 이름·도시·대부분의 나라명에는 정관사를 억지로 붙이지 않는다.
    * Berlin, Korea, Deutschland 등은 [기타 단어집](기타_단어집.md).
