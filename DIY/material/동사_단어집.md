# 동사 단어집

교재 사진 9–13, 15–33, 37–41, 49–52쪽과 52쪽 맞은편 어휘 상자의 보이는 부분에 나온 동사를 기본형으로 모았다. 현재형·목적어의 격·분리 접두사는 해당 단어의 분석이다. 추가 자료의 문장 분석은 [5과](5.md), [7과](7.md)에서 확인한다. 7과의 연습문제 영역은 제외했다.

* 전체형의 순서 → ich / du / er·sie·es / wir / ihr / sie·Sie.
* 단어가 발음 예시에만 나와도 포함한다.
* 3격·4격 표시는 이 교재 문맥 또는 함께 적은 뜻의 결합을 나타낸다.

---

## 1. 대화의 기본 동사

* sein      : ~이다, 있다
    * bin / bist / ist / sind / seid / sind
    * 주어 1격 + sein + 명사 보어 1격 또는 형용사.
* haben     : 가지다, ~이 있다
    * habe / hast / hat / haben / habt / haben
    * haben + 4격. haben Zeit / Geschwister / einen Bruder.
* kommen    : 오다
    * komme / kommst / kommt / kommen / kommt / kommen
    * aus + 출신 / nach + 도시 방향.
* heißen    : 이름이 ~이다
    * heiße / heißt / heißt / heißen / heißt / heißen
    * du에서도 heißt. heißt가 두 번 나오는 것이 맞다.
* wohnen    : 거주하다
    * wohne / wohnst / wohnt / wohnen / wohnt / wohnen
    * in + 장소 3격. wo로 묻는다. In jenem Haus wohnt niemand.
* studieren : 대학에서 공부하다, 전공하다
    * studiere / studierst / studiert / studieren / studiert / studieren
    * -ieren은 현재형에서 규칙적인 어미, 강세는 -ier-.
* machen    : 하다, 만들다
    * mache / machst / macht / machen / macht / machen
    * 4격 → eine Prüfung / einen Spaziergang.
    * Das macht nichts. : 괜찮아, 상관없어 — 5과 대화.
* gehen     : 가다
    * gehe / gehst / geht / gehen / geht / gehen
    * Wie geht es + 사람 3격? → 안부.
    * 방향 → in + 4격 : in den Park / ins Kino. ins = in das.
* danken    : 감사하다
    * danke / dankst / dankt / danken / dankt / danken
    * 감사받는 사람 3격. Danke는 독립적인 감사 인사로도 쓴다.
* trinken   : 마시다
    * trinke / trinkst / trinkt / trinken / trinkt / trinken
    * 4격 → einen Kaffee / einen Tee.
* finden    : 찾다
    * finde / findest / findet / finden / findet / finden
    * 4격 → ein Café. 어간 -d 뒤의 du·er·ihr에 e.
* scheinen  : 빛나다, 비치다
    * scheine / scheinst / scheint / scheinen / scheint / scheinen
    * Die Sonne scheint.
* nehmen    : 잡다, 취하다
    * nehme / nimmst / nimmt / nehmen / nehmt / nehmen
    * du·er → nimm-. Platz nehmen : 자리에 앉다.
* kennen    : 알다, 알고 지내다
    * kenne / kennst / kennt / kennen / kennt / kennen
    * 4격 → den Mann / die Frau / das Kind / die Kinder.
* spielen   : 놀다, 연주하다
    * spiele / spielst / spielt / spielen / spielt / spielen
    * spielen draußen / Klavier spielen.
    * 7과 : Tennis spielen / Schach spielen. 운동·놀이 이름 앞에는 보통 관사를 쓰지 않는다.

## 2. 가족과 옷

* tragen    : 입다, 착용하다, 들다
    * trage / trägst / trägt / tragen / tragt / tragen
    * 4격 → einen Rucksack / eine Jacke.
* sitzen    : 앉아 있다
    * sitze / sitzt / sitzt / sitzen / sitzt / sitzen
    * du에서 sitzst가 아니라 sitzt. 위치 → auf einer Bank.
* reden     : 말하다, 이야기하다
    * rede / redest / redet / reden / redet / reden
    * reden über + 4격 → über ihre Familien.
* besuchen  : 방문하다
    * besuche / besuchst / besucht / besuchen / besucht / besuchen
    * 4격 → sie / meine Eltern. be-는 분리하지 않는다.
* leben     : 살다, 살아 있다
    * lebe / lebst / lebt / leben / lebt / leben
    * leben auf dem Land / lebt noch.
* treiben   : 몰다; Sport treiben으로 운동하다
    * treibe / treibst / treibt / treiben / treibt / treiben
    * Sport treiben : 운동하다. Sport는 4격, 보통 무관사.
* vermissen : 그리워하다
    * vermisse / vermisst / vermisst / vermissen / vermisst / vermissen
    * 4격 → meinen Bruder / sie.
* fehlen    : 없다, 부족하다; 그립다
    * fehle / fehlst / fehlt / fehlen / fehlt / fehlen
    * 그리운 대상이 주어, 그리움을 느끼는 사람이 3격.
    * Sie fehlen mir. → Sie 복수 주어, mir 3격.
* lieben    : 사랑하다
    * liebe / liebst / liebt / lieben / liebt / lieben
    * 4격 → meine Großmutter / mein Kind.
* schreiben : 쓰다
    * schreibe / schreibst / schreibt / schreiben / schreibt / schreiben
    * 교재에서는 der Schreibtisch의 구성 요소 schreib-로도 등장.

    * bitte / bittest / bittet / bitten / bittet / bitten
    * -t 뒤에 발음을 돕는 e.
* schwimmen : 수영하다

* geben     : 주다
    * gebe / gibst / gibt / geben / gebt / geben

* holen     : 가져오다, 데려오다
    * hole / holst / holt / holen / holt / holen
* sagen     : 말하다
    * sage / sagst / sagt / sagen / sagt / sagen
* sprechen  : 말하다
    * spreche / sprichst / spricht / sprechen / sprecht / sprechen
    * sprechen über + 4격 → Sie sprechen über ihre Hobbys. — 7과 도입.

## 4. 접두사 강세 예시

* 분리동사 → 교재의 굵은 접두사에 강세. 단순 현재 평서문에서는 접두사가 끝으로 간다.
    * abfahren    : 출발하다 → er fährt … ab
    * ankommen    : 도착하다 → er kommt … an
        * komme … an / kommst … an / kommt … an / kommen … an / kommt … an / kommen … an
        * Der Zug kommt bald an. — 7과 문법 예문.
    * aussteigen  : 내리다 → er steigt … aus
    * auffallen   : 눈에 띄다 → er fällt … auf
    * einschlafen : 잠들다 → er schläft … ein
    * mitfahren   : 함께 타고 가다 → er fährt … mit
    * vorhaben    : 계획하다 → er hat … vor
        * habe … vor / hast … vor / hat … vor / haben … vor / habt … vor / haben … vor
        * Was hast du am Wochenende vor? — 7과 대화.
    * zusagen     : 승낙하다 → er sagt … zu
* 위의 …는 문장 틀을 표시한 것이며 교재의 별도 완성 문장이 아니다.

* 비분리동사 → 접두사를 떼지 않는다.
    * bekommen     : 받다 → ich bekomme / du bekommst / er bekommt
    * empfehlen    : 추천하다 → ich empfehle / du empfiehlst / er empfiehlt
    * entdecken    : 발견하다 → ich entdecke / du entdeckst / er entdeckt
    * erzählen     : 이야기하다 → ich erzähle / du erzählst / er erzählt
    * gefallen     : 마음에 들다 → gefalle / gefällst / gefällt / gefallen / gefallt / gefallen
        * 마음에 드는 대상 1격 + gefallen + 사람 3격 → Die Wohnung gefällt mir.
        * 5과에서 격지배·불규칙 현재형으로 다시 등장. ge-를 분리하지 않는다.
    * missbrauchen : 남용하다 → ich missbrauche / du missbrauchst / er missbraucht
    * verstehen    : 이해하다 → ich verstehe / du verstehst / er versteht
    * zerstören    : 파괴하다 → ich zerstöre / du zerstörst / er zerstört

## 6. 집 구하기와 가구 배치

5과 37–41쪽의 새 동사. 앞에 나온 helfen·gefallen·geben·fallen·fahren·sehen·lesen·stehen 등의 기존 항목도 5과 문맥과 함께 확인한다.

* suchen : 찾다, 구하다
    * suche / suchst / sucht / suchen / sucht / suchen
    * 4격 → eine Wohnung / dich. suchen은 찾는 과정, finden은 찾아내는 뜻.
* treffen : 만나다
    * treffe / triffst / trifft / treffen / trefft / treffen
    * 4격 → den Vermieter. du·er에서 e → i.
* beschreiben : 묘사하다, 설명하다
    * beschreibe / beschreibst / beschreibt / beschreiben / beschreibt / beschreiben
    * 사람 3격 + 대상 4격 → Er beschreibt Hana die Wohnung. be-는 분리하지 않는다.
* möblieren : 가구를 비치하다
    * möbliere / möblierst / möbliert / möblieren / möbliert / möblieren
    * 대상 4격. sein + möbliert는 가구가 갖추어진 상태 → Das Zimmer ist möbliert.
* aussehen : ~처럼 보이다, 생김새가 ~하다
    * sehe … aus / siehst … aus / sieht … aus / sehen … aus / seht … aus / sehen … aus
    * 분리동사 aus + sehen → Wie sieht das Zimmer aus? du·er에서 e → ie.
* liegen : 놓여 있다, 누워 있다, 위치하다
    * liege / liegst / liegt / liegen / liegt / liegen
    * 위치 → auf dem Sofa / neben dem Badezimmer. 무엇을 놓는 동작 legen과 구별.
* legen : 눕혀 놓다
    * lege / legst / legt / legen / legt / legen
    * 대상 4격 + 목표 위치 → Sie legt das Buch auf das Sofa.
    * auf das Sofa도 목표를 나타내는 전치사구라 4격이다.
* stellen : 세워 놓다
    * stelle / stellst / stellt / stellen / stellt / stellen
    * 대상 4격 + 목표 위치 → Ich stelle die Flasche auf den Tisch.
* hängen : 걸려 있다
    * hänge / hängst / hängt / hängen / hängt / hängen
    * 5과에서는 걸려 있는 상태 + 위치 3격 → Das Bild hängt an der Wand.
    * hängen은 ‘~을 걸다’라는 뜻으로도 쓰인다. 여기의 현재형에 움라우트를 더하지 않는다.
* essen : 먹다
    * esse / isst / isst / essen / esst / essen
    * 4격. du·er의 isst는 sein의 ist와 철자가 다르다 — 40쪽 추가 활용 예시.
* mögen : 좋아하다
    * mag / magst / mag / mögen / mögt / mögen
    * 4격. 37쪽 사진 필기의 동사.
    * möchte / möchtest / möchte / möchten / möchtet / möchten : ~하고 싶다.
    * möchte는 mögen의 접속법 2식. 교재는 möchten을 어휘 표제어로 제시한다.
    * 현재의 희망 + 문장 끝 동사원형 → Ich möchte ein Regal an die Wand stellen.
    * 7과에서는 추측의 화법조동사로도 등장 → Er mag jetzt in Köln sein. : 그는 지금 쾰른에 있을지도 모른다.
    * 7과 대화 Ich möchte gern mitkommen.은 함께 가고 싶다는 희망. [7과 mögen과 möchte](7.md#34-mögen과-möchte) 참고.
* vermieten : 임대하다, 세를 놓다
    * vermiete / vermietest / vermietet / vermieten / vermietet / vermieten
    * 대상 4격. ver-는 분리하지 않는다 — 37쪽 사진 필기.
* fragen : 묻다
    * frage / fragst / fragt / fragen / fragt / fragen
    * 묻는 상대 4격 → Ich frage dich. — 40쪽 사진 필기.
* ziehen : 당기다; 이사하다
    * ziehe / ziehst / zieht / ziehen / zieht / ziehen
    * 41쪽 연습문제에서 이사하는 뜻으로 등장. 방향 표현과 함께 쓴다.

## 7. 취미와 화법조동사

7과의 새 동사. 기존 항목의 sprechen·hören·spielen·arbeiten·vorhaben·ankommen·mögen도 7과 문맥을 반영했다. 여섯 화법조동사의 비교표는 [7과 현재인칭변화](7.md#31-현재인칭변화-전체)에서 확인한다.

* fernsehen : 텔레비전을 보다
    * sehe … fern / siehst … fern / sieht … fern / sehen … fern / seht … fern / sehen … fern
    * 분리동사 fern + sehen. du·er에서 e → ie.
    * Ich sehe heute fern. / Ich will heute fernsehen. 원형은 붙여 쓴다.
* laufen : 달리다, 뛰다; 공연·상영되다
    * laufe / läufst / läuft / laufen / lauft / laufen
    * du·er에서 au → äu. 7과 대화에서는 연극이 공연된다는 뜻 → Im Theater läuft … „Wilhelm Tell“.
* mitkommen : 함께 오다, 동행하다
    * komme … mit / kommst … mit / kommt … mit / kommen … mit / kommt … mit / kommen … mit
    * 분리동사 mit + kommen → Kommst du mit? 문맥에 따라 ‘같이 갈래?’.
    * 화법조동사 뒤에서는 원형 → Ich möchte gern mitkommen.
* sammeln : 모으다, 수집하다
    * sammle / sammelst / sammelt / sammeln / sammelt / sammeln
    * 4격 → Briefmarken und Sondermünzen. 교재 ich형은 sammle.
* können : ~할 수 있다
    * kann / kannst / kann / können / könnt / können
    * 능력·가능 + 문장 끝 동사원형 → Du kannst es nicht ändern.
* müssen : ~해야 하다
    * muss / musst / muss / müssen / müsst / müssen
    * 의무·필요 + 동사원형. nicht müssen은 ‘~할 필요가 없다’.
    * Du musst hier nicht bleiben. : 여기 머물지 않아도 된다.
* dürfen : ~해도 된다
    * darf / darfst / darf / dürfen / dürft / dürfen
    * 허가 + 동사원형. nicht dürfen은 ‘~하면 안 된다’.
    * Du darfst hier nicht rauchen. : 여기서 담배를 피우면 안 된다.
* wollen : ~하려고 하다, 원하다
    * will / willst / will / wollen / wollt / wollen
    * 의지 + 동사원형 → Ich will ins Theater gehen.
    * Wollen wir …?는 함께 하자는 제안에도 쓴다.
* sollen : ~해야 한다; ~라고 한다
    * soll / sollst / soll / sollen / sollt / sollen
    * 요구·당위 → Du sollst deine Eltern ehren.
    * 전해 들은 말 → Das Restaurant soll sehr gut sein.
* bleiben : 머무르다, 남다
    * bleibe / bleibst / bleibt / bleiben / bleibt / bleiben
    * hier bleiben : 여기에 머무르다. Du musst hier nicht bleiben.
* rauchen : 담배를 피우다
    * rauche / rauchst / raucht / rauchen / raucht / rauchen
    * Du darfst hier nicht rauchen.에서 dürfen의 금지 의미와 함께 쓴다.
* ehren : 공경하다, 존경하다
    * ehre / ehrst / ehrt / ehren / ehrt / ehren
    * 4격 → deine Eltern. ‘가르치다’ lehren과 구별한다.
* ändern : 바꾸다, 변경하다
    * ändere / änderst / ändert / ändern / ändert / ändern
    * 4격 → es. Du kannst es nicht ändern.
* besichtigen : 관람하다, 둘러보다
    * besichtige / besichtigst / besichtigt / besichtigen / besichtigt / besichtigen
    * 4격 → das Schloss. be-는 비분리 접두사.
