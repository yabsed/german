교재 사진 9–13, 15–33, 37–41, 49–52쪽과 52쪽 맞은편 어휘 상자의 보이는 부분 중 명사·동사 이외 어휘. 활용형은 기본형과 연결하고, 이름은 정관사를 붙이지 않는다. 추가 자료의 문장 분석은 [5과](5.md), [7과](7.md)에서 확인한다. 7과의 연습문제 영역은 제외했다.

## 5. 전치사와 축약형

* aus + 3격   : ~로부터, ~출신 — aus Korea
* von + 3격   : ~로부터, ~의   — von Beruf; 7과에서는 von Friedrich Schiller로 작품의 작가를 표시
* zu + 3격    : ~로, ~에      — 7과 zur Zeit의 zur = zu der
* nach + 3격  : ~로, ~후에     — nach Berlin
* bei + 3격   : ~에서, ~할 때  — bei der Wohnungssuche / bei der Hausarbeit
* in          : ~안에, ~에서
    * 위치 3격 : in der Nähe, im Café, in seinem Zimmer.
    * 목표·방향 4격 : in den Park, ins Kino.
    * 7과 : im Theater(극장에서, 3격) ↔ ins Theater / ins Konzert(극장·연주회로, 4격).
    * im = in dem(3격) / ins = in das(4격).
* auf         : ~위에
    * 위치 3격 : auf einer Bank, auf dem Land, auf dem Sofa.
    * 목표·방향 4격 : auf das Sofa, auf den Tisch. aufs = auf das.
    * Auf Wiedersehen은 고정된 작별 인사로 따로 외운다.
* an          : ~에 붙어, ~가에
    * 위치 3격 : an der Wand, am Fenster. am = an dem.
    * 목표·방향 4격 : ein Regal an die Wand stellen.
    * 시간 3격 : am Wochenende = an dem Wochenende, 주말에.
* vor         : ~앞에          — vor dem Fenster, 위치 3격.
* hinter      : ~뒤에          — hinter der Tür, 위치 3격.
* neben       : ~옆에          — neben dem Bett, 위치 3격.
* über        : ~위쪽에; ~에 관해
    * 위치 3격 : über dem Tisch.
    * reden über + 4격 : über ihre Familien.
    * sprechen über + 4격 : über ihre Hobbys — 7과 도입.
* unter       : ~아래에        — unter dem Baum, 위치 3격.
* zwischen    : ~사이에        — zwischen meiner Mutter und meinem Vater, 둘 다 3격.
* durch + 4격 : ~을 통하여     — 발음 예시.
* pro         : ~마다          — pro Woche.
* an, auf, in, vor, hinter, neben, über, unter, zwischen은 공간 표현에서 위치(wo) 3격 / 목표·방향(wohin) 4격을 구별한다. [5과 전치사](5.md#2-장소와-방향의-전치사)에서 예문을 비교한다.

## 6. 관사와 대명사

* 정관사 기본형   : der / die / das.
* 정관사 변화형   : der, die, das, des, dem, den.
* 부정관사 변화형 : ein, eine, eines, einer, einem, einen.
* 부정관사 ein에는 복수형이 없다.
* 부정형          : kein, keine, keines, keiner, keinem, keinen.
* 인칭대명사 1격
    * ich, du, er, sie, es, wir, ihr, sie, Sie.
* 인칭대명사 2격
    * meiner, deiner, seiner, ihrer, seiner, unser, euer, ihrer, Ihrer.
* 인칭대명사 3격
    * mir, dir, ihm, ihr, ihm, uns, euch, ihnen, Ihnen.
* 인칭대명사 4격
    * mich, dich, ihn, sie, es, uns, euch, sie, Sie.
* 소유관사 어간
    * mein, dein, sein, ihr, sein, unser, euer, ihr, Ihr.
* 자세한 격 분석 → [3과 관사·대명사](3.md#2-관사와-인칭대명사와-haben), [4과 소유관사](4.md#2-소유관사).
* das             : 정관사일 수도, ‘이것/그것’이라는 대명사일 수도 있다.
* solch           : 그러한 — 발음 예시의 한정 표현.
* dies-           : 이, 이것 — dieser / diese / dieses 등. 뒤 명사의 성·수·격에 맞춰 변화.
* jen-            : 저, 저것 — jener / jene / jenes 등. in jenem Haus는 중성 3격.
* dies-·jen-의 전체 변화와 예문 → [5과 지시 표현](5.md#5-지시-표현-dies-와-jen-).
* jemand          : 누군가 — 40쪽 사진 필기. jemandem은 3격, 교재 약자 jm.
* niemand         : 아무도 ~않다 — In jenem Haus wohnt niemand. 주어일 때 3인칭 단수.
* nichts          : 아무것도 ~않다 — Das macht nichts. kein·nicht와 쓰임을 구별한다.
* jeder           : 각각의, 매~ — 7과 jeden Morgen / jeden Tag / jeden Monat의 jeden은 남성 4격.
