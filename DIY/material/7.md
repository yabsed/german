## 1. 취미와 주말 계획 대화

교재 49–50쪽 · [49쪽 대화](../../materials/textbook-7/KakaoTalk_20261029_145235466.jpg) · [50쪽 어휘·문화](../../materials/textbook-7/KakaoTalk_20261029_145235466_01.jpg)

### 1.1. 도입 문장

* Julia und Hana sitzen auf dem Sofa und sehen zusammen fern.
    * 율리아와 하나는 소파에 앉아 함께 텔레비전을 보고 있다.
    * Julia und Hana = 복수 주어 → sitzen / sehen.
    * sitzen : 앉아 있다 / auf dem Sofa = 위치, auf + 중성 3격.
    * das Sofa → die Sofas : 소파.
    * fernsehen : 텔레비전을 보다. 분리동사 fern + sehen → sehen … fern.
    * zusammen : 함께. und 뒤에서도 같은 주어이므로 주어를 반복하지 않는다.
* Sie sprechen über ihre Hobbys.
    * 두 사람은 자기들의 취미에 관해 이야기한다.
    * Sie = 앞의 두 사람, 복수 주어 → sprechen.
    * sprechen über + 4격 : ~에 관해 이야기하다.
    * das Hobby → die Hobbys : 취미. ihre Hobbys = 그들의 취미들, 복수 4격.

---

### 1.2. 주말 계획과 연극

* Julia : Hana, was hast du am Wochenende vor?
    * 하나야, 주말에 무슨 계획이 있어?
    * vorhaben : 계획하다. 분리동사 vor + haben → du hast … vor.
    * was = 계획의 내용을 묻는 4격 의문대명사 / du = 주어.
    * das Wochenende → die Wochenenden : 주말.
    * am Wochenende = an dem Wochenende, 중성 3격의 시간 표현.
* Hana : Ich will ins Theater gehen.
    * 나는 극장에 가려고 해.
    * wollen : ~하려고 하다, 원하다 → ich will.
    * 화법조동사 will을 활용하고 본동사 gehen은 원형으로 문장 끝에 둔다.
    * das Theater → die Theater : 극장, 연극.
    * ins Theater = in das Theater, 중성 4격의 목적지.
* Im Theater läuft zur Zeit „Wilhelm Tell“ von Friedrich Schiller.
    * 극장에서는 지금 프리드리히 실러의 「빌헬름 텔」이 공연 중이야.
    * Im Theater = in dem Theater, 중성 3격의 장소.
    * laufen : 달리다; 여기서는 연극이 공연되다 → läuft.
    * 주어는 작품 제목 „Wilhelm Tell“ → 단수 동사 läuft.
    * Im Theater / läuft / zur Zeit / „Wilhelm Tell“ von Friedrich Schiller.
    * zur Zeit : 현재, 지금. 교재 표기를 유지했다. zur = zu der, Zeit는 여성 명사.
    * von + 3격 : ~의, ~가 만든. 여기서는 작품의 작가를 나타낸다.
* Kommst du mit?
    * 같이 갈래?
    * mitkommen : 함께 오다, 동행하다 → du kommst … mit.
    * 의문사 없는 질문 → Kommst / du / mit? 분리된 mit는 문장 끝.

---

### 1.3. 함께 가고 싶지만 일해야 할 때

* Julia : Ich möchte gern mitkommen.
    * 나도 같이 가고 싶어.
    * möchte : ~하고 싶다 / gern : 기꺼이, 즐겨.
    * ich → möchte / mitkommen은 문장 끝의 동사원형이라 붙여 쓴다.
    * Kommst du mit?의 분리 형태와 möchte … mitkommen을 비교한다.
* Aber ich muss leider am Wochenende die ganze Zeit arbeiten.
    * 하지만 안타깝게도 주말 내내 일해야 해.
    * müssen : ~해야 하다 → ich muss / arbeiten : 일하다.
    * aber는 앞 문장과 연결하는 접속사. Aber / ich / muss / … / arbeiten.
    * leider : 유감스럽게도 / am Wochenende : 주말에.
    * die Zeit → die Zeiten : 시간 / ganz : 전체의.
    * die ganze Zeit = 내내, 줄곧. 지속 시간을 나타내는 여성 4격 부사구이며 목적어가 아니다.

---

### 1.4. 평소 주말에 하는 일

* Hana : Was machst du normalerweise am Wochenende?
    * 너는 보통 주말에 무엇을 하니?
    * normalerweise : 보통, 일반적으로 / machen → du machst.
    * Was / machst / du / normalerweise / am Wochenende?
* Julia : Ich besuche oft meine Eltern.
    * 나는 부모님을 자주 찾아뵈어.
    * besuchen + 4격 : 방문하다 → ich besuche.
    * die Eltern : 부모, 복수. meine Eltern = 복수 4격 목적어.
    * oft : 자주. be-는 분리하지 않는다.
* Sonst spiele ich gerne Tennis.
    * 그 밖에는 테니스를 즐겨 쳐.
    * sonst : 그 밖에는, 그 외에는 / gerne = gern.
    * das Tennis : 테니스, 복수 없이 사용. Tennis spielen은 보통 무관사 표현.
    * Sonst / spiele / ich / gerne / Tennis. sonst가 앞에 와서 주어 ich는 동사 뒤.
* Ab und zu spiele ich auch Schach.
    * 가끔은 체스도 둬.
    * ab und zu : 이따금, 가끔. 세 단어가 하나의 시간 부사어를 이룬다.
    * Ab und zu / spiele / ich / auch / Schach.
    * das Schach : 체스. Schach spielen도 보통 관사 없이 쓴다.
* Und was sind deine Hobbys?
    * 그리고 네 취미는 뭐야?
    * deine Hobbys = 복수 주어 → sind. 취미 하나를 묻는 ist와 구별한다.
    * dein-은 du의 소유관사. 여기서는 복수 1격 → deine.

---

### 1.5. 수집과 음악 감상

* Hana : Ich sammle Briefmarken und Sondermünzen.
    * 나는 우표와 기념주화를 모아.
    * sammeln + 4격 : 모으다, 수집하다 → ich sammle.
    * -eln 동사의 ich형에서는 어간의 e가 빠지는 형태를 쓴다 → sammeln → sammle.
    * die Briefmarke → die Briefmarken : 우표.
    * die Sondermünze → die Sondermünzen : 기념주화.
    * Briefmarken과 Sondermünzen은 모두 관사 없는 복수 4격 목적어.
* Ich höre auch gern Musik.
    * 음악 듣는 것도 좋아해.
    * hören + 4격 : 듣다 → ich höre.
    * die Musik : 음악, 보통 단수. Musik hören에서는 관사를 생략한다.
    * gern + 동사 : ~하는 것을 좋아하다. hören 자체의 뜻은 ‘듣다’이다.
* Wollen wir irgendwann zusammen ins Konzert gehen?
    * 우리 언젠가 함께 연주회에 갈까?
    * wollen → wir wollen. Wollen wir …?는 함께 하자고 제안하는 질문.
    * irgendwann : 언젠가 / zusammen : 함께.
    * das Konzert → die Konzerte : 연주회, 콘서트.
    * ins Konzert = in das Konzert, 중성 4격의 목적지.
    * Wollen / wir / irgendwann zusammen ins Konzert / gehen? 원형 gehen은 끝.
* Julia : Ja, gerne.
    * 응, 좋아.
    * gerne는 제안에 기꺼이 응한다는 짧은 대답으로도 쓴다.

### 1.6. 49–50쪽 어휘 상자 전체

* fernsehen : 텔레비전을 보다 / sprechen : 말하다, 이야기하다.
* das Hobby → die Hobbys : 취미 / vorhaben : 계획하다.
* das Wochenende → die Wochenenden : 주말.
    * die Woche → die Wochen : 주 / das Ende → die Enden : 끝.
    * Woche + Ende → Wochenende. 마지막 구성 명사 Ende의 성을 따라 중성.
* das Theater → die Theater : 극장, 연극.
* laufen : 달리다, 뛰다; 공연·상영되다 / mitkommen : 함께 가다, 오다.
* ganz : 전체의 / arbeiten : 일하다, 공부하다.
* normalerweise : 보통, 일반적으로. 어휘 설명이 49쪽에서 50쪽으로 이어진다.
* oft : 자주 / sammeln : 모으다, 수집하다.
* das Schach : 체스. 교재의 한국어 풀이 ‘장기’는 여기서 ‘체스’로 풀어 쓴다.
    * 교재는 복수 die Schachs도 제시한다. 놀이 이름으로 쓰는 이 대화에서는 복수를 쓰지 않는다. [Duden의 뜻별 설명](https://www.duden.de/rechtschreibung/Schach) 참고.
* die Briefmarke → die Briefmarken : 우표.
    * der Brief → die Briefe : 편지 / die Marke → die Marken : 표, 상표.
    * Brief + Marke → Briefmarke. 마지막 명사 Marke를 따라 여성.
* die Sondermünze → die Sondermünzen : 기념주화.
* hören : 듣다 / irgendwann : 언젠가.
* das Konzert → die Konzerte : 연주회, 콘서트.

## 2. 주말농장 문화

교재 50쪽 · [원본](../../materials/textbook-7/KakaoTalk_20261029_145235466_01.jpg)

* 교재는 정원 가꾸기를 독일인의 대표적인 취미로 소개한다.
* 정원이 없는 도시 주민도 작은 정원에서 과일과 채소를 기르며 여가를 보낼 수 있는 Kleingarten을 설명한다.
* der Kleingarten → die Kleingärten : 작은 임대 정원, 교재의 ‘주말농장’.
    * klein ‘작은’ + der Garten ‘정원’. 복수에서도 Garten → Gärten의 움라우트를 유지한다.
* 교재는 국가나 시의 정원 용지를 지역 협회를 통해 빌리는 방식과 회비를 소개한다.
* 지역 협회 약 15,000개, 회원 약 100만 명이라는 수치는 교재 당시의 소개 내용이다.

## 3. 화법조동사

교재 51쪽 · [원본](../../materials/textbook-7/KakaoTalk_20261029_145235466_02.jpg)

### 3.1. 현재인칭변화 전체

화법조동사는 능력·의무·허가·의지·당위·추측 등을 나타낸다. 주어에 맞춰 화법조동사를 활용하고, 함께 쓰는 본동사는 원형으로 둔다.

| 주어 | können | müssen | dürfen | wollen | sollen | mögen |
| --- | --- | --- | --- | --- | --- | --- |
| ich | kann | muss | darf | will | soll | mag |
| du | kannst | musst | darfst | willst | sollst | magst |
| er / sie / es | kann | muss | darf | will | soll | mag |
| wir | können | müssen | dürfen | wollen | sollen | mögen |
| ihr | könnt | müsst | dürft | wollt | sollt | mögt |
| sie | können | müssen | dürfen | wollen | sollen | mögen |
| Sie | können | müssen | dürfen | wollen | sollen | mögen |

* ich와 er·sie·es의 형태가 같다. 보통 동사처럼 ich에 -e, er에 -t를 붙이지 않는다.
* 단수에서 können → kann, müssen → muss, dürfen → darf, wollen → will, mögen → mag로 어간이 바뀐다.
* sollen은 단수에서도 어간 soll-을 유지한다.
* wir·sie·Sie는 원형과 같은 형태. ihr에서는 könnt·müsst·dürft·mögt의 움라우트에 주의한다.

---

### 3.2. 교재의 의미별 예문 전체

* Ich will ins Theater gehen.
    * 나는 극장에 가려고 한다.
    * wollen = 의지 → ich will / gehen = 문장 끝의 동사원형.
    * ins Theater = in + 중성 4격, 목적지.
* Sie muss den ganzen Tag arbeiten.
    * 그녀는 하루 종일 일해야 한다.
    * müssen = 의무·필요 → sie muss / arbeiten = 동사원형.
    * den ganzen Tag = 하루 종일, 남성 4격의 지속 시간. arbeiten의 목적어가 아니다.
* Du musst hier nicht bleiben.
    * 너는 여기에 머물 필요가 없다.
    * nicht müssen = ~할 필요가 없다. 남아 있어도 되지만 의무는 없다.
    * bleiben : 머무르다 / hier : 여기에.
* Darf ich in den Park gehen?
    * 제가 공원에 가도 될까요?
    * dürfen = 허가 → ich darf. 예·아니요 질문이라 Darf가 맨 앞.
    * in den Park = in + 남성 4격, 목적지 / gehen은 끝.
* Du darfst hier nicht rauchen.
    * 너는 여기서 담배를 피우면 안 된다.
    * nicht dürfen = ~해서는 안 된다, 금지.
    * rauchen : 담배를 피우다 / du → darfst.
* Du sollst deine Eltern ehren.
    * 너는 부모님을 공경해야 한다.
    * sollen = 당위·요구 → du sollst.
    * ehren + 4격 : 공경하다 / deine Eltern = 복수 4격 목적어.
* Das Restaurant soll sehr gut sein.
    * 그 식당은 아주 좋다고 한다.
    * sollen = 전해 들은 말, 소문. 여기서는 의무가 아니다.
    * das Restaurant → die Restaurants : 식당. 단수 주어 → soll.
    * sein = 동사원형 / sehr gut = 아주 좋은.
* Er mag jetzt in Köln sein.
    * 그는 지금 쾰른에 있을지도 모른다.
    * mögen = 추측·가능성 → er mag / sein = 동사원형.
    * Köln : 쾰른. 도시 이름 앞에 보통 관사를 붙이지 않는다.
    * 이 문장의 mag는 ‘좋아한다’로 번역하지 않는다.
* Du kannst es nicht ändern.
    * 너는 그것을 바꿀 수 없다.
    * können = 능력·가능 → du kannst. nicht가 있어 문장 전체는 불가능을 뜻한다.
    * ändern + 4격 : 바꾸다 / es = 바꾸는 대상, 4격 대명사.

### 3.3. 부정과 어순 비교

| 표현 | 뜻 | 교재 문장 |
| --- | --- | --- |
| nicht müssen | 하지 않아도 된다 | Du musst hier nicht bleiben. |
| nicht dürfen | 하면 안 된다 | Du darfst hier nicht rauchen. |
| nicht können | 할 수 없다 | Du kannst es nicht ändern. |

* 평서문 : 주어 + 활용한 화법조동사 + 나머지 성분 + 본동사 원형.
    * Ich / will / ins Theater / gehen.
* 의문사 없는 질문 : 활용한 화법조동사 + 주어 + 나머지 성분 + 본동사 원형.
    * Darf / ich / in den Park / gehen?
* 위 표의 nicht müssen 등은 뜻을 비교하기 위한 표제다. 실제 문장 속 nicht의 자리는 교재 예문처럼 확인한다.
* 본동사의 목적어·전치사 결합은 그대로 유지한다.
    * ehren + 4격 → deine Eltern / ändern + 4격 → es.
* 분리동사도 본동사 원형으로 쓰면 붙여 쓴다.
    * Ich möchte gern mitkommen. → möchte만 활용, mitkommen은 끝.

### 3.4. mögen과 möchte

대화의 möchte와 51쪽 사진 필기를 설명하기 위한 보충. [5과의 활용 정리](5.md#43-möchte와-mögen)와 연결한다.

* mögen + 명사 4격 : ~을 좋아하다. 이때는 mögen 자체가 본동사 역할을 한다.
* mögen + 동사원형 : 교재 예문에서는 ‘~일지도 모른다’라는 추측.
    * Er mag jetzt in Köln sein.
* möchte : ~하고 싶다. 형태상 mögen의 접속법 2식으로, 현재의 희망을 부드럽게 표현한다.
    * möchte / möchtest / möchte / möchten / möchtet / möchten.
    * 위 순서는 ich / du / er·sie·es / wir / ihr / sie·Sie.
* Ich möchte gern mitkommen.
    * ‘함께 가고 싶다’라는 희망이며 추측이 아니다.

## 4. 복합동사

교재 52쪽 · [원본](../../materials/textbook-7/KakaoTalk_20261029_145235466_03.jpg)

교재는 fallen·suchen·haben·kommen·sehen 등에 접두사가 붙은 동사를 ‘복합동사’로 설명한다. 문장에서 접두사를 떼는지와 어디에 강세를 두는지를 함께 확인한다.

### 4.1. 비분리동사

* 교재의 비분리 접두사 : be-, emp-, ent-, er-, ge-, miss-, ver-, zer-.
* 이 과의 비분리동사는 활용해도 접두사를 붙여 두며, 접두사에 강세를 두지 않는다.
* Das Zimmer gefällt mir sehr.
    * 그 방은 내 마음에 아주 든다.
    * gefallen : 마음에 들다. ge-를 떼지 않는다.
    * das Zimmer = 단수 주어 → gefällt / mir = 마음에 들어 하는 사람, 3격.
* Ich besichtige das Schloss.
    * 나는 그 성을 구경한다.
    * besichtigen + 4격 : 관람하다, 둘러보다 → ich besichtige. be-는 비분리.
    * das Schloss → die Schlösser : 성, 궁전. das Schloss = 중성 4격 목적어.
* Sie besucht ihre Eltern.
    * 그녀는 자기 부모님을 방문한다.
    * besuchen + 4격 → sie besucht / ihre Eltern = 복수 4격.
    * 여기서 Sie는 문장 첫머리의 ‘그녀’. 동사 besucht로 단수임을 확인한다.

---

### 4.2. 분리동사

이 과에서 vor-, mit-, an-, aus-, fern-은 강세를 받는 분리 요소다. 동사를 활용한 평서문·직접 의문문에서는 이 요소가 문장 끝으로 간다.

* Was hast du am Wochenende vor?
    * 주말에 무슨 계획이 있어?
    * vorhaben → du hast … vor. 의문사 Was 다음에 활용형 hast.
* Kommst du mit?
    * 같이 갈래?
    * mitkommen → du kommst … mit. 질문 맨 앞에 Kommst, 끝에 mit.
* Der Zug kommt bald an.
    * 기차가 곧 도착한다.
    * ankommen : 도착하다 → kommt … an / bald : 곧.
    * der Zug → die Züge : 기차. der Zug = 단수 주어.
* Du siehst heute schön aus.
    * 너 오늘 예뻐 보인다.
    * aussehen : ~처럼 보이다 → du siehst … aus. sehen의 e → ie 변화가 유지된다.
    * heute : 오늘 / schön : 아름다운. schön에는 격 어미를 붙이지 않는다.
* Julia und Hana sehen zusammen fern.
    * 율리아와 하나는 함께 텔레비전을 본다.
    * fernsehen → 복수 주어 sehen … fern / zusammen : 함께.

교재는 위 비분리 접두사 이외의 접두사를 분리형으로 단순화해 설명한다. **보충:** 실제로는 über-·um-처럼 동사와 강세에 따라 분리 여부가 달라지는 경우도 있으므로 단어별로 확인한다. [독일어연구소 IDS의 분리·비분리 용법 설명](https://grammis.ids-mannheim.de/progr@mm/6960) 참고.

---

### 4.3. 활용형과 원형을 함께 보기

| 원형 | 활용한 형태 | 확인할 점 |
| --- | --- | --- |
| gefallen | es gefällt mir | ge- 비분리, a → ä, 사람 3격 |
| besichtigen | ich besichtige das Schloss | be- 비분리, 대상 4격 |
| besuchen | sie besucht ihre Eltern | be- 비분리, 대상 4격 |
| vorhaben | du hast … vor | vor- 분리, haben의 활용 |
| mitkommen | du kommst … mit | mit- 분리 |
| ankommen | der Zug kommt … an | an- 분리 |
| aussehen | du siehst … aus | aus- 분리, e → ie |
| fernsehen | sie sehen … fern | fern- 분리, 여기서 sie는 복수 |

* 위 표의 …는 문장 틀 표시다.
* 화법조동사와 결합한 본동사 원형은 분리하지 않는다. 사진 필기의 두 문장을 비교한다.
    * Ich sehe heute fern. → sehe를 활용하고 fern을 끝으로 보낸다.
    * Ich will heute fernsehen. → will을 활용하고 원형 fernsehen을 끝에 둔다.

## 5. 시간의 4격 부사구

교재 52쪽 · [원본](../../materials/textbook-7/KakaoTalk_20261029_145235466_03.jpg)

전치사 없이 4격 명사구를 써서 반복되는 때나 지속 시간을 나타낼 수 있다. 형태는 4격이지만 동사의 목적어가 아니라 ‘언제·얼마나 오래’를 설명한다.

### 5.1. 교재 표현 전체

| 표현 | 뜻 | 기본 명사와 격 |
| --- | --- | --- |
| jeden Morgen | 매일 아침 | der Morgen → 남성 4격 jeden Morgen |
| jeden Tag | 날마다, 매일 | der Tag → 남성 4격 jeden Tag |
| jeden Monat | 매달 | der Monat → 남성 4격 jeden Monat |
| den ganzen Tag | 하루 종일 | der Tag → 남성 4격 den ganzen Tag |
| die ganze Nacht | 밤새 | die Nacht → 여성 4격 die ganze Nacht |
| einen Moment | 잠깐 | der Moment → 남성 4격 einen Moment |
| einen Augenblick | 잠깐 | der Augenblick → 남성 4격 einen Augenblick |

* jeden : jeder ‘각각의, 매~’의 남성 4격 형태.
* den ganzen Tag : 정관사 den + 형용사 ganzen + 남성 명사 Tag.
* die ganze Nacht : 여성 4격 die + 형용사 ganze + Nacht. 여성은 1격·4격의 관사 형태가 같다.
* einen Moment = einen Augenblick : 같은 뜻의 짧은 시간 표현.
* der Monat → die Monate : 달, 개월.
* der Moment → die Momente : 순간 / der Augenblick → die Augenblicke : 순간.

---

### 5.2. 대화·문법 예문과 연결

* Aber ich muss leider **am Wochenende** **die ganze Zeit** arbeiten.
    * am Wochenende = 언제? → an + 3격 전치사구.
    * die ganze Zeit = 얼마나 오래? → 전치사 없는 여성 4격 부사구.
* Sie muss **den ganzen Tag** arbeiten.
    * 하루 종일 일해야 한다 → den ganzen Tag는 남성 4격 부사구.
* 교재의 시간 표현을 읽을 때 ‘4격 = 항상 목적어’라고 판단하지 않는다.
    * meine Eltern besuchen → 누구를 방문하는가? 목적어.
    * den ganzen Tag arbeiten → 얼마나 오래 일하는가? 시간 부사구.

## 6. 추가 어휘와 사진 필기

### 6.1. 52쪽 맞은편 어휘 상자의 보이는 부분

[52쪽과 맞은편 일부](../../materials/textbook-7/KakaoTalk_20261029_145235466_03.jpg). 오른쪽이 잘려 있어 상자 전체를 복원하지 않았다. 같은 사진의 Übungen 영역은 제외했다.

* bleiben : 머무르다, 남다 / rauchen : 담배를 피우다.
* das Restaurant → die Restaurants : 식당.
* ändern : 바꾸다 / der Zug → die Züge : 기차.
* ankommen : 도착하다 / aussehen : ~처럼 보이다.
* das Auge → die Augen : 눈 / der Blick → die Blicke : 시선, 눈길.
    * 상자에서 (das Auge + der Blick)라는 구성 설명이 보인다.
    * 52쪽의 der Augenblick ‘순간’과 연결한다. Auge + -n- + Blick → Augenblick.
* 잘린 표제어나 뜻은 앞쪽 본문에 나온 경우 해당 본문을 근거로 설명했다. 사진 밖의 항목을 추정해 추가하지 않았다.

---

### 6.2. 읽을 수 있는 사진 필기

[51쪽 필기](../../materials/textbook-7/KakaoTalk_20261029_145235466_02.jpg) · [52쪽 필기](../../materials/textbook-7/KakaoTalk_20261029_145235466_03.jpg)

* 51쪽 : nicht müssen은 ‘안 해도 됨’, nicht dürfen은 ‘금지’로 구별한 메모.
* 51쪽 : mögen의 ‘좋아하다’와 화법조동사 용법, 희망을 나타내는 möchte를 구별한 메모.
* Er ist krank.
    * 그는 아프다.
    * er → ist / krank : 아픈. 상태를 직접 서술한다.
* Er mag krank sein.
    * 그는 아플지도 모른다.
    * mag를 활용하고 sein은 원형으로 둔다. 앞 문장에 추측의 뜻을 더한다.
* 52쪽 : gefallen은 비분리, aussehen은 분리동사라는 메모.
* 52쪽 : 비분리 접두사 여덟 개를 다시 묶어 쓴 메모.
* bekommen : 받다, 비분리동사 ↔ ankommen : 도착하다, 분리동사.
    * be-와 an-의 차이이며, ‘받다’를 kommen ‘오다’로 해석하지 않는다.
* Ich sehe heute fern.
    * 나는 오늘 텔레비전을 본다.
* Ich will heute fernsehen.
    * 나는 오늘 텔레비전을 보려고 한다.
    * 같은 분리동사가 정동사인지, 화법조동사 뒤의 원형인지에 따라 형태가 달라진다.
* 필기의 어순 표시와 밑줄은 위 문법 설명에 반영했다. 흐리거나 완성되지 않은 메모는 임의로 문장을 만들지 않았다.
