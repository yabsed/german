## 1. 대화와 인사

교재 15–16쪽 · [15쪽](../../materials/textbook/KakaoTalk_20261012_104454803_03.jpg) · [16–17쪽](../../materials/textbook/KakaoTalk_20261012_104454803_04.jpg)

### 1.1. 도입 문장

* Minho Kim kommt aus Korea.
    * 김민호는 한국에서 왔다.
    * Minho Kim = 주어 1격 / kommt ← kommen, 3인칭 단수.
    * aus + 3격 : ~출신이다. Korea는 여기서 관사 없이 쓴다.
* Er ist Student.
    * 그는 대학생이다.
    * er = Minho Kim / ist ← sein.
    * der Student → die Studenten : 남자 대학생.
    * 직업·신분을 나타내는 1격 보어 → 보통 무관사 Student.
* Klaus Schmidt ist Lehrer.
    * 클라우스 슈미트는 교사다.
    * der Lehrer → die Lehrer : 남자 교사.
    * ist + 직업명 1격 보어.

---

### 1.2. 이름 묻기

* Guten Tag! Ich heiße Klaus Schmidt. Und wie heißen Sie?
    * 안녕하세요! 저는 클라우스 슈미트입니다. 성함이 어떻게 되세요?
    * der Tag → die Tage : 날
    * gut                : 좋은.
    * Guten Tag = 관용 인사. 남성 4격 형태 guten Tag.
    * ich → heiße / 존칭 Sie → heißen.
    * und                : 그리고
    * wie                : 어떻게.
    * wie + 동사 + 주어 → 의문사 질문.
* Ich heiße Minho Kim.
    * 저는 김민호입니다.
    * ich + heiße + 이름.

---

### 1.3. 출신과 거주지

* Herr Kim, woher kommen Sie?
    * 김 선생님, 어디 출신이세요?
    * der Herr → die Herren : 남자에 대한 존칭.
    * Herr Kim은 호칭, Sie가 주어.
    * woher                 : 어디에서
    * kommen ← kommen, 존칭.
* Ich komme aus Korea. Und Sie?
    * 저는 한국 출신입니다. 그쪽은요?
    * komme = ich형 / aus Korea = 출신.
    * Und Sie? = 앞 질문을 되묻는 생략 표현.
* Ich komme eigentlich aus Hamburg.
    * 저는 원래 함부르크 출신입니다.
    * eigentlich : 원래, 사실은
    * Hamburg    : 함부르크.
* Aber ich wohne jetzt in Berlin.
    * 하지만 지금은 베를린에 살아요.
    * aber는 접속사. 뒤의 ich가 첫 문장 성분, wohne가 두 번째.
    * wohnen    : 거주하다
    * jetzt     : 지금
    * in Berlin : 베를린에.
* Ich wohne in München. Dort studiere ich.
    * 저는 뮌헨에 살아요. 거기서 대학 공부를 해요.
    * München   : 뮌헨
    * dort      : 거기에서
    * studieren : 대학에서 공부하다.
    * Dort → 첫 성분 / studiere → 둘째 성분 / ich → 주어.

---

### 1.4. 직업과 권유

* Was machen Sie beruflich?
    * 직업이 무엇인가요?
    * was       : 무엇
    * machen    : 하다
    * beruflich : 직업상.
    * 의문사 + 동사 + 주어.
* Ich bin Lehrer.
    * 저는 교사입니다.
    * bin ← sein, ich형 / Lehrer = 무관사 직업 보어.
* Kommen Sie mal nach Berlin?
    * 베를린에 한번 오시겠어요?
    * 교재는 물음표로 쓴 권유형 질문.
    * 동사 + Sie
    * mal         : 한번, 권유를 부드럽게 함
    * nach Berlin : 베를린으로.
* Sie sind immer herzlich willkommen.
    * 언제나 진심으로 환영합니다.
    * Sie → sind
    * immer      : 항상
    * herzlich   : 진심으로
    * willkommen : 환영받는.
    * sein + 형용사 → 상태. willkommen에 명사 격 어미를 붙이지 않는다.
* Vielen Dank. Auf Wiedersehen!
    * 대단히 감사합니다. 안녕히 계세요!
    * der Dank        : 감사
    * vielen Dank = 남성 4격 관용 표현.
    * das Wiedersehen : 재회
    * auf Wiedersehen = 작별 인사.
* Auf Wiedersehen!
    * 안녕히 가세요! — 상대의 작별 인사에 같은 말로 응답.

---

### 1.5. 16쪽 인사말

* Guten Morgen!     : 좋은 아침입니다.
    * der Morgen → die Morgen : 아침
* Guten Tag!        : 안녕하세요.
    * der Tag → die Tage : 날
* Guten Abend!      : 저녁 인사
    * der Abend → die Abende : 저녁
* Auf Wiedersehen!  : 안녕히 가세요 / 계세요.
* Tschüs! / Tschau! : 잘 가!
* 사진 필기
    * Gute Nacht! : 잘 자요.
    * die Nacht → die Nächte : 밤
    * Nacht는 여성 → gute. Morgen/Tag/Abend는 남성 → guten.

---

### 1.6. 호칭과 이름

* Sie : 존칭 ‘당신/여러분’ → 대문자.
* du  : 친한 사이의 ‘너’ → 소문자.
* Herr Schmidt / Frau Kim / Frau Müller-Seidel
    * der Herr → die Herren : 남자 존칭
    * die Frau → die Frauen : 여자 존칭, 여자, 아내
    * 호칭으로 이름 앞에 쓰면 보통 관사를 붙이지 않는다.
    * 결혼 여부를 Frau라는 호칭만으로 판단하지 않는다.
* 사진 필기
    * siezen                               : Sie로 부르다
    * duzen                                : du로 부르다.
    * Peter Meyer                          : Peter = 이름, Meyer = 성.
    * der Name → die Namen                 : 이름
    * der Vorname → die Vornamen           : 이름, 성을 제외한 이름
    * der Familienname → die Familiennamen : 성
    * der Nachname → die Nachnamen         : 성

---

### 1.7. 지도에 나온 지명

* Deutschland : 독일       — 보통 무관사
    * Hamburg, Berlin, Köln, Frankfurt, München
* Österreich  : 오스트리아 — 보통 무관사
    * Salzburg, Wien
* die Schweiz : 스위스     — 정관사를 함께 외운다.
    * Bern, Zürich
* 독일어 사용 지역에 관한 교재 설명
    * 독일과 오스트리아, 스위스의 많은 지역에서 사용.
    * 지도는 이 세 나라와 도시의 위치를 익히는 자료.
* 지명에는 일반 명사처럼 임의로 der/die/das를 붙이지 않는다.

## 2. 현재형과 문장의 어순

교재 17–18쪽 · [17쪽](../../materials/textbook/KakaoTalk_20261012_104454803_04.jpg) · [18쪽](../../materials/textbook/KakaoTalk_20261012_104454803_05.jpg)

### 2.1. kommen, heißen, sein 전체 현재형

* kommen : 오다
    * ich komme / du kommst / er kommt / sie kommt / es kommt
    * wir kommen / ihr kommt / sie kommen / Sie kommen
* heißen : 이름이 ~이다
    * ich heiße / du heißt / er heißt / sie heißt / es heißt
    * wir heißen / ihr heißt / sie heißen / Sie heißen
* sein   : ~이다, 있다
    * ich bin / du bist / er ist / sie ist / es ist
    * wir sind / ihr seid / sie sind / Sie sind

* ich : 나
* du  : 너
* er  : 그
* sie : 그녀
* es  : 그것
* wir : 우리
* ihr : 너희
* sie : 그들
* Sie : 존칭 당신·여러분
* Sg. = 단수 / Pl. = 복수

---

### 2.2. 교재의 현재형 예문 전체

* Ich komme aus Korea.
    * 나는 한국 출신이다. ich → komme / aus + 출신.
* Woher kommst du?
    * 너는 어디 출신이니? woher + kommst + du.
* Er kommt aus Deutschland.
    * 그는 독일 출신이다. er → kommt.
* Woher kommen Sie?
    * 어디 출신이세요? 존칭 Sie → kommen.

* Ich heiße Minho Kim.
    * 내 이름은 김민호다. ich → heiße.
* Wie heißt du?
    * 이름이 뭐니? du → heißt.
* Wie heißt er?
    * 그의 이름은 뭐니? er → heißt.
* Wie heißen Sie?
    * 성함이 어떻게 되세요? Sie → heißen.

* Ich bin Lehrer.
    * 나는 교사다. ich → bin
    * der Lehrer : 교사, 여기서는 무관사 1격 보어.
* Du bist immer herzlich willkommen.
    * 너는 언제나 진심으로 환영이야. du → bist
    * immer      : 항상
    * herzlich   : 진심으로
    * willkommen : 환영받는.
* Er ist Lehrer.
    * 그는 교사다. er → ist.
* Sie sind immer herzlich willkommen.
    * 언제나 진심으로 환영합니다. Sie → sind
    * herzlich : 진심으로.

---

### 2.3. 어간과 어미

* kommen = komm- + -en
* 현재형 기본 어미 → -e / -st / -t / -en / -t / -en
* machen : 하다
* wohnen : 거주하다 → 같은 기본 어미.
* -t, -d 등으로 끝나는 어간 → 발음을 위해 e.
    * arbeiten : 일하다
    * du arbeitest / er arbeitet / ihr arbeitet
    * 교재의 -fn, -chn 등 설명도 발음에 필요한 e를 넣는 유형을 가리킨다.
* -s, -ß, -z로 끝나는 어간 → du에서 -st 대신 -t.
    * heißen → du heißt
* sein → 불규칙형을 따로 외운다.

---

### 2.4. 평서문 → 동사가 두 번째 성분

* Ich heiße Klaus Schmidt.
    * Ich / heiße / Klaus Schmidt.
    * 저는 클라우스 슈미트입니다.
* Er ist Lehrer.
    * Er / ist / Lehrer.
    * 그는 교사다.
* Dort studiere ich.
    * Dort / studiere / ich.
    * 거기서 나는 대학 공부를 한다.
* 첫 ‘단어’가 아니라 첫 ‘성분’ 다음에 동사를 둔다.

* 사진 필기
    * Anna wohnt jetzt in Seoul.
        * 안나는 지금 서울에 산다. Anna / wohnt / jetzt / in Seoul.
    * Jetzt wohnt Anna in Seoul.
        * 지금 안나는 서울에 산다. Jetzt / wohnt / Anna / in Seoul.
    * In Seoul wohnt Anna jetzt.
        * 서울에 안나는 지금 산다. In Seoul 전체가 첫 성분.

---

### 2.5. 의문사 질문

* Was machen Sie beruflich? — Ich bin Lehrer.
    * 직업이 무엇인가요? — 교사입니다.
    * machen    : 하다
    * beruflich : 직업상.
* Was sind Sie von Beruf?   — Ich bin Student.
    * 직업이 무엇인가요? — 대학생입니다.
    * der Beruf → die Berufe : 직업.
    * von Beruf              : 직업으로. 관용구라 Beruf 앞에 관사가 없다.
* Wie heißen Sie?           — Ich heiße Julia Bachmann.
    * 성함이 어떻게 되세요? — 율리아 바흐만입니다.
* 의문사 + 동사 + 주어 → was / wie / wo / woher.
    * was   : 무엇
    * wie   : 어떻게
    * wo    : 어디에
    * woher : 어디에서.

---

### 2.6. 의문사 없는 질문

* Wohnst du in Berlin?
    * 너는 베를린에 사니?
    * wohnst가 첫 성분, du가 주어.
* Ja, ich wohne in Berlin.
    * 응, 나는 베를린에 살아.
    * ja : 네. 쉼표 뒤는 평서문.
* Nein, ich wohne nicht in Berlin.
    * 아니, 나는 베를린에 살지 않아.
    * nein            : 아니
    * nicht in Berlin : 베를린에 사는 것이 아님.
* 동사 + 주어 → Ja / Nein으로 답할 수 있는 질문.

---

### 2.7. 사진 필기의 질문 단어

* Woher kommen Sie? — Ich komme aus Busan.
    * 어디 출신이세요? — 부산 출신입니다.
    * Sie → kommen
    * ich → komme
    * aus : 출신.
* Lehrer(in), Arzt(in)라는 필기
    * der Lehrer → die Lehrerin : 남자 교사 → 여자 교사.
    * der Arzt → die Ärztin     : 남자 의사 → 여자 의사.
    * 각각 복수 die Lehrer / die Lehrerinnen / die Ärzte / die Ärztinnen.

* wer   : 누구     — 사람을 묻는다.
* wo    : 어디     — 위치.
* woher : 어디에서 — 출신·출발점.
* wohin : 어디로   — 방향.
* wie   : 어떻게   — 이름·상태·정도.
* was   : 무엇     — 사물·내용·직업.
