## 1. 알파벳과 모음

교재 9–10쪽 · [9쪽](../../materials/textbook/KakaoTalk_20261012_104454803.jpg) · [10–11쪽](../../materials/textbook/KakaoTalk_20261012_104454803_01.jpg)

### 1.1. Alphabet und Aussprache

* das Alphabet → die Alphabete     : 알파벳
* die Aussprache → die Aussprachen : 발음
* die Lektion → die Lektionen      : 과
* der Vokal → die Vokale           : 모음
* und                              : 그리고

---

### 1.2. 글자 이름

* A a [aː] · B b [beː] · C c [tseː] · D d [deː]
* E e [eː] · F f [ɛf] · G g [ɡeː] · H h [haː]
* I i [iː] · J j [jɔt] · K k [kaː] · L l [ɛl]
* M m [ɛm] · N n [ɛn] · O o [oː] · P p [peː]
* Q q [kuː] · R r [ɛʁ] · S s [ɛs] · T t [teː]
* U u [uː] · V v [faʊ] · W w [veː] · X x [ɪks]
* Y y [ˈʏpsilɔn] · Z z [tsɛt]
* Ä ä [ɛː] · Ö ö [øː] · Ü ü [yː]
* ß : Eszett [ɛsˈtsɛt]
    * 글자 이름과 단어 안에서 나는 소리는 다르다.
    * 교재의 인쇄체·필기체는 같은 글자의 서로 다른 모양이다.

---

### 1.3. a, e, i, o, u

* a → 긴 [aː]
    * da     : 거기에
    * fahren : 타고 가다
* a → 짧은 [a]
    * hallo  : 안녕
    * fallen : 떨어지다

* e → 긴 [eː]
    * der Lehrer → die Lehrer : 남자 교사
    * der See → die Seen      : 호수
* e → 짧은 [ɛ]
    * hell   : 밝은
    * lernen : 배우다
* 강세 없는 e → [ə]
    * der Name → die Namen    : 이름
    * komme ← kommen          : 나는 온다
    * 모음 뒤 어말 -er는 흔히 [ɐ] : der Lehrer, die Mutter.
    * die Mutter → die Mütter : 어머니

* i / ie → 긴 [iː]
    * Berlin                 : 베를린
    * die Miete → die Mieten : 집세
* i → 짧은 [ɪ]
    * ich                    : 나
    * die Mitte → die Mitten : 가운데
* 강세 없는 -ie → [i̯ə]
    * Asien                      : 아시아
    * die Familie → die Familien : 가족

* o → 긴 [oː]
    * der Sohn → die Söhne : 아들
    * das Boot → die Boote : 배
* o → 짧은 [ɔ]
    * von    : ~로부터, ~의
    * kommen : 오다

* u → 긴 [uː]
    * gut                    : 좋은, 잘
    * der Beruf → die Berufe : 직업
* u → 짧은 [ʊ]
    * und                   : 그리고
    * der Mund → die Münder : 입

---

### 1.4. ä, ö, ü

* ä → 긴 [ɛː]
    * die Bären ← der Bär : 곰들
    * schläft ← schlafen  : 그/그녀가 잔다
* ä → [ɛ] 계열
    * die Ärztin → die Ärztinnen : 여자 의사
    * die Getränke ← das Getränk : 음료들
    * 교재는 두 단어를 짧은 ä 묶음에 놓는다. Ärztin은 r 앞 모음이므로 단순한 자음 개수 규칙의 대표 예로 외우지 않는다.

* ö → 긴 [øː]
    * schön : 아름다운, 좋은
    * hören : 듣다
* ö → 짧은 [œ]
    * die Wörter ← das Wort : 낱말들
    * Köln                  : 쾰른

* ü → 긴 [yː]
    * süß    : 달콤한, 귀여운
    * fühlen : 느끼다
* ü → 짧은 [ʏ]
    * dünn   : 얇은, 마른
    * füllen : 채우다

---

### 1.5. 길이 판단

* 같은 자음 두 개 → 앞 모음이 대체로 짧다.
    * hallo, Mitte, kommen, Mund의 모음은 짧다. Mund는 서로 다른 자음 두 개의 예.
* 모음 뒤의 묵음 h → 앞 모음이 길다.
    * fahren, sehen, der Sohn
    * sehen : 보다
* 동사의 변화형 → 기본형의 모음 길이를 함께 확인한다.
    * schlafen → schläft : 긴 모음
* 철자 규칙은 단서다. 모든 모음 길이를 자음 개수만으로 결정하지 않는다.

---

### 1.6. 복모음

* au → [aʊ]
    * das Haus → die Häuser : 집
    * die Frau → die Frauen : 여자, 부인
* eu / äu → [ɔʏ]
    * heute                    : 오늘
    * der Freund → die Freunde : 남자 친구
    * der Käufer → die Käufer  : 구매자
    * der Räuber → die Räuber  : 강도
* ai / ay / ei → [aɪ]
    * der Mai              : 5월
    * der Laib → die Laibe : 빵 한 덩이
    * Bayern               : 바이에른
    * Mayer                : 성씨
    * nein                 : 아니요
    * allein               : 혼자, 홀로

## 2. 자음과 강세

교재 11–12쪽 · [10–11쪽](../../materials/textbook/KakaoTalk_20261012_104454803_01.jpg) · [12–13쪽](../../materials/textbook/KakaoTalk_20261012_104454803_02.jpg)

### 2.1. 유성음과 무성음

* der Konsonant → die Konsonanten : 자음
* b → [b]
    * bin ← sein             : 나는 ~이다
    * der Beruf → die Berufe : 직업
* b → 어말 [p]
    * der Dieb → die Diebe : 도둑
    * lieb                 : 사랑스러운
* p → [p]
    * die Post                 : 우편
    * das Papier → die Papiere : 종이, 서류

* d → [d]
    * der                  : 남성 1격 등의 정관사
    * die Dame → die Damen : 숙녀, 여자분
* d → 어말 [t]
    * die Hand → die Hände  : 손
    * der Mund → die Münder : 입
* t / dt / th → [t]
    * der Tag → die Tage        : 날
    * hat ← haben               : 그/그녀가 가지고 있다
    * Schmidt                   : 성씨 슈미트
    * das Theater → die Theater : 극장, 연극

* g → [ɡ]
    * gut                   : 좋은
    * der Magen → die Mägen : 위
* g → 어말 [k]
    * der Tag → die Tage    : 날
    * die Burg → die Burgen : 성
* k / ck → [k]
    * kalt   : 추운
    * welken : 시들다
    * dick   : 두꺼운, 뚱뚱한
    * zurück : 뒤로, 돌아서
* c로 시작하는 교재 외래어 → [k]
    * die Cola → die Colas        : 콜라
    * der Computer → die Computer : 컴퓨터
* 끝의 b/d/g → [p/t/k]
    * der Dieb, die Hand, der Tag

---

### 2.2. s, v, f, w

* s → 모음 앞 [z]
    * sehen                : 보다
    * der Sohn → die Söhne : 아들
* s → 어말 [s]
    * das Haus → die Häuser : 집
    * die Maus → die Mäuse  : 쥐
* v → [v]
    * die Vase → die Vasen  : 꽃병
    * das Verb → die Verben : 동사
* v → [f]
    * von                   : ~로부터
    * der Vater → die Väter : 아버지
* f → [f]
    * die Familie → die Familien : 가족
    * helfen                     : 돕다
* w → [v]
    * wir        : 우리
    * was        : 무엇
    * das Wetter : 날씨

---

### 2.3. 나머지 자음

* l → [l]
    * lesen     : 읽다
    * das Glück : 행운, 행복
* r → [ʁ] 등
    * das Herz → die Herzen : 심장, 마음
    * trinken               : 마시다
* j → [j]
    * ja                   : 네
    * das Jahr → die Jahre : 해, 년
* ß → [s]
    * der Fuß → die Füße : 발
    * das Maß → die Maße : 치수, 척도
* ng → [ŋ]
    * eng    : 좁은
    * singen : 노래하다
* nk → [ŋk]
    * denken                : 생각하다
    * der Onkel → die Onkel : 삼촌

* ch → [ç]
    * echt                  : 진짜의
    * ich                   : 나
    * die Bücher ← das Buch : 책들
    * durch                 : ~을 통하여
* ch → [x]
    * der Bach → die Bäche  : 시내
    * das Buch → die Bücher : 책
    * doch                  : 그렇지만, 부정 질문에 대한 ‘아니, 그래’
* chs → [ks]
    * sechs                  : 6
    * der Fuchs → die Füchse : 여우
* z / ts / tz → [ts]
    * die Zeit → die Zeiten  : 시간
    * rechts                 : 오른쪽에
    * jetzt                  : 지금
    * die Katze → die Katzen : 고양이
* tsch → [tʃ]
    * Deutsch : 독일어 — 명사 기본형 das Deutsch, 언어명으로는 보통 무관사
    * tschüs  : 잘 가
* sch → [ʃ]
    * schön                    : 아름다운
    * die Schule → die Schulen : 학교
* 단어·어간 첫머리 sp / st → [ʃp] / [ʃt]
    * spielen                     : 놀다, 연주하다
    * der Sport                   : 스포츠
    * der Student → die Studenten : 남자 대학생
    * stehen                      : 서 있다

---

### 2.4. 첫 음절 강세

* 굵은 부분 → 강세
    * der **A**bend → die Abende    : 저녁
    * die **Ar**beit → die Arbeiten : 일
    * der **Bru**der → die Brüder   : 남자 형제
    * die **El**tern                : 부모, 복수
    * **Ham**burg                   : 함부르크
    * der **Leh**rer → die Lehrer   : 남자 교사
    * die **Schu**le → die Schulen  : 학교
    * die **Son**ne → die Sonnen    : 태양
    * das **Wet**ter                : 날씨
    * **bit**ten                    : 부탁하다
    * **hei**ßen                    : 이름이 ~이다
    * **kom**men                    : 오다
    * **le**ben                     : 살다
    * **ma**chen                    : 하다
    * **schwim**men                 : 수영하다
    * **woh**nen                    : 거주하다
    * **al**les                     : 모든 것
    * **ger**ne                     : 기꺼이, 즐겨
    * **heu**te                     : 오늘
    * **im**mer                     : 항상
    * **lei**der                    : 유감스럽게도
    * **spä**ter                    : 나중에
* 외래어·고유명사 강세
    * Ber**lin**               : 베를린
    * das Ca**fé** → die Cafés : 카페
    * die Mu**sik**            : 음악
    * mö**bliert**             : 가구가 갖추어진

---

### 2.5. 접두사 강세

* 분리 접두사 → 접두사에 강세
    * **ab**fahren    : 출발하다
    * **an**kommen    : 도착하다
    * **aus**steigen  : 내리다
    * **auf**fallen   : 눈에 띄다
    * **ein**schlafen : 잠들다
    * **mit**fahren   : 함께 타고 가다
    * **vor**haben    : 계획하다
    * **zu**sagen     : 승낙하다
* 교재 접두사 목록 : ab-, an-, auf-, aus-, ein-, mit-, vor-, zu-

* 비분리 접두사 → 뒤 어간에 강세
    * be**kom**men     : 받다
    * emp**feh**len    : 추천하다
    * ent**de**cken    : 발견하다
    * er**zäh**len     : 이야기하다
    * ge**fal**len     : 마음에 들다
    * miss**brau**chen : 남용하다
    * ver**ste**hen    : 이해하다
    * zer**stö**ren    : 파괴하다
* 교재 접두사 목록 : be-, emp-, ent-, er-, ge-, miss-, ver-, zer-
* 이 장은 강세 연습이다. 문장 속 분리·활용은 각각의 동사 용법을 따로 확인한다.

---

### 2.6. 접미사 강세

* 보통 강세를 받지 않는 접미사
    * -heit, -keit, -lein, -ung, -er, -schaft, -bar, -haft, -ig, -isch, -lich
* 교재 예시
    * die Ge**sund**heit                        : 건강
    * die **Sau**berkeit                        : 청결
    * das **Fräu**lein → die Fräulein           : 아가씨라는 옛 호칭
    * die **Prü**fung → die Prüfungen           : 시험
    * der **Leh**rer → die Lehrer               : 교사
    * die **Freund**schaft → die Freundschaften : 우정
    * **wun**derbar                             : 멋진
    * **zwei**felhaft                           : 의심스러운
    * **flei**ßig                               : 부지런한
    * **herz**lich                              : 진심 어린

* 강세가 오는 외래어 접미사
    * -ent, -ion, -tät, -ist, -ieren
    * der Stu**dent** → die Studenten         : 대학생
    * die Na**tion** → die Nationen           : 국가, 민족
    * die Universi**tät** → die Universitäten : 대학교
    * der Pia**nist** → die Pianisten         : 피아니스트
    * stu**die**ren                           : 대학에서 공부하다
