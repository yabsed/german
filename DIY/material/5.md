## 1. 집을 구하고 설명하는 대화

교재 37–38쪽 · [37쪽 상세](../../materials/textbook-5/KakaoTalk_20261024_195145676_03.jpg) · [37쪽과 맞은편 필기](../../materials/textbook-5/KakaoTalk_20261024_195145676_02.jpg) · [38–39쪽](../../materials/textbook-5/KakaoTalk_20261024_195145676_01.jpg)

### 1.1. 도입 문장

* Minho sucht eine Wohnung.
    * 민호는 집을 구하고 있다.
    * suchen + 4격 : 찾다, 구하다. Minho 단수 → sucht.
    * die Wohnung → die Wohnungen : 주거 공간, 아파트 한 세대.
    * eine Wohnung = 여성 4격 목적어.
* Hana hilft ihm bei der Wohnungssuche.
    * 하나는 민호가 집 구하는 것을 도와준다.
    * helfen → hilft : 3인칭 단수에서 e → i.
    * helfen + 사람 3격 → ihm = 민호에게.
    * bei + 3격 → bei der Wohnungssuche : 집을 구하는 일에서.
    * die Wohnungssuche : 집 구하기, 보통 단수.
* Er trifft den Vermieter.
    * 그는 집주인을 만난다.
    * treffen + 4격 → er trifft, den Vermieter.
    * der Vermieter → die Vermieter : 임대인, 집주인.
* Später beschreibt er Hana die Wohnung.
    * 나중에 그는 하나에게 그 집을 설명한다.
    * später : 나중에. Später / beschreibt / er / Hana / die Wohnung.
    * beschreiben : 묘사하다, 설명하다. be-는 분리하지 않는다.
    * er = 주어 1격 / Hana = 듣는 사람 3격 / die Wohnung = 설명하는 대상 4격.
    * 사람 이름 Hana는 이 문장에서 격에 따라 철자가 바뀌지 않는다.

---

### 1.2. 집이 마음에 드는지 묻기

* Hana : Wie gefällt dir die Wohnung?
    * 그 집은 마음에 들어?
    * gefallen + 사람 3격 : ~의 마음에 들다.
    * die Wohnung = 마음에 드는 대상, 주어 1격 → gefällt.
    * dir = du의 3격. Wie / gefällt / dir / die Wohnung?
* Minho : Sie gefällt mir sehr gut.
    * 아주 마음에 들어.
    * Sie = die Wohnung을 받는 여성 단수 주어. 문장 첫 글자라 대문자.
    * mir = ich의 3격 / sehr gut : 아주, 매우 좋게.
* Sie ist sauber und relativ groß.
    * 깨끗하고 비교적 커.
    * sauber : 깨끗한 / relativ : 비교적 / groß : 큰.
    * sein 뒤의 형용사 보어 sauber·groß에는 성·격 어미를 붙이지 않는다.

---

### 1.3. 크기와 방 구성

* Hana : Wie groß ist die Wohnung?
    * 집이 얼마나 커?
    * wie groß : 얼마나 큰. 크기·면적을 묻는다.
* Minho : Sie ist ungefähr 40 m² groß.
    * 약 40제곱미터야.
    * ungefähr : 대략 / vierzig : 40.
    * der Quadratmeter → die Quadratmeter : 제곱미터, m².
    * 40 m²는 vierzig Quadratmeter로 읽는다. Sie는 집을 받으므로 ist.
* Die Wohnung hat ein Zimmer, ein Badezimmer und eine Küche.
    * 집에는 방 하나, 욕실 하나, 부엌 하나가 있어.
    * haben → hat / 뒤의 세 명사구는 모두 4격 목적어.
    * das Zimmer → die Zimmer : 방 → ein Zimmer.
    * das Badezimmer → die Badezimmer : 욕실 → ein Badezimmer.
    * die Küche → die Küchen : 부엌 → eine Küche.

---

### 1.4. 가구와 방의 모습

* Hana : Ist das Zimmer möbliert?
    * 방에 가구가 갖추어져 있어?
    * 의문사 없는 질문 → Ist / das Zimmer / möbliert?
    * möbliert : 가구가 갖추어진. möblieren ‘가구를 비치하다’와 연결한다.
* Minho : Ja, es ist voll möbliert.
    * 응, 가구가 완비되어 있어.
    * es = 중성 명사 das Zimmer / voll : 완전히, 가득.
* Hana : Wie sieht das Zimmer aus?
    * 방은 어떻게 생겼어?
    * aussehen : ~처럼 보이다, 생김새가 ~하다. 분리동사 aus + sehen.
    * das Zimmer 단수 → sieht … aus. 동사 변화형 sieht는 두 번째 성분, aus는 끝.

---

### 1.5. 가구의 위치

* Minho : In der Ecke am Fenster steht ein Bett.
    * 창가 구석에 침대가 하나 있어.
    * die Ecke → die Ecken : 모퉁이, 구석 / das Fenster → die Fenster : 창문.
    * in der Ecke = 여성 3격 / am Fenster = an dem Fenster, 중성 3격.
    * das Bett → die Betten : 침대. ein Bett = 주어 1격 → steht.
    * In der Ecke am Fenster / steht / ein Bett. 장소가 앞에 와도 동사는 두 번째 성분.
* Neben dem Bett steht ein Tisch.
    * 침대 옆에 탁자가 하나 있어.
    * neben + 장소 3격 → dem Bett.
    * der Tisch → die Tische : 탁자. ein Tisch = 주어 1격.
* An der Wand über dem Tisch hängt sogar ein Bild.
    * 탁자 위쪽 벽에는 그림까지 걸려 있어.
    * die Wand → die Wände : 벽 / das Bild → die Bilder : 그림.
    * an der Wand = 벽에, 여성 3격 / über dem Tisch = 탁자 위쪽에, 남성 3격.
    * hängen → hängt : 걸려 있다 / sogar : 심지어, ~까지도.
    * ein Bild = 주어 1격. 두 장소 표현은 그림의 위치를 설명한다.

---

### 1.6. 책장과 배치 계획

* Hana : Gibt es auch ein Bücherregal?
    * 책장도 있어?
    * es gibt + 4격 : ~이 있다. 질문에서는 Gibt / es / …?
    * das Bücherregal → die Bücherregale : 책장.
    * ein Bücherregal = 중성 4격 목적어. 주어는 es이므로 gibt.
* Minho : Nein, leider nicht.
    * 아니, 아쉽게도 없어.
    * leider : 유감스럽게도 / nicht : ~하지 않다. 앞 질문을 받아 짧게 답한다.
* Ich möchte ein Regal an die Wand stellen.
    * 벽에 선반을 하나 세워 놓고 싶어.
    * möchte : ~하고 싶다. 문장 끝에 동사원형 stellen.
    * das Regal → die Regale : 선반, 책장. ein Regal = 놓는 대상, 4격.
    * stellen : 세워 놓다 / an die Wand = 놓을 목표 위치, 여성 4격.
    * 이미 있는 위치 an der Wand ↔ 옮겨 놓을 곳 an die Wand.

---

### 1.7. 발코니와 짧은 대답

* Hana : Gibt es einen Balkon?
    * 발코니가 있어?
    * der Balkon → die Balkons : 발코니. 복수형 Balkone도 쓴다.
    * es gibt + 4격 → einen Balkon. 남성이라 ein → einen이 드러난다.
* Minho : Ja, er ist aber klein.
    * 응, 그런데 작아.
    * er = 남성 명사 der Balkon / klein : 작은 / aber : 하지만.
* Hana : Das macht nichts.
    * 그건 괜찮아. / 상관없어.
    * das = 앞 상황을 받는 주어 / machen → macht / nichts : 아무것도 ~않다.
    * 전체를 ‘문제없다’라는 관용 표현으로 외운다.

---

### 1.8. 38쪽 어휘 상자 전체

* suchen : 찾다 / helfen : 돕다 / treffen : 만나다.
* der Vermieter → die Vermieter : 임대인, 집주인.
* beschreiben : 묘사하다 / die Wohnung → die Wohnungen : 집, 주거 공간.
* jemandem gefallen : ~의 마음에 들다. 교재의 jm.은 jemandem, 사람 3격의 약자.
* sauber : 깨끗한 / relativ : 비교적 / groß : 큰 / ungefähr : 대략.
* der Quadratmeter → die Quadratmeter : 제곱미터.
* das Zimmer → die Zimmer : 방 / das Badezimmer → die Badezimmer : 욕실.
* das Badezimmer = das Bad + das Zimmer. das Bad → die Bäder : 목욕, 욕실.
* die Küche → die Küchen : 부엌 / voll : 가득 찬, 완전히.
* möblieren : 가구를 비치하다 / möbliert : 가구가 갖추어진.
* aussehen : ~처럼 보이다 / die Ecke → die Ecken : 모퉁이, 구석.
* das Fenster → die Fenster : 창문 / stehen : 서 있다.
* das Bett → die Betten : 침대 / der Tisch → die Tische : 탁자.
* die Wand → die Wände : 벽 / hängen : 걸려 있다 / sogar : 심지어.
* das Bild → die Bilder : 그림 / geben : 주다 / es gibt : ~이 있다.
* das Buch → die Bücher : 책 / leider : 유감스럽게도.
* möchten : ~하고 싶다. 교재 표제어이며, 형태상 mögen의 접속법 2식 활용은 [4.3](#43-möchte와-mögen)에서 확인한다.
* das Regal → die Regale : 선반, 책장 / stellen : 세워 놓다.
* der Balkon → die Balkons : 발코니 / klein : 작은.
* nichts : 아무것도 ~않다 / Das macht nichts. : 괜찮아.

---

### 1.9. 38쪽 집 구하기 문화

* 교재 문화란은 월세와 보증금, 학교 게시판을 통한 방 구하기, 공동 주거를 소개한다. 교재 당시의 소개 내용으로 읽는다.
* die Kaution → die Kautionen : 보증금.
* die Wohngemeinschaft → die Wohngemeinschaften : 여러 사람이 함께 사는 주거 공동체.
* die WG → die WGs : Wohngemeinschaft의 약자.

## 2. 장소와 방향의 전치사

교재 39쪽 · [원본](../../materials/textbook-5/KakaoTalk_20261024_195145676_01.jpg)

### 2.1. 아홉 전치사

같은 전치사라도 **어디에 있는가(wo) → 3격**, **어디로 옮기거나 향하는가(wohin) → 4격**으로 구별한다. 아래는 공간을 나타내는 용법이다.

| 전치사 | 기본 뜻 |
| --- | --- |
| an | ~에 붙어, ~가에 |
| auf | ~위에, 표면에 닿아 |
| in | ~안에 |
| vor | ~앞에 |
| hinter | ~뒤에 |
| neben | ~옆에 |
| über | ~위쪽에 |
| unter | ~아래에 |
| zwischen | ~사이에 |

### 2.2. 전치사별 교재 예문 전체

* Das Bild hängt an der Wand.
    * 그림이 벽에 걸려 있다.
    * das Bild = 주어 / an + 여성 3격 → der Wand.
* Auf dem Boden liegt ein Teppich.
    * 바닥에 양탄자가 하나 깔려 있다.
    * der Boden → die Böden : 바닥 / der Teppich → die Teppiche : 양탄자.
    * auf dem Boden = 남성 3격 장소 / ein Teppich = 주어 → liegt.
* Er ist jetzt in seinem Zimmer.
    * 그는 지금 자기 방에 있다.
    * in + 중성 3격 → seinem Zimmer. sein = 그의, 지금 주어 자신의.
* Ein Schreibtisch steht vor dem Fenster.
    * 책상 하나가 창문 앞에 있다.
    * der Schreibtisch → die Schreibtische : 책상 / vor + 중성 3격 → dem Fenster.
* Hinter der Tür steht ein Schrank.
    * 문 뒤에 장이 하나 있다.
    * die Tür → die Türen : 문 / der Schrank → die Schränke : 장, 수납장.
    * hinter der Tür = 여성 3격 / ein Schrank = 남성 1격 주어.
* Liegt die Küche neben dem Badezimmer?
    * 부엌이 욕실 옆에 있니?
    * liegen은 여기서 공간의 위치를 나타낸다. die Küche = 주어.
    * neben dem Badezimmer = 중성 3격. 예·아니요 질문이라 Liegt가 맨 앞.
* Die Lampe hängt über dem Tisch.
    * 등이 탁자 위쪽에 달려 있다.
    * die Lampe → die Lampen : 등, 램프 / über + 남성 3격 → dem Tisch.
* Unter dem Baum liegt ein Mann.
    * 나무 아래에 남자가 한 명 누워 있다.
    * der Baum → die Bäume : 나무 / unter dem Baum = 남성 3격.
    * ein Mann = 주어 → liegt. liegen : 누워 있다.
* Ich stehe zwischen meiner Mutter und meinem Vater.
    * 나는 어머니와 아버지 사이에 서 있다.
    * stehen → ich stehe.
    * zwischen 뒤의 두 명사구 모두 3격 → meiner Mutter / meinem Vater.

---

### 2.3. 위치와 방향을 비교하는 교재 예문

* Das Buch liegt auf dem Sofa.
    * 책이 소파 위에 놓여 있다.
    * liegen : 놓여 있다. 위치 → auf + 3격, dem Sofa.
    * das Sofa → die Sofas : 소파.
* Sie legt das Buch auf das Sofa.
    * 그녀가 책을 소파 위에 놓는다.
    * legen : 눕혀 놓다. das Buch = 동사의 4격 목적어.
    * auf das Sofa = 책을 놓을 목표, 전치사 뒤 중성 4격.
* Die Flasche steht auf dem Tisch.
    * 병이 탁자 위에 서 있다.
    * die Flasche → die Flaschen : 병. 위치 → auf dem Tisch, 남성 3격.
* Ich stelle die Flasche auf den Tisch.
    * 나는 병을 탁자 위에 세워 놓는다.
    * stellen : 세워 놓다 / die Flasche = 동사의 4격 목적어.
    * 놓을 목표 → auf den Tisch, 남성 4격.
* Wir sind jetzt im Park.
    * 우리는 지금 공원에 있다.
    * wir → sind / im = in dem, 남성 3격 위치.
* Sie geht in den Park.
    * 그녀는 공원으로 간다.
    * gehen → geht / in den Park = 목적지, 남성 4격.
* Wo bist du? — Ich bin im Kino.
    * 너 어디에 있어? — 영화관에 있어.
    * das Kino → die Kinos : 영화관 / im Kino = in dem Kino, 중성 3격.
* Wohin gehst du? — Ich gehe ins Kino.
    * 어디로 가니? — 영화관으로 가.
    * ins Kino = in das Kino, 중성 4격 목적지.

---

### 2.4. 축약형과 격 확인

* am = an dem → am Fenster, 창가에, 3격. 37쪽 사진 필기에도 나온다.
* im = in dem → im Park / im Kino, 3격.
* ins = in das → ins Kino, 4격.
* aufs = auf das → 41쪽 연습문제의 선택지에 나온 축약형, 4격.
* der Tisch → dem Tisch(3격) / den Tisch(4격).
* die Wand → der Wand(3격) / die Wand(4격).
* das Sofa → dem Sofa(3격) / das Sofa(4격).
* 동사의 4격 목적어와 전치사 뒤의 격을 따로 본다.
    * Ich stelle **die Flasche**(무엇을?) **auf den Tisch**(어디로?).
* ‘움직이는 동사면 항상 4격’으로 외우지 않는다. 같은 공간 안에서 하는 동작인지, 그 공간으로 들어가거나 옮겨 놓는 것인지 구별한다.
* liegen ↔ legen : 놓여 있다 ↔ 눕혀 놓다.
* stehen ↔ stellen : 서 있다 ↔ 세워 놓다.

## 3. 동사의 격지배

교재 40쪽 · [40–41쪽](../../materials/textbook-5/KakaoTalk_20261024_195145676.jpg)

### 3.1. 3격을 쓰는 동사

* Sie hilft mir bei der Hausarbeit.
    * 그녀는 내가 집안일 하는 것을 도와준다.
    * helfen + 사람 3격 → mir / sie → hilft.
    * die Hausarbeit → die Hausarbeiten : 집안일; 학교의 과제물이라는 뜻도 있다.
    * bei + 3격 → bei der Hausarbeit. 여기서는 집안일을 뜻한다.
* Die Stadt gefällt mir nicht.
    * 그 도시는 내 마음에 들지 않는다.
    * die Stadt → die Städte : 도시. die Stadt = 주어 → gefällt.
    * gefallen + 사람 3격 → mir / nicht : ~하지 않다.
    * 마음에 드는 대상이 주어이고, 느끼는 사람이 3격이다.

---

### 3.2. 4격을 쓰는 동사

* Minho sucht dich.
    * 민호가 너를 찾는다.
    * suchen + 4격 → dich = du의 4격 / Minho → sucht.
* Meine Eltern lieben mich.
    * 우리 부모님은 나를 사랑하신다.
    * die Eltern = 복수 주어 → lieben.
    * lieben + 4격 → mich = ich의 4격.
* 사진 필기 : Ich frage dich.
    * 나는 너에게 묻는다.
    * fragen + 사람 4격 → dich. 한국어 ‘~에게’만 보고 3격으로 고르지 않는다.

---

### 3.3. 대화에서 함께 확인

* helfen + 사람 3격 → Hana hilft **ihm**.
* gefallen + 사람 3격 → Die Wohnung gefällt **mir**.
* suchen / treffen / lieben + 4격 → eine Wohnung / den Vermieter / mich.
* beschreiben + 사람 3격 + 대상 4격 → er beschreibt **Hana** **die Wohnung**.
* es gibt + 4격 → es gibt **einen Balkon**.
* 주어·동사 목적어·전치사구의 격은 각각 판단한다.
    * Hana(주어) / hilft / ihm(helfen의 3격) / bei der Wohnungssuche(bei의 3격).

## 4. 불규칙 현재형

교재 40쪽 · [원본](../../materials/textbook-5/KakaoTalk_20261024_195145676.jpg)

### 4.1. 교재 변화표 전체

| 주어 | fallen · 떨어지다 | helfen · 돕다 | sehen · 보다 |
| --- | --- | --- | --- |
| ich | falle | helfe | sehe |
| du | fällst | hilfst | siehst |
| er / sie / es | fällt | hilft | sieht |
| wir | fallen | helfen | sehen |
| ihr | fallt | helft | seht |
| sie | fallen | helfen | sehen |
| Sie | fallen | helfen | sehen |

* 어간 모음 변화는 이 동사들의 du와 er/sie/es에 나타난다.
* fallen : a → ä / helfen : e → i / sehen : e → ie.
* ihr형은 fallt / helft / seht. du·er형의 모음을 그대로 옮기지 않는다.

---

### 4.2. 교재에 함께 제시된 동사

아래 전체형은 교재의 추가 동사 목록을 풀어 쓴 보충이다. 순서: ich / du / er·sie·es / wir / ihr / sie·Sie.

* fahren : 타고 가다
    * fahre / fährst / fährt / fahren / fahrt / fahren.
* gefallen : 마음에 들다
    * gefalle / gefällst / gefällt / gefallen / gefallt / gefallen.
    * gefallen의 ge-는 분리하지 않는다.
* geben : 주다
    * gebe / gibst / gibt / geben / gebt / geben.
    * 대화의 es gibt는 ‘~이 있다’라는 구문이며 뒤에 4격을 쓴다.
* essen : 먹다
    * esse / isst / isst / essen / esst / essen.
    * du와 er형 모두 isst. sein의 ist와 철자를 구별한다.
* lesen : 읽다
    * lese / liest / liest / lesen / lest / lesen.
* aussehen : ~처럼 보이다
    * sehe … aus / siehst … aus / sieht … aus / sehen … aus / seht … aus / sehen … aus.
    * sehen의 모음 변화와 aus-의 분리를 함께 확인한다.
    * …는 문장 틀을 나타내며 교재의 별도 문장이 아니다.

---

### 4.3. möchte와 mögen

37쪽 대화의 möchte와 사진 필기의 mögen을 연결하는 보충이다.

* mögen : 좋아하다
    * mag / magst / mag / mögen / mögt / mögen.
    * 대상을 직접 좋아한다는 뜻에서는 4격 목적어를 쓴다.
* möchte : ~하고 싶다, ~을 원한다
    * möchte / möchtest / möchte / möchten / möchtet / möchten.
    * 형태상 mögen의 접속법 2식이며, 여기서는 현재의 희망을 부드럽게 말한다.
    * 교재 어휘 상자는 möchten으로 제시한다.
* Ich möchte ein Regal an die Wand stellen.
    * möchte는 활용한 동사, stellen은 문장 끝의 동사원형.
    * stellen을 ich형 stelle로 함께 활용하지 않는다.

---

## 5. 지시 표현 dies-와 jen-

교재 40–41쪽 · [원본](../../materials/textbook-5/KakaoTalk_20261024_195145676.jpg)

### 5.1. 의미와 변화

* dies- : 이, 이것 / jen- : 저, 저것.
* 교재 제목은 ‘지시대명사’. 아래 예문에서는 명사 앞의 지시 한정사로 쓰인다.
* 뒤 명사의 성·수·격에 맞춰 정관사와 같은 계열의 어미를 붙인다.
* 아래 표는 교재의 변화 설명을 풀어 쓴 보충. 각 칸은 dies- / jen- 순서다.

| 격 | 남성 | 여성 | 중성 | 복수 |
| --- | --- | --- | --- | --- |
| 1격 | dieser / jener | diese / jene | dieses / jenes | diese / jene |
| 2격 | dieses / jenes | dieser / jener | dieses / jenes | dieser / jener |
| 3격 | diesem / jenem | dieser / jener | diesem / jenem | diesen / jenen |
| 4격 | diesen / jenen | diese / jene | dieses / jenes | diese / jene |

* 복수 3격에서는 명사에도 보통 -n을 붙인다 → diesen Kindern.

---

### 5.2. 교재 예문 전체

* Ich kenne diese Frau.
    * 나는 이 여자를 안다.
    * kennen + 4격 → diese Frau, 여성 4격.
    * die Frau → die Frauen : 여자, 부인.
* Dieses Buch gefällt mir.
    * 이 책은 내 마음에 든다.
    * dieses Buch = 중성 1격 주어 → gefällt.
    * mir = 마음에 들어 하는 사람, 3격.
* Jenes Kind ist sehr brav.
    * 저 아이는 아주 얌전하다.
    * jenes Kind = 중성 1격 주어 / brav : 얌전한, 착한.
    * das Kind → die Kinder : 아이.
* In jenem Haus wohnt niemand.
    * 저 집에는 아무도 살지 않는다.
    * in + 위치 3격 → jenem Haus, 중성 3격.
    * niemand : 아무도 ~않다. 주어로 쓰였으므로 wohnt는 3인칭 단수.
    * das Haus → die Häuser : 집.
    * niemand 자체에 부정 의미가 있어 이 문장에 nicht를 더하지 않는다.

---

## 6. 추가 어휘와 사진 필기

### 6.1. 41쪽 어휘 상자 전체

교재 41쪽 · [원본](../../materials/textbook-5/KakaoTalk_20261024_195145676.jpg). 연습문제의 빈칸·답안은 옮기지 않고 어휘 상자를 정리했다.

* der Boden → die Böden : 바닥.
* der Teppich → die Teppiche : 양탄자.
* die Schule → die Schulen : 학교.
* die Tür → die Türen : 문.
* der Schrank → die Schränke : 장, 수납장.
* die Lampe → die Lampen : 등, 램프.
* der Baum → die Bäume : 나무.
* der Park → die Parks : 공원.
* die Hausarbeit → die Hausarbeiten : 집안일, 과제물.
    * das Haus + die Arbeit. 집안일이라는 뜻에서는 보통 단수.
* wohin : 어디로.
* das Sofa → die Sofas : 소파.
* legen : 눕혀 놓다.
* die Stadt → die Städte : 도시.
* lieben : 사랑하다.
* brav : 착한, 얌전한.
* niemand : 아무도 ~않다.

---

### 6.2. 읽을 수 있는 사진 필기

37쪽과 맞은편 여백 · [전체 사진](../../materials/textbook-5/KakaoTalk_20261024_195145676_02.jpg) · [37쪽 상세](../../materials/textbook-5/KakaoTalk_20261024_195145676_03.jpg).

* die Suche : 찾기, 탐색. Wohnung + 연결 요소 -s- + Suche → Wohnungssuche.
* der Mieter → die Mieter : 임차인, 세입자.
* vermieten : 임대하다, 세를 놓다. der Vermieter ‘임대인’과 연결한다.
* gefallen : 비분리동사 / aussehen : 분리동사.
* es gibt + 4격 / am = an dem.
* Ich stelle ein Regal an die Wand.
    * 나는 선반을 벽에 세워 놓는다.
    * ich → stelle / ein Regal = 동사의 4격 목적어 / an die Wand = 목표 위치 4격.
    * 대화의 möchte … stellen에서 möchte가 없는 현재형 문장으로 바꾼 필기.
* mögen : 좋아하다. 활용과 möchte의 관계는 [4.3](#43-möchte와-mögen).
* -keit, -heit, -tion, -ung, -tät : 여성 명사를 만드는 접미사 필기.
    * Wohnung처럼 해당 접미사로 만들어진 명사의 성을 확인한다.
    * 단순히 철자 끝부분이 같다고 모든 명사에 기계적으로 적용하지 않는다.
* 40쪽 사진 필기 : jemand ‘누군가’ ↔ niemand ‘아무도 ~않다’.
* 흐리거나 완성되지 않은 메모는 임의로 문장을 만들어 옮기지 않았다.
