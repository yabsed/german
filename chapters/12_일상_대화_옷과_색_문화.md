# 12장. 일상 대화·옷과 색·문화

[전체 목차](../독일어_통합_학습노트.md) · [← 11장](11_가족과_단어_만들기.md)

출처: 교재 16·20–22·26–30쪽의 회화·어휘·활동·문화 설명. 이 장은 앞에서 배운 문법을 실제 문맥에서 다시 읽도록 묶었다.

## 12.1 안부에서 커피와 산책으로 이어지는 대화

| 화자 | 독일어 | 뜻 |
|---|---|---|
| Hana Park | Hallo, Julia! | 안녕, 율리아! |
| Julia Bachmann | Hallo, Hana! Wie geht es dir? | 안녕, 하나! 어떻게 지내? |
| Hana Park | Danke. Mir geht es gut. Und dir? | 고마워. 잘 지내. 너는? |
| Julia Bachmann | Prima. Heute ist das Wetter sehr schön. Trinken wir einen Kaffee? | 아주 좋아. 오늘 날씨가 정말 좋네. 커피 한잔할까? |
| Hana Park | Gerne. | 좋아. |

**Bald finden sie ein Café.** 곧 두 사람은 카페 하나를 찾는다.

| 화자 | 독일어 | 뜻 |
|---|---|---|
| Julia Bachmann | Die Sonne scheint. Nehmen wir hier draußen Platz? | 해가 비치네. 우리 여기 바깥에 앉을까? |
| Hana Park | Ja, das Wetter ist heute wirklich schön. Später machen wir einen Spaziergang im Englischen Garten. | 응, 오늘은 날씨가 정말 좋아. 나중에 영국정원에서 산책하자. |
| Julia Bachmann | Gute Idee. Hast du denn Zeit? | 좋은 생각이야. 그런데 시간은 있어? |
| Hana Park | Ja, die Prüfung ist vorbei. Ich habe jetzt viel Zeit. | 응, 시험이 끝났어. 지금은 시간이 많아. |
| Julia Bachmann | Das ist gut. | 잘됐네. |

`einen Kaffee trinken`은 커피 한 잔 마시기, `Platz nehmen`은 자리를 잡고 앉기, `einen Spaziergang machen`은 산책하기다. 필기에는 `eine Prüfung machen`(시험을 보다), `eine Reise machen`(여행하다)도 함께 적혀 있다.

`denn`은 여기서 질문을 부드럽게 잇는 말이다. `Hast du denn Zeit?`를 ‘왜냐하면 시간이 있니?’처럼 번역하지 않는다. `vorbei sein`은 끝난 상태라는 뜻이다.

## 12.2 일상 대화의 어휘

| 어휘 | 복수·결합 | 뜻 |
|---|---|---|
| hallo | Hallo! | 안녕, 여보세요 |
| danken | Danke! | 감사하다 |
| prima | Prima! | 멋진, 아주 좋은 |
| das Wetter | 대화에서는 주로 단수 | 날씨 — 교재는 복수 die Wetter도 제시 |
| sehr | sehr schön | 매우 |
| schön | schönes Wetter의 schön | 아름다운, 좋은 |
| trinken | einen Kaffee / Tee trinken | 마시다 |
| bald | Bald finden sie ... | 곧 |
| finden | ein Café finden | 찾다, 발견하다 |
| das Café | die Cafés | 카페 |
| die Sonne | die Sonnen | 태양 — 이 대화에서는 단수 |
| scheinen | Die Sonne scheint. | 해가 비치다 |
| nehmen | Platz nehmen | 잡다, 취하다 |
| hier | hier draußen | 여기 |
| draußen | draußen spielen | 밖에, 밖에서 |
| der Platz | die Plätze | 자리, 장소 |
| heute | Heute ist ... | 오늘 |
| wirklich | wirklich schön | 정말로 |
| später | Später machen wir ... | 나중에 |
| der Spaziergang | die Spaziergänge | 산책 |
| gut | Gute Idee! | 좋은 |
| die Idee | die Ideen | 생각, 아이디어 |
| denn | Hast du denn Zeit? | 질문을 잇거나 뉘앙스를 더하는 말 |
| die Zeit | die Zeiten | 시간 |
| die Prüfung | die Prüfungen | 시험 |
| vorbei | Die Prüfung ist vorbei. | 끝난, 지나간 |
| die Flasche | die Flaschen | 병 |
| der Kaffee | einen Kaffee trinken | 커피; 한 잔의 커피 |
| der Tee | einen Tee trinken | 차; 한 잔의 차 |
| laut | Das Kind ist laut. | 시끄러운 |
| groß | Der Mann ist groß. | 큰, 키가 큰 |
| kennen | jemanden kennen | 사람·대상을 알다 |

`kennen`은 사람이나 대상을 알고 있다는 뜻이다. `finden`은 찾다·발견하다이므로 `Ich kenne den Mann`과 `Ich finde den Mann`은 다른 뜻이다.

## 12.3 옷·소지품과 색

| 명사 | 복수 | 뜻 |
|---|---|---|
| das Hemd | die Hemden | 셔츠 |
| die Bluse | die Blusen | 블라우스 |
| die Jacke | die Jacken | 재킷 |
| der Rock | die Röcke | 치마 |
| die Tasche | die Taschen | 가방 |
| die Lederhose | die Lederhosen | 가죽 바지 |
| die Brille | die Brillen | 안경 |
| die Mütze | die Mützen | 모자 |
| der Rucksack | die Rucksäcke | 배낭 |
| die Socke | die Socken | 양말 |

| 색 | 뜻 | 색 | 뜻 |
|---|---|---|---|
| weiß | 흰색 | schwarz | 검은색 |
| grau | 회색 | blau | 파란색 |
| grün | 초록색 | gelb | 노란색 |
| braun | 갈색 | | |

교재의 그림 옆 문장은 다음과 같다.

> Er trägt einen Rucksack. Der Rucksack ist schwarz.

그는 배낭을 메고 있다. 그 배낭은 검은색이다. 처음 소개하는 배낭에는 `einen`, 이어서 같은 배낭을 가리킬 때는 `der`를 쓴다. `tragen`의 목적어는 4격이다.

> Sie trägt eine Jacke. Die Jacke ist blau.

그녀는 재킷을 입고 있다. 그 재킷은 파란색이다. 여성 명사는 1격 `die Jacke`, 4격 `eine Jacke`다. `sein` 뒤의 색 형용사 `schwarz, blau`에는 여기서 어미를 붙이지 않는다.

`tragen`은 옷을 입다, 모자를 쓰다, 안경을 끼다, 배낭을 메다 등 한국어에서는 서로 다른 동사로 옮겨진다. 독일어에서는 같은 동사가 여러 착용 표현에 쓰인다.

## 12.4 사람을 소개하는 글

교재 20쪽의 인물 소개용 설정은 아래와 같다. **교재에 제시된 학습용 정보**이며 실제 인물의 최신 거주지를 나타내는 표로 읽지 않는다.

| 이름 | 나라 | 도시 | 직업 |
|---|---|---|---|
| Angela Merkel | Deutschland | Berlin | Politikerin |
| Lionel Messi | Argentinien | Barcelona | Fußballspieler |
| Julia Roberts | Amerika | Taos | Schauspielerin |

위 정보를 문장으로 읽으면 다음과 같다.

| 소개 문장 | 뜻 |
|---|---|
| Ich heiße Angela Merkel. Ich komme aus Deutschland. Ich wohne in Berlin. Ich bin Politikerin. | 저는 앙겔라 메르켈입니다. 독일 출신이고 베를린에 삽니다. 정치인입니다. |
| Ich heiße Lionel Messi. Ich komme aus Argentinien. Ich wohne in Barcelona. Ich bin Fußballspieler. | 저는 리오넬 메시입니다. 아르헨티나 출신이고 바르셀로나에 삽니다. 축구 선수입니다. |
| Ich heiße Julia Roberts. Ich komme aus Amerika. Ich wohne in Taos. Ich bin Schauspielerin. | 저는 줄리아 로버츠입니다. 미국 출신이고 타오스에 삽니다. 배우입니다. |

이 활동의 흐름은 **인사 → 이름 → 출신 → 거주지 → 직업 → 작별**이다. 각 질문은 [3장](03_인사와_자기소개.md)의 `Wie heißen Sie?`, `Woher kommen Sie? / Woher sind Sie?`, `Wo wohnen Sie?`, `Was sind Sie von Beruf?`와 연결된다.

## 12.5 독일어권과 지도 속 지명

교재의 지도는 **Deutschland(독일), Österreich(오스트리아), Schweiz(스위스)**를 중심으로 독일어권을 소개한다. 스위스 전체가 독일어만 사용하는 것은 아니며, 독일어권 지역이 넓게 존재한다는 점을 읽는다.

| 나라 | 지도에 적힌 도시 |
|---|---|
| Deutschland | Hamburg 함부르크, Berlin 베를린, Köln 쾰른, Frankfurt 프랑크푸르트, München 뮌헨 |
| Österreich | Wien 빈, Salzburg 잘츠부르크 |
| Schweiz | Zürich 취리히, Bern 베른 |

다른 본문에 등장하는 `Heidelberg`는 하이델베르크, `Düsseldorf`는 뒤셀도르프, `Dortmund`는 도르트문트다. `Ich komme aus ...`, `Ich wohne in ...`, `Ich komme nach ...`에 넣어 읽는 지명들이다.

## 12.6 독일의 이름에 관한 교재 설명

교재는 기독교·게르만 문화에서 온 이름이 전통적으로 많이 쓰였고, 1950년대 이후에는 영어·로만어 계열 이름도 널리 쓰였다고 설명한다. 예로 `Jennifer, Kevin, Natalie, Marco`를 든다.

교재의 ‘이름은 성별을 드러내야 하고 중성적인 이름이면 두 번째 이름으로 구별한다’는 설명은 일반적인 의무로 외우지 않는다. 독일 연방헌법재판소는 2008년 **Kiran 사건**에서 성별을 분명히 하는 두 번째 이름을 추가해야 한다는 조건을 인정하지 않았다. [독일 연방헌법재판소 2008년 12월 5일 결정](https://www.bundesverfassungsgericht.de/SharedDocs/Entscheidungen/DE/2008/12/rk20081205_1bvr057607.html)

다음은 **교재에 실린 해당 출생연도별 인기 이름 표**다. 현재 순위라는 뜻은 아니며, 철자와 이름에 익숙해지기 위한 자료다.

### 남자 이름

| 순위 | 1940 | 1970 | 1990 | 2000 |
|---|---|---|---|---|
| 1 | Peter | Stefan/Stephan | Jan | Lucas/Lukas |
| 2 | Klaus/Claus | Michael | Tobias | Jan |
| 3 | Hans | Andreas | Christian | Tim/Timm |
| 4 | Jürgen | Thomas | Alexander | Finn/Fynn |
| 5 | Dieter | Frank | Daniel | Leon |

### 여자 이름

| 순위 | 1940 | 1970 | 1990 | 2000 |
|---|---|---|---|---|
| 1 | Karin | Nicole | Julia | Anna |
| 2 | Ingrid | Anja | Sarah/Sara | Lea/Leah |
| 3 | Helga | Claudia | Jennifer | Sarah/Sara |
| 4 | Renate | Stephanie/Stefanie | Katharina | Hannah/Hanna |
| 5 | Elke | Andrea | Lisa | Michelle |

교재의 `Stehphanie`는 `Stephanie`로 표기를 바로잡았다. 슬래시로 나뉜 것은 같은 표에 함께 제시된 철자 변형이다.

## 12.7 뮌헨의 영국정원

가족 대화와 산책 대화의 **Englischer Garten**은 뮌헨의 영국정원이다. 교재는 뮌헨 동쪽의 도심 휴식 공간으로 소개하고, 1789년에 조성되었다고 설명한다. 사진에는 **Chinesischer Turm(중국탑)**과 잔디밭이 나오며, 중국탑 앞의 야외 맥주 공간도 언급된다.

본문의 `im Englischen Garten`은 ‘영국정원에서’라는 장소 표현이다. `im`은 `in dem`이 합쳐진 말이다. 같은 방식으로 `im Café`는 카페에서, `im Park`는 공원에서라는 뜻이다.
