# 11장. 가족과 단어 만들기

[전체 목차](../독일어_통합_학습노트.md) · [← 10장](10_숫자와_나이.md) · [12장 →](12_일상_대화_옷과_색_문화.md)

출처: PDF 「Meine Familie」 전체, 교재 29–33쪽, 소유관사 자료의 가족 어휘.

## 11.1 가족 명사는 단수와 복수를 함께

| 단수 | 복수 | 뜻 |
|---|---|---|
| die Familie | die Familien | 가족 |
| — | die Großeltern | 조부모 |
| der Großvater | die Großväter | 할아버지 |
| die Großmutter | die Großmütter | 할머니 |
| — | die Eltern | 부모 |
| der Vater | die Väter | 아버지 |
| die Mutter | die Mütter | 어머니 |
| — | die Geschwister | 형제자매 |
| der Bruder | die Brüder | 형·오빠·남동생 |
| die Schwester | die Schwestern | 누나·언니·여동생 |
| das Kind | die Kinder | 아이·자녀 |
| der Sohn | die Söhne | 아들 |
| die Tochter | die Töchter | 딸 |
| das Enkelkind | die Enkelkinder | 손자녀 |
| der Enkel | die Enkel | 손자 |
| der Enkelsohn | die Enkelsöhne | 손자 |
| die Enkelin | die Enkelinnen | 손녀 |
| die Enkeltochter | die Enkeltöchter | 손녀 |
| der Onkel | die Onkel | 삼촌·외삼촌 등 |
| die Tante | die Tanten | 이모·고모·숙모 등 |

`Eltern, Großeltern, Geschwister`는 이 자료에서 복수로 쓰인다. 그래서 `Meine Eltern wohnen ...`, `Hast du Geschwister?`처럼 사용한다. `Familie`는 여러 사람을 뜻해도 문법적으로는 단수일 수 있다는 점이 다르다.

한국어처럼 손위·손아래나 친가·외가를 한 단어 자체로 세밀하게 나누지는 않는다. `Bruder`를 언제나 ‘오빠’로만 번역하지 않고 문맥에 맞게 읽는다.

## 11.2 가족 대화의 배경

**Hana und Julia sitzen jetzt auf einer Bank im Englischen Garten. Sie reden über ihre Familien.**

하나와 율리아는 지금 영국정원의 벤치에 앉아 있다. 두 사람은 자기 가족들에 관해 이야기한다. 여기의 `Bank`는 은행이 아니라 벤치이며, `ihre Familien`은 ‘그들의 가족들’이다.

## 11.3 가족 대화 전체

| 화자 | 독일어 | 뜻 |
|---|---|---|
| Hana | Wo wohnen deine Eltern? | 부모님은 어디에 사시니? |
| Julia | Meine Eltern wohnen hier in der Nähe. | 우리 부모님은 이 근처에 사셔. |
| Hana | Wie oft besuchst du sie? | 부모님을 얼마나 자주 방문하니? |
| Julia | Ich besuche sie mindestens einmal pro Woche. | 적어도 일주일에 한 번은 찾아뵈어. |
| Hana | Hast du Geschwister? | 형제자매가 있니? |
| Julia | Ja, ich habe einen Bruder und eine Schwester. Mein Bruder ist 30 Jahre alt. Er ist Deutschlehrer. | 응, 남자 형제 한 명과 여자 형제 한 명이 있어. 남자 형제는 30살이고 독일어 교사야. |
| Hana | Und wie alt ist deine Schwester? | 여자 형제는 몇 살이니? |
| Julia | Sie ist siebzehn. Sie ist Schülerin. | 열일곱 살이야. 학생이야. |
| Hana | Hast du auch Großeltern? | 조부모님도 계시니? |
| Julia | Ja, aber nur meine Großmutter lebt noch. | 응, 하지만 할머니만 아직 살아 계셔. |
| Julia | Sie ist zwar alt, aber sehr gesund. | 나이는 많으시지만 아주 건강하셔. |
| Julia | Sie treibt regelmäßig Sport und spielt auch Klavier. | 규칙적으로 운동하시고 피아노도 치셔. |
| Hana | Ich habe auch Großeltern in Korea. Sie leben auf dem Land. | 나도 한국에 조부모님이 계셔. 시골에 사셔. |
| Julia | Vermisst du sie? | 그분들이 보고 싶니? |
| Hana | Ja, sie fehlen mir sehr. | 응, 아주 많이 보고 싶어. |

이 대화에서 `Ich besuche sie`의 `sie`는 부모님, `Vermisst du sie?`의 `sie`는 조부모님을 가리킨다. 같은 대명사여도 앞에서 어떤 대상을 말했는지 확인해야 한다.

## 11.4 문장을 연결해 주는 표현

| 표현 | 뜻 | 대화에서의 쓰임 |
|---|---|---|
| in der Nähe | 근처에 | wohnen과 함께 거주 위치를 말함 |
| wie oft | 얼마나 자주 | 방문 빈도를 물음 |
| mindestens | 적어도 | 빈도의 최솟값을 말함 |
| einmal pro Woche | 일주일에 한 번 | einmal 한 번 + pro Woche 주당 |
| zwar …, aber … | …이기는 하지만 … | Sie ist zwar alt, aber sehr gesund. |
| nur | 오직, …만 | nur meine Großmutter |
| noch | 아직 | lebt noch |
| regelmäßig | 규칙적으로 | regelmäßig Sport treiben |
| auch | 또한, …도 | spielt auch Klavier |
| auf dem Land | 시골에 | Sie leben auf dem Land. |

`leben`은 ‘살아 있다·생활하다’, `wohnen`은 거주지에 초점을 두는 ‘살다’다. `Meine Großmutter lebt noch`를 ‘할머니가 아직 거주하신다’라고 읽지 않는다.

## 11.5 vermissen과 fehlen

같은 그리움을 서로 다른 주어와 목적어로 말할 수 있다.

| 표현 | 문장 구조 | 뜻 |
|---|---|---|
| Ich vermisse sie. | 나(1격) + vermissen + 그들(4격) | 나는 그들이 그립다. |
| Sie fehlen mir. | 그들(1격) + fehlen + 나에게(3격) | 그들이 내게 없어서 아쉽다 → 그들이 그립다. |

`Sie fehlen mir sehr`의 주어는 `sie`다. 그래서 복수 동사 `fehlen`을 쓴다. 한 사람인 형제가 그리우면 보충 예로 `Mein Bruder fehlt mir`라고 할 수 있다.

## 11.6 여성 명사 만들기

직업이나 신분을 나타내는 여러 남성 명사에 `-in`을 붙여 여성 명사를 만든다. 여성 복수는 흔히 `-innen`이다.

| 남성 | 여성 | 여성 복수 | 뜻 |
|---|---|---|---|
| der Schüler | die Schülerin | die Schülerinnen | 학교에 다니는 학생 |
| der Student | die Studentin | die Studentinnen | 대학생 |
| der Lehrer | die Lehrerin | die Lehrerinnen | 교사 |
| der Deutschlehrer | die Deutschlehrerin | die Deutschlehrerinnen | 독일어 교사 |
| der Freund | die Freundin | die Freundinnen | 친구 |

교재의 `Schülerin`과 `Studentin`은 같지 않다. 전자는 학교 학생, 후자는 대학생이다. `-in` 규칙은 여러 직업·신분 명사에 적용되는 방식이며 모든 여성 명사를 만드는 유일한 규칙은 아니다.

## 11.7 복합명사 만들기

독일어는 단어를 붙여 긴 명사를 만들 수 있다. 기본적으로 **맨 뒤 명사가 전체 단어의 성을 결정**한다. 자료의 복합명사는 앞부분에 주강세가 온다.

| 복합명사 | 구성 | 뜻·성 |
|---|---|---|
| der Deutschlehrer | Deutsch + der Lehrer | 독일어 교사, Lehrer가 남성이므로 남성 |
| die Hausfrau | das Haus + die Frau | 가정주부, Frau가 여성이므로 여성 |
| die Großeltern | groß + die Eltern | 조부모, Eltern을 중심으로 하는 복수 명사 |
| der Schreibtisch | schreib- + der Tisch | 책상, Tisch가 남성이므로 남성 |

자료는 `Deutschlehrer = das Deutsch + der Lehrer`, `Schreibtisch = schreiben + der Tisch`처럼 설명한다. 실제 조합에서는 독일어라는 뜻의 `Deutsch`, 쓰다의 어간 `schreib-`이 붙은 형태로 이해하면 된다. 명사+명사뿐 아니라 형용사·동사 어간+명사도 가능하다.

## 11.8 가족 대화의 나머지 어휘

| 어휘 | 복수·관련형 | 뜻 |
|---|---|---|
| sitzen | sitzt, sitzen | 앉아 있다 |
| die Bank | die Bänke | 벤치 — 은행의 복수 Banken과 구별 |
| reden über + 4격 | ihre Familien | …에 관해 이야기하다 |
| die Nähe | in der Nähe | 가까움, 근처 |
| besuchen | besucht | 방문하다 |
| die Woche | die Wochen | 주, 일주일 |
| das Jahr | die Jahre | 해, 년 |
| alt | Jahre alt | 나이가 든, …살의 |
| gesund | sehr gesund | 건강한 |
| Sport treiben | sie treibt Sport | 운동하다 |
| spielen | Klavier spielen | 놀다, 악기를 연주하다 |
| das Klavier | die Klaviere | 피아노 |
| das Land | die Länder | 나라; auf dem Land에서는 시골 |
| vermissen | vermisst | 그리워하다 |
| fehlen | fehlt / fehlen | 없다, 부족하다; 누군가에게 그리운 상태다 |
| das Haus | die Häuser | 집 |
| die Hausfrau | die Hausfrauen | 가정주부 |
| schreiben | schreibt | 쓰다 |
| der Schreibtisch | die Schreibtische | 책상 |

`Sport treiben`과 `Klavier spielen`은 이 대화에서 관사 없이 쓰는 익숙한 결합이다. 단어별 번역보다 표현 전체로 읽으면 자연스럽다.
