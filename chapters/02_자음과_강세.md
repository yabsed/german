# 2장. 자음과 강세

출처: 교재 11–13쪽, 프린트 「알파벳과 발음」 23–24쪽과 필기, PDF 「독일어 발음-2」 7–12쪽.

## 2.1 b·d·g는 위치에 따라 달라진다

독일어에서는 음절 끝의 유성 자음이 무성음으로 바뀌는 일이 있다. 특히 `b, d, g`는 단어 끝에서 각각 `[p], [t], [k]`로 읽는 경우가 많다.

| 글자 | 기본 소리와 예 | 끝에서 무성음이 되는 예 |
|---|---|---|
| b | [b] Bruder, Blume, Butter, Liebe, Elbe, Bus, Brot, bin, Beruf, Baum, leben | [p] lieb, Dieb, Herbst, Obst, halb, gelb, selbst |
| d | [d] Drama, Deutsch, Boden, Dame, drei, der, finden | [t] Land, Kind, Mädchen, Freund, Hand, Mund, Wind |
| g | [ɡ] Gnade, Grafik, gegen, original, Gabel, Gast, gut, Magen, geben, Gott, sagen, Tages | [k] Burg, Zug, Tag, Berg |

`Tag`의 마지막 `g`와 `Tages`에서 모음 사이에 있는 `g`는 다르게 들린다. ‘글자 뒤에 모음이 없으면 언제나 무성음’처럼 외우기보다는 음절과 단어의 끝을 먼저 본다.

단어 끝의 `-ig`는 표준 발음에서 흔히 `[ɪç]`다. `billig, König, Honig, lustig`가 자료의 예다. 지역에 따라 `[ɪk]`도 들을 수 있다. `Genie, Orange`처럼 프랑스어계 단어의 `g`는 `[ʒ]`가 되기도 한다.

## 2.2 단자음 한눈에 보기

| 철자 | 소리·읽는 법 | 자료의 예 |
|---|---|---|
| c | 외래어에서 [k] 또는 [ts] | Café, Creme, Cola, Computer / Cent, circa |
| f | [f] | auf, Frau, Familie, helfen |
| h | 음절 첫머리에서는 [h], 장음을 나타내는 위치에서는 묵음 | Hut, Haus / gehen, froh |
| j | [j], 영어 y와 비슷한 소리 | ja, jung, Jahr |
| k | [k] | kalt, Kind, welken |
| l | [l] | Ball, leben, lesen, Glück |
| m | [m] | Monat, Morgen |
| n | [n] | neben, nein |
| p | [p] | Post, Prost, Papier |
| qu | [kv] | Quelle, Qual, Quatsch |
| r | 혀끝·목젖의 r, 위치에 따라 모음화 | Reis, Rad, Herz, trinken / Bier, wer, Vater, Mutter |
| s | 유성 [z] 또는 무성 [s] | senden, sagen, sehen, Sohn, Häuser, Nase, Sommer / Maus, Plus, Haus, Glas |
| t | [t] | Traum, Tat, Tag, halt |
| v | [f] 또는 [v] | Vater, voll, Vogel, Volk, von / Vase, Klavier, Verb |
| w | [v], 영어 w와 다름 | Welt, Winter, wir, was, Wetter |
| x | [ks] | Text, Taxi |
| z | [ts] | zwei, Arzt, Zeit |

`Prost!`는 건배할 때 쓰는 말이다. `r`는 `Bier, wir, Uhr, Tür`처럼 모음 뒤에서 약해져 모음처럼 들리기도 한다. 끝의 `-er`를 또렷한 한국어 ‘에르’로 읽으려고 애쓰지 않아도 된다.

**주의:** 프린트의 `z` 발음기호 `[z]`는 오기다. `z`는 `[ts]`이고, `[z]`는 `Sonne` 첫소리와 같은 유성 s 소리를 뜻한다.

## 2.3 v와 y의 여러 발음

`v`는 단어별로 익히는 편이 안전하다.

| 소리 | 원자료의 예 |
|---|---|
| [f] | Vogel, Volk, Motiv, brav, naiv, Vater, voll, von |
| [v] | Vitamin, Violine, November, Novelle, Vase, Klavier, Verb |

`Motiv, brav, naiv`의 맨 끝 `v`는 무성음 `[f]`다. 모음으로 시작하는 어미가 붙으면 `Motive, brave, naive`처럼 `[v]`가 날 수 있다.

`y`는 모음으로 쓰일 때 `ü` 계열의 소리가 될 수 있고, 자음으로 쓰일 때 `[j]`가 될 수 있다.

| 역할 | 예 |
|---|---|
| 모음, [yː] 또는 [ʏ] 계열 | System, Gymnasium, Physiker, Typ, Lyrik, Mythos, dynamisch, Rhythmus |
| 자음 [j] | Yacht, Yoga, Yoghurt / Joghurt |

PDF는 `Joghurt`를 표준형으로 제시한다. 여기서는 학습용 철자를 `Joghurt`로 통일한다.

## 2.4 ch는 앞의 모음을 살핀다

| 환경 | 대표 발음 | 원자료의 예 |
|---|---|---|
| a, o, u, au 뒤 | [x], 목 뒤쪽의 마찰음 | Bach, Buch, auch, noch, doch, Nacht, Tochter, ach, hoch, Koch |
| 그 밖의 모음이나 여러 자음 뒤 | [ç], 혀 앞쪽의 부드러운 마찰음 | echt, ich, Milch, nicht, recht, leicht, Nächte, Töchter, Bücher, durch, dich, höchst, München, solch |
| 일부 어두·외래어 | 단어·지역에 따라 다름 | China, Chemie / Chaos, Christ / Chance, Chef |

`Buch → Bücher`, `Tochter → Töchter`, `Nacht → Nächte`처럼 움라우트가 생기면 `ch`의 발음도 `[x] → [ç]`로 달라진다.

자료의 `China, Chemie`는 `[ç]`로 시작하는 표준 발음을 예로 든 것이다. **모든 어두 ch가 [ç]인 것은 아니다.** `Chaos, Christ`는 `[k]`, `Chance, Chef`는 `[ʃ]` 계열이다.

## 2.5 여러 글자가 만드는 자음

| 철자 | 발음 | 자료의 예 |
|---|---|---|
| chs | [ks] | Ochs, sechs, Fuchs |
| ck | [k] | Zucker, locker, dick, zurück |
| ds | [ts] | Landsmann, abends |
| dt | [t] | Stadt, Schmidt |
| ng | [ŋ], ‘ㅇ’ 받침 계열 | jung, Finger, eng, singen, Junge, Wohnung |
| nk | [ŋk] | trinken, danken, denken, Onkel |
| pf | [pf], 두 자음을 이어 냄 | Pferd, Kopf, Apfel |
| ph | [f] | Physik, Phase |
| rh | r 소리 | Rhein, Rhetorik |
| sch | [ʃ] | Schwester, Schule, Tisch, Mensch, schön, Schiff |
| sp | 어근 첫머리 [ʃp], 그 밖에는 [sp]인 경우가 많음 | Sprache, Sport, spielen, sprechen / Knospe, Wespe |
| st | 어근 첫머리 [ʃt], 그 밖에는 [st]인 경우가 많음 | Staat, Stein, Student, stehen, Stunde / Fenster, Kunst, bist, fast |
| th | [t] | Theater, Thema |
| ts | [ts] | nachts, bereits, rechts |
| tsch | [tʃ] | Deutsch, Quatsch, Dolmetscher, tschüss |
| tz | [ts] | jetzt, Netz, Katze, Platz, Satz |
| ß | [s] | Fuß, heißen, Maß, Soße |
| ti + 모음 | 외래어에서 흔히 [tsi̯] 계열 | Information, Patient, Nation, Lektion, Aktie |

`sch`는 앞에 오든 뒤에 오든 기본적으로 같은 `[ʃ]`다. 한글로 ‘슈/쉬’를 나누어 적은 원자료 설명은 발음을 돕기 위한 근사치다.

`sp, st`의 기준은 **단어의 맨 처음만이 아니라 어근의 첫머리**다. 필기의 `Ein|stein, ver|stehen, Aus|sprache, Fremd|sprache`는 이 점을 보여 준다. `verstehen`의 `st`는 `[ʃt]`, `Aussprache, Fremdsprache`의 `sp`는 `[ʃp]`로 읽는다. ## 2.6 강세는 어느 음절을 힘주어 읽는가이다

기본 독일어 단어는 첫 음절에 강세가 오는 경우가 많다. 아래의 굵은 부분이 강세를 받는다.

| 묶음 | 원자료의 단어 |
|---|---|
| 명사 | **A**bend, **Ar**beit, **Bru**der, **El**tern, **Ham**burg, **Leh**rer, **Schu**le, **Son**ne, **Wet**ter |
| 동사 | **bit**ten, **hei**ßen, **ken**nen, **kom**men, **le**ben, **ma**chen, **schwim**men, **woh**nen |
| 그 밖의 표현 | **al**les, **ger**ne, **heu**te, **im**mer, **lei**der, **spä**ter |
| 첫 음절 강세가 아닌 예 | Ber**lin**, Ca**fé**, Mu**sik**, mö**bliert** |

`Berlin`처럼 외래어 여부만으로 설명되지 않는 고유명사도 있다. ‘첫 음절 강세’는 자주 맞는 경향이지 절대 규칙이 아니다.

## 2.7 접두사·접미사와 강세

분리접두사는 보통 강세를 받는다. 자료의 접두사는 `ab-, an-, auf-, aus-, ein-, mit-, vor-, zu-`다.

`**ab**fahren` 출발하다, `**an**kommen` 도착하다, `**aus**steigen` 내리다, `**auf**fallen` 눈에 띄다, `**ein**schlafen` 잠들다, `**mit**fahren` 함께 타고 가다, `**vor**haben` 계획하다, `**zu**sagen` 승낙하다.

비분리접두사 `be-, emp-, ent-, er-, ge-, miss-, ver-, zer-`는 자료에 제시된 다음 단어들에서 강세를 받지 않는다.

`be**kom**men` 받다, `emp**feh**len` 추천하다, `ent**de**cken` 발견하다, `er**zäh**len` 이야기하다, `ge**fal**len` 마음에 들다, `miss**brau**chen` 남용하다, `ver**ste**hen` 이해하다, `zer**stö**ren` 파괴하다.

**보충:** 특히 `miss-`와 복합적인 파생어의 강세는 단어별 예외가 있으므로 목록 전체를 무조건적인 법칙으로 확대하지 않는다. 지금은 자료 속 예시의 발음을 익히면 된다.

접미사 `-heit, -keit, -lein, -ung, -er, -schaft, -bar, -haft, -ig, -isch, -lich`는 대체로 강세를 끌어오지 않는다.

`Ge**sund**heit` 건강, `**Sau**berkeit` 청결, `**Fräu**lein`, `**Prü**fung` 시험, `**Leh**rer` 교사, `**Freund**schaft` 우정, `**wun**derbar` 멋진, `**zwei**felhaft` 의심스러운, `**flei**ßig` 부지런한, `**herz**lich` 진심 어린.

외래어 접미사 `-ent, -ion, -tät, -ist, -ieren`는 강세를 받는 경우가 많다: `Stu**dent**, Na**tion**, Universi**tät**, Pia**nist**, stu**die**ren`.

## 2.8 필기에 추가된 발음 비교와 표현

| 묶음 | 읽으며 볼 점 |
|---|---|
| Nummer, Sommer, Zimmer | 끝의 -er가 약하게 발음됨 |
| wir, Bier, Bär, Uhr, Natur, Tür, Tor | 모음 뒤 r의 소리 |
| Sohn, Salz, Soja, Sonne, Sommer | 유성 s의 예 |
| leise, Reise, Rose, Riese | 모음 사이 s의 소리 |
| Land, rot, Regen | d·t·r·g 비교 |
| gehen / geheim | h와 ei, 그리고 서로 다른 강세 |
| woher / wohin | 어디에서 / 어디로 |
| Abend / abends | 저녁 / 저녁에 |
| Stadt / Staat | 도시 / 국가: 짧은 a와 긴 a |
| nichts, Deutschland, Sojasoße | 자음 조합이 포함된 단어 |
| Alles klar? — Ja, alles klar. | 다 이해됐어? — 응, 다 이해됐어. |
| Danke schön! / Bitte schön! | 감사합니다! / 천만에요·여기 있습니다! |
