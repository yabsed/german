# 10장. 숫자와 나이

[전체 목차](../독일어_통합_학습노트.md) · [← 9장](09_부정문_kein과_nicht.md) · [11장 →](11_가족과_단어_만들기.md)

출처: 프린트 「수(Zahlen): 0–200」와 필기, 교재 29·32–33쪽.

## 10.1 0부터 20까지

| 숫자 | 독일어 | 숫자 | 독일어 |
|---|---|---|---|
| 0 | null | 11 | elf |
| 1 | eins | 12 | zwölf |
| 2 | zwei | 13 | dreizehn |
| 3 | drei | 14 | vierzehn |
| 4 | vier | 15 | fünfzehn |
| 5 | fünf | 16 | sechzehn |
| 6 | sechs | 17 | siebzehn |
| 7 | sieben | 18 | achtzehn |
| 8 | acht | 19 | neunzehn |
| 9 | neun | 20 | zwanzig |
| 10 | zehn | | |

13–19는 기본적으로 ‘일의 자리 + zehn’이다. `dreizehn = drei + zehn`이다. 다만 **sechs → sechzehn**, **sieben → siebzehn**에서는 일부 철자가 줄어든다. `sechszehn`, `siebenzehn`이라고 쓰지 않는다.

## 10.2 21부터는 일의 자리를 먼저 읽는다

독일어의 21은 ‘하나 그리고 스물’ 순서다. **일의 자리 + und + 십의 자리**를 붙여 쓴다.

| 숫자 | 독일어 | 구조 |
|---|---|---|
| 21 | einundzwanzig | ein + und + zwanzig |
| 22 | zweiundzwanzig | zwei + und + zwanzig |
| 23 | dreiundzwanzig | drei + und + zwanzig |
| 24 | vierundzwanzig | vier + und + zwanzig |
| 25 | fünfundzwanzig | fünf + und + zwanzig |
| 26 | sechsundzwanzig | sechs + und + zwanzig |
| 27 | siebenundzwanzig | sieben + und + zwanzig |
| 28 | achtundzwanzig | acht + und + zwanzig |
| 29 | neunundzwanzig | neun + und + zwanzig |

31–39, 41–49, …, 91–99도 같은 방식이다. `49 → neunundvierzig`, `51 → einundfünfzig`다. 13의 `dreizehn`에는 `und`가 없고, 23의 `dreiundzwanzig`에는 있다.

## 10.3 십 단위와 백 단위

| 숫자 | 독일어 | 주의할 점 |
|---|---|---|
| 20 | zwanzig | zwei + zig로 단순히 만들 수 없음 |
| 30 | dreißig | -zig가 아니라 -ßig |
| 40 | vierzig | vier + zig |
| 50 | fünfzig | fünf + zig |
| 60 | sechzig | sechs의 s가 빠짐 |
| 70 | siebzig | sieben의 en이 빠짐 |
| 80 | achtzig | acht + zig |
| 90 | neunzig | neun + zig |
| 100 | hundert / einhundert | ein을 붙일 수 있음 |
| 101 | hunderteins / einhunderteins | 끝의 1은 eins |
| 200 | zweihundert | zwei + hundert |

`26, 27`에서는 `sechsundzwanzig, siebenundzwanzig`처럼 원래 형태를 쓴다. 16·17·60·70에서 줄어든 형태를 다른 숫자에 그대로 적용하지 않는다.

## 10.4 eins와 ein

숫자 1을 독립적으로 셀 때는 `eins`, `einundzwanzig`나 `einhundert`의 구성요소로는 `ein`이다. `101`처럼 끝에 단독 1이 남으면 `hunderteins`다.

명사 앞에서는 성과 격에 맞춰 `ein Kind, eine Schwester, einen Bruder`처럼 바뀐다. 숫자 읽기와 관사 변화를 연결해 보면 형태가 다른 이유를 이해하기 쉽다.

## 10.5 큰 수

| 숫자 | 독일어 | 한국어 |
|---|---|---|
| 1,000 | tausend / eintausend | 천 |
| 1,000,000 | eine Million | 백만 |
| 1,000,000,000 | eine Milliarde | 십억 |
| 1,000,000,000,000 | eine Billion | 일조 |

`Million, Milliarde, Billion`은 명사라서 대문자로 쓴다. 독일어 **Billion은 영어 billion과 크기가 다르다.** 자료의 Billion은 일조다. 복수형은 `Millionen, Milliarden, Billionen`이다.

## 10.6 나이는 sein으로 말한다

구조는 **주어 + sein + 숫자 + Jahre alt**다. 독일어에서는 나이를 `haben`으로 말하지 않는다.

| 질문 | 대답 | 뜻 |
|---|---|---|
| Wie alt ist dein Vater? | Er ist neunundvierzig Jahre alt. | 네 아버지는 몇 살이니? — 49세야. |
| Wie alt bist du? | Ich bin neunzehn Jahre alt. | 너는 몇 살이니? — 19살이야. |
| Wie alt ist Ihr Enkel? | Er ist sechs Jahre alt. | 손자는 몇 살인가요? — 6살입니다. |
| Wie alt ist seine Mutter? | Sie ist einundfünfzig Jahre alt. | 그의 어머니는 몇 살인가? — 51세다. |
| Wie alt ist dein Bruder? | Er ist siebenundvierzig Jahre alt. | 네 남자 형제는 몇 살이니? — 47살이야. |
| Wie alt ist Ihre Schwester? | Sie ist dreiundzwanzig Jahre alt. | 자매는 몇 살인가요? — 23살입니다. |

가족 대화의 `Mein Bruder ist 30 Jahre alt`는 ‘내 남자 형제는 30살이다’, `Sie ist siebzehn`은 ‘그녀는 17살이다’다. 나이를 말하는 문맥이 분명하면 `Jahre alt`를 생략할 수 있다. 정중한 질문은 `Wie alt sind Sie?`다.
