# 7장. 인칭대명사와 목적어

[전체 목차](../독일어_통합_학습노트.md) · [← 6장](06_명사의_성_수_격과_관사.md) · [8장 →](08_소유관사.md)

출처: 교재 24·26쪽, 프린트 「인칭대명사」 및 작문 프린트의 대명사 바꾸기 필기.

## 7.1 이름이나 명사 대신 쓰는 말

`Peter`를 계속 반복하지 않고 `er`, `den Mann`을 반복하지 않고 `ihn`으로 바꿀 수 있다. 이때 **누구를 가리키는지**뿐 아니라 **몇 격인지**도 맞아야 한다.

| 대상 | 1격 | 2격 | 3격 | 4격 |
|---|---|---|---|---|
| 나 | ich | meiner | mir | mich |
| 너 | du | deiner | dir | dich |
| 그 / 남성 명사 | er | seiner | ihm | ihn |
| 그녀 / 여성 명사 | sie | ihrer | ihr | sie |
| 그것 / 중성 명사 | es | seiner | ihm | es |
| 우리 | wir | unser | uns | uns |
| 너희 | ihr | euer | euch | euch |
| 그들 / 복수 명사 | sie | ihrer | ihnen | sie |
| 존칭 한 사람 | Sie | Ihrer | Ihnen | Sie |
| 존칭 여러 사람 | Sie | Ihrer | Ihnen | Sie |

`Ich liebe dich`에서 `ich`는 사랑하는 사람인 주어, `dich`는 사랑을 받는 대상인 4격이다. `Du liebst mich`에서는 역할이 반대가 된다.

문법적 성은 사물에도 적용된다. `der Wein`을 4격 대명사로 바꾸면 `ihn`, `die Blume`는 `sie`, `das Geld`는 `es`다. ‘사물이니까 모두 es’라고 생각하면 안 된다.

## 7.2 2격 인칭대명사와 소유관사는 다르다

표의 `meiner, deiner, seiner` 등은 **2격을 요구하는 표현에 쓰이는 인칭대명사**다. 일상에서는 사용 빈도가 낮다. 명사 앞에서 ‘나의 책’을 나타내는 `mein Buch`와는 용법이 다르다.

프린트에 있는 예는 다음과 같다.

| 원자료의 예문 | 뜻·설명 |
|---|---|
| Er spottet meiner. | 그는 나를 비웃는다. `spotten`의 문어적인 2격 용법이다. |
| Ich bin seiner bedürftig. | 나는 그를 필요로 한다. `bedürftig`가 2격을 요구하는 문어적인 표현이다. |
| Ich gehe dort statt deiner. | 나는 거기에 / 거기서 네 대신 간다. `statt deiner`는 ‘네 대신’이라는 문어적 표현이다. |

처음에는 회화에서 자주 쓰는 **1·3·4격**을 먼저 익히면 된다. 이 2격 표가 빠져 있는 자료와 충돌하는 것이 아니라, 학습 단계에 따라 생략되는 부분이다.

## 7.3 lieben으로 읽는 4격 대명사

| 예문 | 뜻 |
|---|---|
| Ich liebe dich. | 나는 너를 사랑한다. |
| Du liebst mich. | 너는 나를 사랑한다. |
| Liebst du mich? | 너는 나를 사랑하니? |
| Er liebt sie. | 그는 그녀를 / 그들을 사랑한다. |
| Sie liebt dich. | 그녀는 너를 사랑한다. |
| Es liebt ihn. | 그것은 그를 사랑한다. — es가 가리키는 대상은 앞 문맥에서 정해진다. |
| Wir lieben es. | 우리는 그것을 사랑한다. |
| Ihr liebt uns. | 너희는 우리를 사랑한다. |
| Sie lieben euch. | 그들은 너희를 사랑한다. — 프린트가 지정한 해석 |
| Sie lieben mich. | 당신은 저를 사랑하십니다. — 존칭 단수로 제시된 예 |
| Sie lieben uns. | 여러분은 우리를 사랑하십니다. — 존칭 복수로 제시된 예 |

같은 `Sie lieben ...`도 문맥에 따라 ‘그들’ 또는 존칭이 된다. 대명사만으로 해석이 확정되지 않을 때는 동사 형태와 대화 상황을 함께 본다.

## 7.4 편지를 쓰는 상대는 3격

`jemandem einen Brief schreiben`은 ‘누구에게 편지 한 통을 쓰다’다. 받는 사람은 3격, `einen Brief`는 4격이다.

| 예문 | 받는 사람과 뜻 |
|---|---|
| Ich schreibe dir einen Brief. | 나는 너에게 편지를 쓴다. |
| Du schreibst mir einen Brief. | 너는 나에게 편지를 쓴다. |
| Martin schreibt ihr einen Brief. | 마르틴은 그녀에게 편지를 쓴다. `ihr`는 앞서 말한 Mutter를 가리킨다. |
| Maria schreibt ihm einen Brief. | 마리아는 그 아이에게 편지를 쓴다. Kind는 중성이다. |
| Das Kind schreibt ihm einen Brief. | 그 아이는 아버지에게 편지를 쓴다. Vater는 남성이다. |
| Wir schreiben euch einen Brief. | 우리는 너희에게 편지를 쓴다. |
| Ihr schreibt uns einen Brief. | 너희는 우리에게 편지를 쓴다. |
| Sie schreiben Ihnen einen Brief. | 그들은 당신 / 여러분에게 편지를 쓴다. |
| Sie schreiben ihm einen Brief. | 당신은 페터에게 편지를 쓰십니다. |
| Sie schreiben ihnen einen Brief. | 여러분은 자비네와 기젤라에게 편지를 쓰십니다. |

마지막 두 줄은 프린트에 지정된 주어의 해석이다. `Ihnen`은 존칭, `ihnen`은 그들에게라는 뜻이므로 대소문자를 구별한다.

## 7.5 명사 문장을 대명사로 바꾸어 읽기

| 원래 문장 | 대명사를 사용한 문장 | 연결 관계 |
|---|---|---|
| Die Frau liebt einen Mann. | Sie liebt ihn. | die Frau → sie, einen Mann → ihn |
| Ich helfe dem Kind. | Ich helfe ihm. | 중성 3격 → ihm |
| Wir schenken der Mutter eine Blume. | Wir schenken ihr eine Blume. / Wir schenken sie ihr. | der Mutter → ihr, eine Blume → sie |
| Du zeigst einem Freund den Stern. | Du zeigst ihm den Stern. / Du zeigst ihn ihm. | einem Freund → ihm, den Stern → ihn |
| Der Vater kauft der Tochter ein Auto. | Er kauft ihr ein Auto. / Er kauft es ihr. | Vater → er, Tochter → ihr, Auto → es |
| Gisela schreibt einer Freundin einen Brief. | Sie schreibt ihr einen Brief. / Sie schreibt ihn ihr. | Gisela → sie, Freundin → ihr, Brief → ihn |
| Peter trinkt den Wein. | Er trinkt ihn. | Wein은 남성 4격이므로 ihn |
| Hast du einen Bruder? | Hast du ihn? | 문법상 대치 가능하지만 자연스러운 뜻은 달라질 수 있음 |
| Brauchen Sie das Geld? | Brauchen Sie es? | Geld는 중성 4격이므로 es |
| Peter fragt den Lehrer. | Er fragt ihn. | Lehrer는 남성 4격이므로 ihn |

`Hast du einen Bruder?`는 형제가 있는지 묻는다. `Hast du ihn?`은 이미 언급한 사람을 찾았는지·확보했는지 등을 묻는 문맥이 필요하다. **대명사 대치는 언제나 원래 문장의 정보와 쓰임을 그대로 유지하는 것은 아니다.**

프린트 필기의 `Er trinkt es`는 앞의 `den Wein`을 받는 문장이라면 `Er trinkt ihn`으로 고쳐야 한다. 두 목적어가 모두 대명사인 `Wir schenken sie ihr`에서는 보통 **4격 대명사 + 3격 대명사** 순서다.

## 7.6 안부 표현에서 다시 만나는 3격

`Wie geht's?`는 `Wie geht es?`를 줄인 말이다. 사람을 붙이면 `Wie geht es dir / Ihnen / Peter / Julia?`가 된다.

`Danke, gut. Und dir?`는 ‘고마워, 잘 지내. 너는?’, `Danke, mir geht es gut`는 ‘고마워요, 잘 지내요’, `Es geht so`는 ‘그럭저럭이에요’다. 페터를 받아 답하면 `Es geht ihm gut`, 율리아를 받아 답하면 `Es geht ihr sehr gut`라고 한다.

안부의 틀은 **es geht + 3격 사람 + 상태**다. 그래서 `Wie geht es du?`나 `Es geht ich gut`는 쓰지 않는다.
